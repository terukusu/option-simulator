# 契約テンプレ: 画面部品・操作（`ui/`）

対象: `ui/` の画面部品と操作。例: 板の表、スマイルのグラフ、損益グラフ、シナリオのスライダー、指標・テール表、足の編集、保存（localStorage / URL）、データ元の切替と鮮度表示（`docs/design.md` 2.1 の M1〜M14、6 章のワイヤー）。

画面部品は DOM と描画が本体なので、**表示する値の計算・整形は `model/` か DOM を持たない関数に切り出し**（そちらは `pure-function.md`）、この契約では「何を入力に、何をどう表示し、どの操作に何が起きるか」を書く。

## 記入項目

| 項目 | 書き方 |
|---|---|
| 入力 | 部品が受け取る状態（板・ポジション・シナリオ・設定）と、その出どころ（`data/` / `model/` / 利用者の操作） |
| 表示 | 何をどの単位・桁で出すか（円 / 千円の自動切替、IV の pt、デルタのラージ換算とミニ換算、「補間」「IV 不安定」「理論値（板なし）」「古い板」の印） |
| 操作 | マウス・キー・タッチ（`docs/design.md` M5・M10: 数値入力、矢印キー 1 刻み / Shift 10 刻み、R でリセット、+ / − で拡大、1 本指ドラッグ = パン、2 本指 = 拡大）と、それぞれで状態がどう変わるか |
| 状態と保存 | 状態の持ち場所。localStorage / URL に保存するなら形式と後方互換（古い形式を読めるか） |
| 異常系 | 板が無い・API が 503・データが古い・入力が範囲外のときの表示（入力値をそのまま HTML として出さない） |
| セキュリティ | DOM への値の入れ方（`textContent` / 属性の setter。`innerHTML` にデータを入れない）、CSP（インライン script・style 属性・外部 URL を使わない。スタイルは CSS のクラスで） |
| 性能 | 描き直しの予算（16 ms、横軸 1 画素 1 点、足 10 本、板 322 行） |
| 画面幅 | 幅 360px で横スクロールが出ないこと、スマホでの列の絞り込み・切替 |
| アクセシビリティ | キーボードで操作できるか、ラベル |
| 設計との対応 | `docs/design.md` の節・M / AC / U 番号 |

## 記入テンプレ

```markdown
### `<部品名>` (`<ファイルパス>`) — 新規 / 改修

- 入力: <状態と出どころ>
- 表示: <項目・単位・桁・印>
- 操作:
  1. <操作> → <状態の変化と再描画>
- 保存: <なし / localStorage・URL のキーと形式、旧形式の扱い>
- 異常系: <板なし / 503 / 古い板 / 範囲外入力の表示>
- セキュリティ: <DOM への入れ方、CSP>
- 性能: <予算と計り方>
- 画面幅: <360px での配置>
- 設計: docs/design.md <節>、<M / AC / U 番号>
- 改修の場合の差分:
  - 現契約 (コードから抽出): <現状の表示・操作>
  - 変更点: <追加 / 変更した表示・操作>
  - 後方互換: 保存済みの URL / localStorage が読めるか
```

## 観察可能な AC への落とし方

ロジックは vitest で、見た目と操作はブラウザでの確認手順で AC にする。ブラウザでしか判定できないものは `not-observable`（手動確認の手順つき）と明記し、黙って混ぜない。

| 契約 | 観察可能な AC |
|---|---|
| 単位の自動切替 | `formatAmount(99_999) が「99,999 円」、formatAmount(100_000) が「100 千円」`（整形関数の vitest） |
| キー操作の刻み | `スライダーの状態遷移関数に ArrowRight で +1 刻み、Shift+ArrowRight で +10 刻み`（DOM を持たない遷移関数の vitest） |
| 保存の後方互換 | `旧形式の URL 文字列（テストに固定）を読み込むと同じポジションになる` |
| CSP | `npm run build` 後、ci.yml の「ビルド成果物の検査」が ok |
| XSS | `grep -rnE 'innerHTML|outerHTML|insertAdjacentHTML' ui/` が 0 件（使うなら固定文字列だけで、理由をコメントに書く） |
| 画面幅・見た目 | `npm run dev` で幅 360px にし、<画面> で横スクロールが出ない（手動確認。手順を PR に書く） |
| 性能 | 計算部分は `tests/model/perf.test.ts` 相当のベンチ、描画はブラウザの Performance で 16 ms 以内（手動確認） |

**書いてはいけない AC**: 「見やすく表示される」「操作しやすい」。
