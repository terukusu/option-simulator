# ADR-0011: 余力の先物の項と追証の線を証券会社の計算式に合わせる

- 状態: 採択（2026-11-20）
- 日付: 2026-11-20
- 関連: #375、#131・#149・#150（[ADR-0002](adr-0002-margin-grid-approximation.md)）、`docs/design.md` 5.10・5.11・13.1 K14

## 背景

- オーナーが証券会社の公開している先物・オプションの余力の計算式を見せた: 余力 = 受入証拠金 − 必要委託証拠金 − 拘束金額。受入証拠金 = 証拠金差入金額 + 翌日受渡額（先物決済受渡代金 + OP プレミアム受渡代金）、拘束金額 = 先物建玉評価損 + 買 OP 購入代金 + 手数料等、必要委託証拠金 = 当社証拠金（注文含む）− 当社 NOV、維持証拠金 = 当社証拠金（建玉のみ）− 当社 NOV、追加証拠金 = 維持証拠金 − 受入証拠金（正のとき）
- simulator の余力 `A`（5.10）は生きている先物の評価損益を **益も損も** 足していた。計算式は評価損だけを拘束金額に入れる。先物の買い + OP の売りなどで、上げ側の余力を大きく見る（追証の線を遠く見る）= 保守寄りの方針に反する
- simulator は「余力 < 0 = 追証の目安」として、損益グラフの追証の線・テールの証拠金の表・追証マップ・過去の急落の再生を余力で引いている。計算式の追加証拠金（維持証拠金 − 受入証拠金）と余力 0 の関係を説明していなかった

## 調べたこと

- simulator の資金は建てる前の口座の現金で、余力は **建てて受渡の済んだ状態** の評価。支払・受取・手数料・SQ を過ぎた足の清算額は受入証拠金に入っている。拘束金額の買 OP 購入代金・手数料等は受渡前（約定日）の分と読め、受渡の済んだ状態では 0（受入証拠金と二重に引かない）
- 追証の判定（日中の引け）で先物の評価損が受入証拠金を減らすことは、他社の公開の説明の例（受入証拠金 = 差入 − 先物の評価損 < 維持証拠金 → 追証）と、JPX の規則の「計算上の損益額」（先物の利益と損失の差引額）で確かめた。計算式の追加証拠金の行に評価損が無いのは、受入証拠金が値洗いを含むためと読む
- 評価益を追証の判定で受入証拠金に数えるかは、公開の説明からは会社ごとに確かめられなかった

## 検討した選択肢

1. **余力の先物の項を評価損だけにし、追証の線は余力 0 の 1 本のまま**（採用）
2. 余力 0 の線と、計算式どおりの追加証拠金（拘束金額を引かない）の線の 2 本を出す: 受渡の済んだ状態では拘束金額は先物の評価損だけで、評価損を引かない追証の線は実際の追証（引けの値洗いで評価損が受入証拠金を減らす）より遠くに出る。保守寄りに反し、2 本の線の読み分けも重い
3. 評価益を数えるか（会社の扱い）を設定で切り替える: 確かめられない扱いのために設定を増やすより、保守寄りの 1 つにそろえる
4. 先物の評価損を足ごとに拾う（益と損を差し引かない）: より保守的だが、限月違いの買いと売り（カレンダー）で片側の損だけを引き、ほぼ打ち消し合うポジションに大きな追証の線を作る。JPX の計算上の損益額は差引額

## 決定

1. 余力 `A = 資金 − 支払 + 受取 − 手数料 + min(0, 生きている先物の足の評価損益の合計) + 決済済みの足の清算額 − 所要額 R_q`。評価損益は足どうしで差し引いた合計で、負のときだけ引く。SQ を過ぎた足の清算額は損益とも入れる（翌日受渡額）
2. 追証の線は余力 0 の 1 本のまま。受渡の済んだ状態で、受入証拠金 = 資金 − 支払 + 受取 − 手数料 + 清算額、必要委託証拠金 = 維持証拠金 = R_q（注文を持たない）、拘束金額 = 先物の評価損なので、**余力 < 0 ⇔ 追加証拠金 > 0**
3. 設定は足さない。実装は `model/margin.ts` の `marginRoom` の 1 か所（追証の線・テールの証拠金の表・追証マップ・過去の急落の再生・保有の一覧・建てられる倍数はこれを通る）。全項が枚数に 1 次同次のまま（`min(0, m·f) = m·min(0, f)`）なので、建てられる倍数の式は変わらない

## 結果

- 先物の足を含み、先物の評価損益の合計が正の状態の余力が今までより小さく出る。先物の買いでは、上げで所要額（`k × R × X × 乗数`）が増えても益で相殺しないので、上げ側にも追証の線が出うる
- **先物で OP をヘッジした形では、ヘッジが効く側の追証がかなり早く出る**（いちばん大きな変化）。例: put の売り + 先物の売りでは、下げで先物の益が put の損を打ち消していたのを余力に数えなくなる。合成の板の見本（`fixtures/synthetic/ai_tools.json` の「ミニ先物の売り 1 枚 + put の売り 1 枚」。架空の値）では、原資産 −5% の余力が 約 77 万円 → 約 43 万円、−10% で 約 −268 万円 → 約 −336 万円（ミニ先物の売りの評価益 約 34 万円・68 万円の分）、下の追証の線が 63,529 円 → 63,955 円に上がった。追証マップ・過去の急落の再生でも追証の側が広がる
- OP だけのポジションは変わらない
- 評価益を追証の判定に数える会社では、先物の益が出ている側の追証の線が実際より近く出る（保守寄りの側。5.10 の「JSCC の方式との違い」に注記）
