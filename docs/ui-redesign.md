# UI / UX 再設計（設計書）

option-simulator の画面を「書類」から「計器」に作り直すための設計書。計算（`model/`）・表示モデル（`ui/view/`）・状態と保存（`ui/state.ts`・`ui/persist.ts`・`ui/share.ts`・`ui/book.ts`）はそのまま使い、作り直すのは **見せ方と触り方の層**（`ui/components/`・`ui/style.css`・`ui/chart/` の一部）だけ。今ある機能はすべて残す（置き場所と出し方を変える）。

触れる試作品は [`ui-redesign/prototype.html`](ui-redesign/prototype.html)（単体の HTML。値はすべて架空）。撮影した画面は同じフォルダの `proto-*.png`。

- 読む人: オーナー（採否の判断）と実装者（Issue に分ける人）
- 数値・銘柄の例はすべて **架空の値**
- 用語: 「板」= 気配の一覧、「足」= ポジションの 1 本、「シナリオ点」= X₀ + ΔX、「BOX タブ」= 作業中のポジションのタブ

---

## 1. 設計の原則（このツールならではの芯）

オーナーの主な使い方は「シナリオ（経過日数・原資産・IV）を動かして **期中の損益** がどう変わるかを見る → 流れでポジションを少し直す」。だから画面の芯は次の 5 つにする。

| # | 原則 | 具体 |
|---|---|---|
| 1 | **損益の面を手で撫でる** | 損益グラフが舞台。シナリオの 3 軸（ΔX・d・Δσ）は欄に打つものではなく、グラフの **横（X）・下の帯（時間）・右の帯（IV）** を直接つかんで動かす。読み取りの数字はつかんだ瞬間に追従する |
| 2 | **常に見せる数字は少なく、大きく** | 画面に固定で出すのは「指定日の損益」「満期の損益」「Δ」の 3 つ（PC は Θ・V・受取も）。他はパネルを開く。文章で状態を説明しない（印・色・トースト） |
| 3 | **触る頻度で置き場所を決める** | 毎回触る（シナリオ・足の枚数・板の bid/ask）は手前、ときどき触る（プリセット・評価時刻・ヘッジ・ピン）は 1 タップ、ほぼ触らない（ATM 基準・β・sticky・basis・縦軸・単位・手数料・テーマ）は設定へ |
| 4 | **画面は 1 枚の長い紙ではなく、固定の舞台と引き出し** | ページはスクロールしない。スクロールするのはパネルの中だけ。スマホは上に舞台・下に引き出し（親指の届く位置に操作）。PC は 3 面（市場・舞台・作業台） |
| 5 | **因果が追える動き** | 離散の操作（プリセット・枚数 ±・タブ切替・足の追加）は線が 200ms で補間して動き、連続の操作（ドラッグ）は即時。追加・削除は「元に戻す」付きのトーストで知らせる |

「静かで精密」な見た目: 面は暗い無彩色、色は意味のある所（損益の符号・シナリオ線・つかむ所・bid/ask）にだけ使う。数字は等幅・タブ付き数字で桁が揺れない。

## 2. 画面の骨組み

幅で 3 段階。境は今と同じ（`PHONE_QUERY` = 719.98px、PC = 1200px）。どの段階でも **ページ全体はスクロールしない**（`body { overflow: hidden }`、高さ `100dvh`）。

### 2.1 共通の領域

| 領域 | 中身 | 備考 |
|---|---|---|
| **トップバー**（44 / 48px） | ブランド、**BOX タブ**（A 2 / B 1 / ＋）、**市場ピル**（● 板の時刻・鮮度タグ・F・ATM・先物）、[最新]、テーマ、⋯ | 市場ピルを押すとヘッダの詳細（限月ごとの F ±・A/B の候補・前提）がポップオーバーで出る。スマホはピルを「21:31」の短縮形に |
| **舞台（stage）** | 凡例行（線・ピン・モード）→ 描画域 + **IV レール**（右）→ **時間レール**（下）→ **読み取り（大きな数字）** | 常に見える。たたむ機能は「シートを全開にすると舞台がミニ（高さ 92px）になる」で置き換える |
| **シナリオ** | ステッパー 5 つ（d・ΔX・Δσ・Δs・β）・プリセット・評価時刻・「モデルの前提」の折りたたみ（sticky・basis・ΔX 単位） | PC・タブレットは舞台の直下に常設。スマホは引き出しの 1 枚 |
| **ポジション** | 足 1 本 1 行（売買・名前・建値 / 限月・IV・Δ・印 / 枚数ステッパー / ⇄ / ×）、行を押すと詳細、末尾に **デルタヘッジ** 1 行 | PC は右列の上。スマホ・タブレットは引き出し |
| **指標 · テール** | タイル 6 枚（最大利益・最大損失・BEP・受取 or 掛け金・指定日 + シナリオ・合計グリーク）+ テール表（バー付き） | PC は右列の下。スマホ・タブレットは引き出し |
| **板** | 限月セグメント・put/call セグメント・ジャンプのチップ行（横スクロール）・表（幅で 9 / 7 / 5 列）・脚注（F・ATM・SQ） | PC は左列（スマイルとセグメントで切替）。スマホ・タブレットは引き出し |
| **スマイル** | 軸セグメント・描画域・選択行（売り bid / 買い ask）・凡例 | 同上 |
| **ドック** | ポジ / 板 / シナリオ / 指標 / スマイル の 5 ボタン（ポジには足の本数のバッジ） | スマホは下端、タブレットは右列の上。PC には無い |

│ デルタヘッジ  現在 Δ … → ミニ −1 [追加] │

- シートは 3 状態: **隠す**（舞台が最大）/ **覗く**（42dvh）/ **全開**（舞台はミニ = 読み取り 3 つと線だけ 92px）。つまみを上下にドラッグ、またはタップで切替。ドックの同じボタンをもう一度押すと隠す
- 舞台の中はページをスクロールさせない（`touch-action: none`）。スクロールはシートの中だけ
- 板の表は 5 列（K・bid・ask・IV b/a・Δ）、put / call はセグメントで切替
- 読み取りは 3 つ（指定日の損益・満期・Δ）。Θ・V・受取はシートの指標で見る

### 2.3 タブレット（720〜1199px、例 900×1100）

```
┌───────────────────────┬──────────────────┐
│ 舞台（凡例・描画域・σ・時間・読み取り） │ ドック（ポジ 板 指標 スマイル）│
│                       │ 選んだパネル 1 枚   │
├───────────────────────┤                  │
│ シナリオ（常設）         │                  │
└───────────────────────┴──────────────────┘
```

- 2 列。左 = 舞台 + シナリオ（常設なのでドックに「シナリオ」は無い）、右 = ドックで切り替える 1 枚（ポジション / 板 / 指標 / スマイル）
- 読み取りは 5 つ（指定日・満期・Δ・Θ・V）。個数は舞台の幅のコンテナクエリで決める（< 480px で 3、480〜599px で 5、≥ 600px で 6。#82）

```

```

- 列の比: 市場 `minmax(340px, 30%)` / 舞台 `1fr` / 作業台 `minmax(360px, min(28%, 420px))`。1280 で舞台 ≈ 540px、1440 で ≈ 600px、1800 で ≈ 760px
- 板の列数は **板の枠の幅** で決める（≥ 540px で 9 列、≥ 410px で 7 列 = Δ 無し、未満は 5 列 + put/call セグメント）。1800px 以上で 9 列になる
- 舞台・シナリオはコンテナクエリで自分の幅に合わせる（読み取りの個数・ステッパーの列数・拡大ボタンの表示）。読み取りは舞台の幅 ≥ 600px で 6 つ（480〜599px は 5 つ、< 480px は 3 つ）
- ドックは無い。板 / スマイルは市場列のセグメントで切替。各列は独立にスクロール

## 4. 操作の仕様

### 4.1 損益グラフ（舞台の描画域）

| 操作 | マウス | タッチ | キー（描画域にフォーカス） |
|---|---|---|---|
| **シナリオ点 ΔX** | ハンドル（● とその縦線 ±14px）をつかんでドラッグ。離れた所は **長押し 450ms** でつかむ | 同じ（長押しで軽い振動） | ← → で ∓100 円、Shift で 1,000 円 |
| **IV Δσ** | 右の IV レールのつまみを上下にドラッグ。レールをダブルクリックで 0 | 同じ | ↑ ↓ で ±0.5pt |
| **経過日数 d** | 下の時間レールのつまみをドラッグ（1 日刻み）。目盛り（最終日 / SQ）をタップで **その時刻ぴったり** | 同じ | [ ] で ±1 日 |
| 面モードの点 | 描画域の上で押してそのままドラッグ（横 = ΔX、縦 = d を同時に） | 同じ | 同上 |
| パン | ドラッグ（長押し前に 6px 以上動かす）、横ホイール | 1 本指 | — |
| 拡大・縮小 | ホイール（カーソル中心）、[−][＋] | ピンチ（2 本指の下の値を保つ） | + − |
| リセット | ダブルクリック、[⟲] | ダブルタップ | R |
| シナリオを 0 に | プリセットの [リセット] | 同じ | 0 |
| 足を選ぶ | 横軸の足マーカー（▲ call / ▼ put、塗り = 買い、白抜き = 売り）をクリック → ポジションの行が開く | タップ | — |

- 長押し中は文字選択・コンテキストメニューを出さない（今と同じ）
- ドラッグ中は線の補間（§7）を切り、離したら戻す
- ΔX の範囲・刻み（10 円格子、−40%〜+20%）・d の範囲（0〜最遠の SQ）・Δσ（−10〜+40pt、0.5）は今のまま

**新しい画面（#82）の決め**（旧画面は今のまま）:

- ハンドルは ΔX = 0 でも X₀ の上にある。つかむ幅は ±14px（旧画面は ±12px のまま。`gesture.ts` の `GestureCtx.scrub.grabPx`、省略時は今の `GRAB_PX`）
- キー: ← → は ΔX（旧画面の `, .` `< >` と同じ刻み・範囲。← → でパンはしない）、↑ ↓ は Δσ ±0.5pt（`sliderSpec('dSigma')` の格子）、`[` `]` は d ±1 日（格子に乗せない。目盛りのタップで入った端数を保つ）、0 はシナリオを 0 に、+ − R は今のまま。解釈は `ui/view/stage.ts` の `stageKey`
- 操作の優先: (1) 足マーカーの当たり判定（横 ±8px・横軸の上 14px の帯）→ タップで足を選ぶ、長押し 450ms → 横に滑らせて行使価格を変える（板の OP の足だけ）、長押し前に 6px 動けばパン (2) ハンドル ±14px → ΔX を即つかむ (3) それ以外 → パン / 長押しで ΔX。マーカーのタップはダブルタップ（リセット）の 1 回目に数えない（マウスの dblclick もマーカーの上では無視）。マーカーのドラッグ中に 2 本目の指が来たら取り消す（確定しない）
- シートを全開にした舞台（92px）の描画域はミニ（線・塗り・0 の線・ハンドルの縦線だけ）で、操作を受けない
- IV レールの感度は 0.25pt / px まで。レールが短い（トラック < 200px）ときは押した位置に飛ばさず、縦の移動量で動かす（相対）
- 時間レールの現在値の吹き出しはつまみの下の文字の行に置き（描画域の目盛りの文字を隠さない）、重なる目盛りの文字は出さない
- 凡例行のピン（①②③ + 名前 + ×）は線の凡例より先に場所を取り、縮むのは名前だけ（名前は省略記号。× は 24px の当たりで常に押せ、右の道具（ピン・拡大縮小・⋯・ⓘ）は縮まない。ピンのメニューにも「① 名前 を外す」）。交点のラベルは線（満期・指定日・今日）・他のラベル・IV レールの吹き出しに重ならない位置へ上下にずらす（元の位置から ±45px に無ければ縦線の反対側、それでも無ければ描画域の高さまで広げる。`stageMarkLabels`）

### 4.2 ステッパー（シナリオ）

- [−][＋]: 1 刻み（d 1 日 / ΔX 0.5% または 100 円 / Δσ 0.5pt / Δs 0.5 / β 0.1）。長押しで連続
- **値の上を左右にドラッグ（スクラブ）**: 8px で 1 刻み。ホイールでも 1 刻み
- 値をダブルクリック / 長押しで数値入力（確定 Enter、Esc で戻す。範囲外は赤く、反映しない = 今の `parseSliderInput` の規則）
- Shift + ボタンで 10 刻み

### 4.3 板

### 5.1 折り返しの規則

1. **数値・ラベル付きの値・ボタンの文字・セグメント・チップは折り返さない**（`white-space: nowrap`）。入らないときは (a) 省略記号、(b) 副題を隠す、(c) ⋯ メニューへ退避、の順で対応する
2. 折り返してよいのは **説明文**（ⓘ の中・テール表の注記・空の状態の案内）だけ
3. 行の中で要素が入らないときは行を折らず、**横スクロール**（チップ行）か **列数の変更**（板・ステッパー）で対応する
4. 幅 360px でも横スクロールが出ないことを維持（試作品は 390 で `scrollWidth = 394`。4px は丸めの誤差で、実装では 0 にする）

### 5.2 数値の書式

今の `ui/view/format.ts`・`metrics.ts` の規則を変えない。見せ方だけ次を足す。

| 値 | 書式 | 例 |
|---|---|---|
| 金額 | 符号付き（+ / −（U+2212））、千円は小数 1 桁（10 万円未満）/ 整数、単位は値の横に小さく | `−617` `千円` |
| 損益の色 | 正 = `--gain`、負 = `--loss`、0 = 無色。**文字色だけに頼らず符号を必ず付ける** | |
| ΔX | 円と % を併記 | `−2,000 / −2.9%` |
| Δ | ラージ 2 桁（詳細は 3 桁）、括弧にミニ 1 桁 | `+0.32 (+3.2)` |
| Γ | 3 桁 /100円 | `−0.010` |
| IV | 1 桁、% は省く（板・スマイル・詳細） | `28.0` |
| 日付 | `MM/DD HH:mm（曜）`、年は板のポップオーバーだけ | `10/18 21:31（日）` |

## 11. 論点と決定（2026-10-16）

**進め方（方針 A、オーナー了承）**: 新しい画面は別の入口（`?ui=next`）で育て、全部そろったら既定に切り替えて旧 CSS を消す。今の画面はその間そのまま使える。

下の論点はオーナーの返事を待たずに **推奨の既定で進める**。どれも後から変えられるので、使ってみて直す。

| # | 論点 | 決定（既定） |
|---|---|---|
| 1 | 板の 9 列をどこまで守るか | **舞台を優先**。PC の板は 7 列（Δ 無し）/ 5 列（put / call 切替）、9 列は 1800px 以上 |
| 2 | 面モード（ヒートマップ）の色の向き・濃さ | **下が今日・上が満期**。濃さは損益の大きさ（絶対値の最大で正規化）、0 付近は透明 |
| 3 | 面の上で ΔX と d を同時にドラッグ | **入れる**（線モードは横だけのまま） |
| 4 | IV レールの向き・位置 | 設計の案のまま（上 = +40pt、右側） |
| 5 | 足マーカーのドラッグで行使価格を変える | **入れる**。長押しから始め、建値は新しい K の bid / ask（アンカー IV も）、[元に戻す] 付き |
| 6 | 読み取りの 3 つ（スマホ） | 設計の案のまま（指定日の損益・満期・Δ） |
| 7 | [たたむ] の廃止 | **廃止**。舞台の高さはシートの開き具合で決める。`pnlFolded` の保存は捨てる |
| 8 | 確認ダイアログの廃止 | **廃止**。×・タブを閉じる・全クリア・保存の上書きは即実行 + [元に戻す] 付きのトースト |
| 9 | 設定にしまうもの | 設計の案のまま。**β・sticky はシナリオ側**（「モデルの前提」として畳む） |
| 10 | PWA | まず **ホーム画面に追加とアイコンまで**。全画面（standalone）は iPhone で IAP のログインを試してから決める。オフラインの板は後回し |
