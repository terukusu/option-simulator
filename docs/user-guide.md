# option-simulator 利用者マニュアル

日経225オプション（ラージ）のポジションを **建てる前に** 検討するための損益シミュレーターです。最新の板（気配・IV）を読み込み、板から足を選んでポジションを組み、満期・指定日・今日の損益と、原資産・IV・時間を動かしたときの損益（シナリオ）を見ます。

- 計算はすべてブラウザの中で行います。スライダーを動かしても通信しません（通信するのは板を読むときだけ）
- 発注・約定の機能はありません。値はモデルによる **理論値** で、実際の約定・清算価格とは一致しません
- この文書の数値の例はすべて **架空の値** です

設計の詳細（式・判定の規則・決定の経緯）は [`design.md`](design.md) にあります。この文書では画面の使い方と、表示の読み方を説明します。

## 1. はじめに

### 開き方

デプロイ先の URL をブラウザで開きます（画面とタブのタイトルは「OP Simulator」）。IAP（Google アカウントのログイン）で守られているので、閲覧を許可された Google アカウントでログインします。開くと自動で 1 回だけ **最新の板** を読み込みます。

- パソコン・スマートフォンのどちらでも使えます。幅 360px（小さめのスマホ）でも横スクロールしない作りです
- 自動更新はしません。新しい板が欲しいときは [最新] を押します（[2 章](#2-板の読み込み)）

### 画面の構成

上から順に並びます。板の下（右）は「シミュレーター」（損益グラフ・シナリオ）と「詳細」（ポジション以下）に分かれ、画面の幅で 3 通りに並びます。

| 画面の幅 | 並び |
|---|---|
| スマホ（720px 未満） | 1 列: 板 → シミュレーター → 詳細 |
| タブレット（720〜1,199px） | 2 列: 左 = 板、右 = シミュレーター → 詳細 |
| PC（1,200px 以上） | 3 列: 左 = 板、中 = シミュレーター、右 = 詳細 |

損益グラフの **タブの帯・操作行・グラフ・読み取りの帯**（ドック）は、下へスクロールしても画面の上端に残ります（スマホ・タブレットでは詳細を見ている間も、PC ではシミュレーターの列ごと）。グラフが場所を取るときは [たたむ] で隠せます（[6 章](#6-損益グラフ)）。

| 場所 | 内容 |
|---|---|
| 上端の行 | [最新]・[ファイルを開く…]・表示中のデータ元・読み込みのエラー |
| ヘッダ | 板の時刻と遅れ・日経平均・先物・限月ごとの F と ATM・ATM の基準の切替・計算の前提 |
| 限月のタブ | 板・スマイルに出す限月（1 限月 / 2 限月）の切替 |
| 板 | 行使価格ごとの bid / ask・IV・Δ。bid / ask を押すと足が入る |
| シミュレーター | 損益グラフ（作業中のタブの帯・操作行・グラフ・読み取りの帯）→ 凡例（ピンがあればピンの一覧）→ シナリオ |
| 詳細 | ポジション → 指標・テール表 → スマイル → デルタヘッジ → 足の追加フォーム |

章の順（9 指標 / 10 スマイル / 11 ポジション）は画面の並びと違います。画面の並びは上の表のとおりです。

### ⓘ（説明の吹き出し）

計算の前提・操作の説明・単位の決まり方などの説明文は、ふだんは隠してあり、近くの **ⓘ** を押すと吹き出しで出ます。

- もう一度 ⓘ を押す・吹き出しの外を押す（タップする）・Esc で閉じます。外を押したときは、そこにあるボタンやグラフの操作もそのまま効きます
- 同時に開くのは 1 つだけです。別の ⓘ を押すと前の吹き出しは閉じます
- キーボードでは Tab で ⓘ に移り Enter / Space で開きます。Esc で閉じるとフォーカスは ⓘ に戻ります
- **値・警告・状態は吹き出しに入れず常に出します**（金利などの前提の値・評価時刻・金額の単位・損益グラフの縦軸の単位・カレンダーの期限切れ・「プレミアム 0 のため自動」など）

ⓘ の場所: ヘッダの「前提:」の行末、板の上の「板の使い方」、損益グラフの凡例の行末、シナリオの [basis 減衰] の横と評価時刻の行末、ポジション・テール表・手入力の OP の足の見出しの横、指標の「金額の単位」の行末、スマイルの凡例の行末。

### 最短の使い方

1. 開く（最新の板が入る）
2. 限月のタブを選び、板で売りたい行の **bid**（売り）/ 買いたい行の **ask**（買い）を押す
3. 損益グラフと指標を見る
4. シナリオのスライダー（日数・原資産・IV）を動かして、期中の損益を見る

### 作業の自動保存（この端末）

足・シナリオ・表示の設定は、**作業中のタブ（[6 章](#作業中のタブbox)）全部** を含めて、操作が止まってから約 0.5 秒で **このブラウザ（この端末）に自動で保存** され、再読み込み・タブを閉じた後に開き直すと元に戻ります。保存ボタンはありません。

| 保存されるもの | 保存されないもの |
|---|---|
| タブ（名前・並び・作業中のタブ）と各タブの足（建値・枚数・売買・IV の編集・印・手入力の足の F）、シナリオ（d・ΔX・Δσ・Δs・β・動き方）、ATM の基準・表示中の限月・板の種別と絞り込み・スマイルの軸・縦軸・指標の単位・手数料・先物の basis・デルタヘッジの設定・グラフをたたんだ状態 | 板（ただし最後に取れた板は別に残します。[2 章](#2-板の読み込み)）、グラフの拡大・スマイルの選択、足の詳細の開閉、入れかけの値 |

- 開き直すと topbar の下に「前回の作業を復元した（足 N 本。保存 日時、そのときの板 日時）。建値は保存時のまま」と出ます（[閉じる] で消せます）。タブが 2 個以上なら「（タブ N 個・作業中のタブの足 n 本。…）」です。保存が一部壊れていたときは、壊れたタブだけを捨てて「保存したタブ N 個を読めなかった。残りのタブ M 個を復元した」と出ます
- 前の版の画面で保存した作業（タブの無いころの保存）は、タブ「A」1 個として開きます
- **建値・枚数・売買・IV の編集は保存したときのまま** です。板の値で建て直しません。足の評価（IV・グリーク・損益）は、開いたときに読んだ新しい板で計算し直します。手入力の足の F（先物で代用したもの）や、板の先物と限月違いの先物の足の評価価格も、新しい板から求め直します
- 保存した足の限月が新しい板に無い（SQ を過ぎて限月が進んだなど）ときは、板の足は「板に無い限月」のエラーになり、グラフ・指標から外れます（[11 章](#11-ポジション)）。消すか、手入力の足として入れ直してください。手入力の足（板に無い限月で入れた足）は、その限月が板に入ったあとで限月の無い板（古いファイルなど）を読んでも、入れた F・暦の SQ で評価を続けます
- 保存はブラウザ・端末ごとです。別の PC・スマホとは共有しません。プライベートモード・Cookie のブロック・容量不足で保存できないときは「この端末に作業を保存できない」と 1 行出ます（画面はそのまま使えます。あとで保存できたら消えます）
- 同じブラウザでタブを 2 つ開いて両方で操作すると、**最後に操作したタブの内容が残ります**。別のタブが保存すると「別のタブで作業が保存された」と出ます。そのタブの内容を取り込むには再読み込みしてください。別のタブが新しい版の画面で保存したときは「別のタブが新しい版で作業を保存した」と出て、このタブは以後保存しません（新しい版の保存を上書きしないため）
- 保存した足を消すには [全クリア]（[11 章](#11-ポジション)）。全部の保存を消すには、ブラウザのサイトデータの削除（[19 章](#19-困ったとき)）
- 自動保存は **作業中のタブ（最大 6 個）** だけです。それより多くのポジションを名前を付けて残す・別の端末へ移すには **保存一覧**（[11 章](#保存一覧名前を付けて保存)）を使います。ポジション 1 つをすぐ別の端末（PC → スマホなど）で開くには **URL で渡す**（[6 章](#url-で渡す別の端末で開く)）

## 2. 板の読み込み

上端の行で板を読み込みます。

| 操作 | 内容 |
|---|---|
| **[最新]** | サーバー（API）から、いま使える最新の板を読み直す。読み込み中は押せない |
| **[ファイルを開く…]** | 手元にある板の JSON ファイル（形は `design.md` 7.1 の版 1）を開く |
| 「表示中: …」 | いま表示している板のデータ元（API・ファイル名） |

### 「使える最新の板」とは

板のデータは optionchan（JPX のページから毎分取り込むツール）が蓄積したもので、**約 15 分遅れ** です。サーバーは新しい順に板を調べ、気配が十分にそろった板だけを返します。そのため、時間帯によっては「いまの時刻の板」ではなく、少し前の板が表示されます。ヘッダのタグで理由がわかります（[3 章](#3-ヘッダ)）。

### 読み込みに失敗したとき

- エラーの種類ごとの文言が出ます。すでに板を表示していた場合は **前の板のまま** 表示を続け、「前の板のまま（取得 HH:MM）」と出ます。ポジションも消えません
- 板が 1 枚も無いときは、画面に「板を読めない。[最新] で読み直すか、板の JSON を選んでください。」と出ます
- **開いたときに読み込みに失敗して板が 1 枚も無いとき**（サーバーが止まっている・通信エラー・ログイン切れ）は、このブラウザに残っている **最後に取れた板** を表示します。ヘッダに **「古い板」** のタグと日付つきの取得時刻（`取得 2026-11-02 21:47（保存した板（API））`）、エラーの後ろに「保存した板を表示（取得 …）」が出ます。数日前の板のこともあるので、日付を確かめてください。[最新] で読み込めれば印は消えます
- 最後に取れた板は、[最新]（と本番で開いたとき）に読み込みに成功するたびに 1 枚だけ上書きで残します。[ファイルを開く…] で読んだ板は残しません
- 板を読み直しても、ポジションの足・シナリオは残り、新しい板で評価し直されます（建値は変わりません。手入力の足の F の代用・限月違いの先物の評価価格は新しい板から求め直します）。グラフの拡大・スマイルの選択は元に戻ります

## 3. ヘッダ

### 1 行目: 板の時刻と鮮度

例: `板 2026-11-02 21:31（約 15 分遅れ） [最新] 取得 21:47（API）`

| 表示 | 意味 |
|---|---|
| 板 日時 | 板（スナップショット）の時刻。JPX のページの時刻 |
| 約 N 分遅れ | データ元の遅れ |
| タグ | 板を選んだ理由。下の表 |
| 取得 HH:MM | ブラウザで読み込んだ時刻と、データ元 |
| データ元 | 板の JSON に入っている元（`bigquery` など） |

タグの意味:

| タグ | 意味 |
|---|---|
| **最新** | 直近の板（45 分以内・立会中）をそのまま表示 |
| **板寄せ前** | 寄り前のため、直前の立会の「板寄せ前の最後のスナップショット」を表示 |
| **引け後** | 引け後のため、その立会の「板寄せ前の最後のスナップショット」を表示 |
| **時間外** | 時間外・休業日、または取り込みの停止のため、最後に使えた板寄せ前のスナップショットを表示 |
| **古い板**（赤） | 読み込みに失敗したので、このブラウザに残っていた最後の板を表示（取得時刻は日付つき。[2 章](#2-板の読み込み)） |

「最新」以外のときは、次の行に理由の 1 文と表示している板の時刻が出ます。

### 2 行目: 日経平均と先物

- **日経平均**: 現物の値と時刻（夜間は止まっています）
- **先物**: 直近四半期限月のラージ先物の値・約定時刻・SQ 日

### ATM の基準

ATM（その限月で原資産に最も近い行使価格）を何で決めるかを選びます。板の ATM 行の強調・スマイルの ATM の縦線・moneyness の基準・ジャンプの基準が切り替わります。

| 選択 | 基準価格 | 特徴 |
|---|---|---|
| **B 合成先物（限月ごと）**（既定） | 限月ごとに、プットとコールの気配から求めた合成先物 F | 限月ごとに別の値。価格モデルの F と同じ。先物の限月交代で飛ばない |
| **A ラージ先物（直近四半期）** | 板のラージ先物の値 | 両限月で共通。SQ で先物の限月が変わると ATM が飛ぶ |

### 限月ごとの欄

限月（1 限月・2 限月）ごとに次を出します。

| 表示 | 意味 |
|---|---|
| 最終・SQ | 取引最終日と SQ 日 |
| F | その限月の原資産（Black-76 の F）。`67,810 ±15` のように不確かさ付き。タグで求め方: **合成先物** / **先物で代用** / **先物で代用（限月違い）** / **F なし** |
| A 先物 / B 合成先物 | 基準価格の候補 2 つと時刻。選択中の方が強調される。**A で代用**（B が決まらず A を使った）・**古い**（板の時刻より 30 分以上古い）のタグ |
| ATM（A / B） | 選択中の基準での ATM の行使価格。決まらなければ「ATM なし」 |

### 前提の行

計算の前提（金利・評価時刻・取引カレンダー）の値を 1 行で出します。取引カレンダーの期限を過ぎていると、警告が強調表示されます（SQ 日の計算が不確かになるため）。行末の ⓘ を押すと、それぞれの前提が何に使われるか（金利は割引とプット・コール・パリティ、評価時刻は残存期間の起点、取引カレンダーは SQ 日・取引最終日の休業日）の説明が出ます。

## 5. 板

### 列

幅が広いときは 9 列です。

| Δ | IV | C bid | C ask | **K** | P bid | P ask | IV | Δ |
|---|---|---|---|---|---|---|---|---|

- **K**（行使価格）は **降順**（上が高い行使価格）に並びます
- **IV** は `bid の IV / ask の IV`（%）。気配から逆算した値です
- **Δ** はスマイル（[10 章](#10-スマイル)）の IV で計算したデルタです
- ATM の行は強調されます

板の枠が狭いとき（スマホなど）は、選んだ種別（put / call）だけを **K・bid・ask・IV** の 4 列で出します。種別を切り替えても、枠の中央にあった行使価格の付近を保ちます。

### 足を入れる

- **bid を押す = 売り**、**ask を押す = 買い** の足（1 枚）がポジションに入ります。建値はその bid / ask です
- 気配が片側だけ・無い行（`—`）も押せます。その場合の建値の初期値は [11 章](#11-ポジション) を見てください
- 同じ足を何度押しても、別の足として追加されます（枚数はポジションで変えられます）
- この使い方と「Δ はスマイルの IV での値」は、板の上の「板の使い方 ⓘ」でも確かめられます

### ツール

| ボタン | 動き |
|---|---|
| **ATM へ戻る** | ATM の行を枠の中央に（ページはスクロールしない） |
| **put / call** | 対象の種別。下の OTM・|Δ| のジャンプと、狭い枠で出す表の種別に効く |
| **OTM 10% / 20% / 30% / 40%** | 基準価格から、その割合だけ OTM の行使価格へ移動（put なら下、call なら上） |
| **\|Δ\| 0.05 / 0.10 / 0.20 / 0.30** | 対象の種別で、デルタの絶対値がその値に最も近い行へ移動 |
| **ask ≤ 50 円** | 対象の種別の ask が 50 円以下の行だけに絞る（ファー OTM を探すとき）。もう一度押すと解除 |

ジャンプ先の行は一瞬強調されます。絞り込みで隠れている行へジャンプすると、絞り込みを外してから移動します。

### 行の印

| 印 | 意味 |
|---|---|
| **IV 不安定** | 価格が呼値 1 つ分動くだけで IV が大きく変わる行（価格の分解能から見て IV が 5pt 超ぶれる、または ask ≤ 5 円）。スマイルの節点から外している |
| **補間** / **外挿** | その行のスマイルの IV が、周りの節点からの補間 / 端からの外挿 |
| **気配なし** | その種別に bid・ask が無い |
| **JPX の IV 欠損** | JPX が IV を出していない |

## 6. 損益グラフ

横軸が **基準原資産 X**（円）、縦軸が **損益**（円。大きいときは千円）のグラフです。足を 1 本以上入れると表示されます。

### 線と印

| 線・印 | 意味 |
|---|---|
| **━ 満期（SQ）** | 全部の足を SQ で決済したときの損益（手数料込み） |
| **━ 指定日 + シナリオ** | シナリオ（経過日数 d・IV の変化）を当てたときの理論損益。d > 0 か Δσ・Δs ≠ 0 のときだけ描く |
| **┅ 今日** | 板の時刻のまま、IV を変えずに原資産だけ動かしたときの理論損益 |
| ● | 満期の線の折れ点（行使価格の位置） |
| ◆ | 満期の損益分岐点（BEP） |
| ┆ X₀ | いまの基準原資産 |
| ┆ シナリオ点 | X₀ + ΔX（シナリオの原資産）。ΔX ≠ 0 のとき |
| ┆ シナリオ ATM（紫の点線） | ΔX だけ動いた後の ATM の行使価格（表示中の限月）。ΔX ≠ 0 で、板の行使価格の範囲内のとき |

**シナリオ点の縦線と各線の交点** に点と金額のラベル（`満 +120,000` / `指 −45,000` / `今 −10,000` のように）が出ます。ΔX = 0 のときは X₀ の縦線の上に出ます。金額の単位は指標と同じです（グラフの縦軸の単位とは別）。交点が縦軸の範囲外なら、ラベルを端に寄せて ▲ / ▼ を付けます。

### 縦軸

| ボタン | 範囲 |
|---|---|
| **自動**（既定） | 表示中の線が収まる範囲 |
| **手動** | 下端・上端（円）を入れる。切り替えた時点の範囲から始まる |
| **±N 倍** | プレミアムの差引（受取 − 支払）の ±N 倍（N の既定 5）。小さいプレミアムの売りで、折れ点と BEP を見るとき。差引が 0 のときは自動になり、その旨が出る |

### 拡大・移動

- [−] [＋] [⟲]（縮小・拡大・リセット）のボタン
- ホイール・ピンチで拡大、ドラッグでパン、ダブルクリック / ダブルタップでリセット
- 詳しくは [14 章](#14-グラフの操作一覧)

### たたむ・上端に残る

- 操作行の右端の **[たたむ]** でグラフ（描画域）だけを隠し、操作行と読み取りの帯は残します。**[ひらく]** で戻ります。板を読み直しても、足を全部消しても、たたんだままです
- 操作行・グラフ・読み取りの帯（ドック）は、下へスクロールしても画面の上端に残ります。スマホ・タブレットではポジション・指標・スマイルを見ている間も残り、PC ではシミュレーターの列ごと残ります（列が画面より長いときは列の中でスクロールします）
- グラフの高さはスマホで 180px、それ以外は 260px（グラフの幅が 560px 未満なら 220px）。グラフの上ではページがスクロールしないので、グラフの外（操作行・帯・その下の欄）でスクロールしてください

### 作業中のタブ（BOX）

ドックの 1 行目（[自動][手動]… の操作行の上）のタブで、**作業中のポジションを最大 6 個** 持って切り替えられます。「ストラングル」と「アイアンコンドル」を同じシナリオで見比べる、元の案を残したまま足を変えてみる、といった使い方をします。

```
[A 2][B 1][C] [＋] [⋯]
```

（A・B・C = タブの名前、数字 = 足の本数。作業中のタブは塗りつぶし）

- **タブを押す** と、そのタブの足に切り替わります。足・建値・枚数・IV の編集は **タブごと** で、混ざりません
- **全タブで共通** のもの: 板・限月のタブ・ATM の基準・**シナリオ（d・ΔX・Δσ・Δs・β・動き方）**・手数料・先物の basis・縦軸・指標の単位・デルタヘッジの設定・たたむ・**グラフの横の表示範囲**。スライダーを動かしたまま A / B を往復すると、同じ条件で比べられます。指定日 d が足の短いタブの最遠の SQ を超えるときは、そのタブでは SQ に収めて描きます（凡例に注記）
- **[＋]**: 下に [空のタブ][このタブを複製][やめる] が出ます。新しいタブは作業中のタブの右隣にでき、名前は A〜Z の空いている文字です。6 個のときは押せません（「タブは 6 個まで」）
- **[⋯]**: 作業中のタブの操作です。名前の欄（12 字まで。Enter か [名前を変える] で確定。ほかのタブと同じ名前にはできません＝「同じ名前のタブがある」）、**[保存一覧に保存…]**（保存一覧を開きます。保存するのは作業中のタブ）、**[URL をコピー]**（作業中のタブを URL にします。[次の節](#url-で渡す別の端末で開く)）、**[閉じる]**（タブが 1 個のときは出ません。足があるときは「タブ B（足 3 本）を閉じる。保存一覧に無い内容は消える」と確認が出ます）。閉じると右隣（無ければ左隣）のタブに移ります
- キーボード: タブにフォーカスがあるとき **← / →** で隣のタブ（端では反対の端へ）、**Home / End** で先頭 / 最後のタブに切り替わります
- 板を読み直すと、作業中のタブの足の評価は新しい板で計算し直します。ほかのタブは、切り替えたときに今の板で計算し直します（建値はそのまま）
- 狭い画面では長い名前は「…」で省略します（全文は PC ではマウスを重ねると出ます。[⋯] の名前の欄でも見られます）

### URL で渡す（別の端末で開く）

作業中のタブ 1 つ（足・建値・枚数・売買・IV の編集・タブの名前）を **URL** にして、別の端末（PC → スマホなど）やメモに渡せます。サーバーには何も保存しません（ポジションは URL の `#` より後ろに入り、サーバーには送られません）。

1. 渡したいタブを作業中にして、[⋯] → **[URL をコピー]** を押します（足が 0 本のときは押せません）。「コピーした（N 字）」と出たら、メッセンジャー・メールなどに貼り付けます
2. 受け取った側でその URL を開くと、作業中のタブが **空ならそのタブに**、**足があれば新しいタブに** 開きます（作業中の内容は置き換えません）。topbar の下に「URL のポジションを新しいタブで開いた（足 N 本。共有 日時、そのときの板 日時）。建値は共有時のまま。…」と出ます。タブの名前は渡した側の名前です（同じ名前のタブがあれば A〜Z の空いている文字）
3. タブが 6 個あるときは、その行に「タブは 6 個まで。URL のポジション（足 N 本）を開くと作業中のタブ X（足 n 本）が置き換わる（保存一覧に無い内容は消える）」と出ます。[置き換える] か [やめる] を選びます（置き換えたくなければ、先にタブを閉じてから URL をもう一度開きます）

- 開いたあとはアドレス欄の `#` から後ろが消えます（再読み込みしても二重に開きません。開いたタブは自動保存されます）
- **建値は共有したときのまま** です。評価は開いた端末で読んだ今の板で計算し直します（保存一覧の [開く] と同じ。限月が今の板に無い板の足はエラーの行になります）
- URL から開くのは **足と名前だけ** です。**シナリオ・手数料・先物の basis・表示の設定**（限月のタブ・ATM の基準・縦軸など）は **開いた端末のまま** で、ほかのタブの評価も変わりません（渡した側のシナリオで見たいときは、受け取った側で同じ値に合わせます）。保存一覧の [開く] / [新しいタブで開く] は従来どおりシナリオ・手数料・basis も保存した値になります
- URL の長さの目安: 足 3 本で約 800 字、10 本で約 1,000 字、50 本で約 1,600 字。**2,000 字を超える** と「長い URL… アプリによっては途中で切れる」と注意が出ます（メールの折り返しなどで切れることがあります）。**8,000 字を超える**（足がとても多い）ときは URL にできません。保存一覧の [書き出し] でファイルにして渡してください
- コピーできない（ブラウザがクリップボードを許可しない）ときは「コピーできない。下の欄を選んでコピーする」と出て、URL の入った欄が選択された状態で出ます。そこからコピーしてください
- URL の中身は **暗号化していません**。URL を渡した相手（と、そのメッセンジャーの履歴・ブラウザの履歴）からポジションが読めます。見せたくない相手には渡さないでください
- 古いブラウザ（iOS 16.4 より前の Safari など）では URL を作れず、開けません（「このブラウザでは…」と出ます）

### ピン留め（線を重ねて比べる）

損益グラフに、ほかの線を **最大 3 本** 重ねて比べられます（**ピン**）。ピンは 2 種類です。

| 種類 | 何を比べるか | 線の値 |
|---|---|---|
| **固定**（ゴースト）| 今の線を残して、足やシナリオを **変える前** と比べる（「足を 1 本足したら」「IV が +5pt なら」） | 残したときの値のまま。あとで足・シナリオ・手数料を変えても、板を読み直しても、タブを切り替えても **動きません** |
| **タブ** / **保存**（重ね）| 別のタブ・保存一覧の項目を、**今の板・今のシナリオ・今の設定** で同じ条件で比べる（案を並べる） | スライダーを動かすと **一緒に動きます**（シナリオは全タブ共通） |

1. 操作行の **[ピン N/3]**（N = 今のピンの本数）を押すと、操作行の下に 1 行が出ます
2. **[今の線を残す]**: 今の期中の線（指定日 + シナリオの線。シナリオが 0 なら今日の線）を **固定** のピン ① で残します
3. **[B を重ねる]**: 作業中以外のタブごとに出ます。そのタブの足を今の条件で重ねます（足 0 本のタブ・重ね済みのタブは押せません）
4. 保存一覧の行の **[重ねる]**（[11 章](#保存一覧名前を付けて保存)）: その項目の足（重ねた時点の写し）を今の条件で重ねます。一覧は閉じます
5. **[期中][満期]**: ピンの線を期中の線か満期の線に切り替えます（全部のピンで共通。既定は期中）。最大損失を比べるときは満期にします
6. [閉じる] か Esc で行を閉じます（ピンは残ります）

- 線は今の線の **下** に、色・**線種**（① 破線・② 点線・③ 一点鎖線）と、線の右端の **番号 ①②③** で区別します（色が見分けにくくても線種と番号で分かります）。線の値が縦軸の外なら番号に ↑ / ↓ が付きます
- 凡例の下に **ピンの一覧** が出ます。1 本 1 行に「線種の見本・番号・種類（固定 / タブ / 保存）・名前・条件・満期の最大損失・受取 / 掛け金・シナリオ点（X₀ + ΔX でのピンの線の損益）・[外す]」。金額は指標の単位です。[全部外す] でまとめて消せます
- 固定の条件は「板 21:31 時点・d 5 日・Δσ +2.0pt・Δs 0.0・期中 = 指定日」の形（残したときの板の時刻とシナリオ）、重ねは「足 3 本・今の板・今のシナリオ」（保存は「…・今の設定」= 手数料・先物の basis も今の値で、保存一覧の要約（項目の手数料）とは違います）
- 重ねたタブに切り替えると、そのピンは「作業中（線は今の線）」になり線を描きません（同じ線を二重に描かない）。戻すとまた描きます。そのタブを閉じるとピンも外れます
- 今の板で評価できない足（限月が板に無い足など）は除いて描き、「一部の足を除く（N 本）」と出ます
- 縦軸が **自動** のときはピンの線も範囲に入ります（手動・±N 倍は変わりません）。パン・ズームしても表示範囲の全体に描きます（ズームしている間は少し粗く描き、止まるとすぐ細かく描き直します）
- 3 本あるときは追加のボタンが押せず、「ピンは 3 本まで（外すと追加できる）」と出ます。[外す] で 1 本ずつ外すと、空いた番号を次のピンが使います（ほかのピンの番号は変わりません）
- **ピンは保存しません**。再読み込み・別の端末では消えます（作業の自動保存・保存一覧・URL には入りません）。残したい案は保存一覧に保存して、あとで [重ねる] で重ね直してください
- 作業中のタブの足が 0 本のときはグラフが空なので、ピンの線も描きません（一覧には残ります）

### 長押しでシナリオ点を動かす

グラフの上で **長押し**（約 0.45 秒、ほぼ動かさずに）すると「つかむ」状態になり、押した位置がシナリオ点（原資産 X₀ + ΔX）になります。離さずに左右へ動かすと縦線が付いてきて、交点の金額・読み取りの帯・シナリオの ΔX が同時に変わります。

- 離しても ΔX はそのまま残ります
- いま出ているシナリオ点の縦線の近く（左右 12px）を押すと、待たずにすぐつかめます（マウスを載せると左右矢印のカーソルになります）
- ΔX は 10 円単位で、−40%〜+20% の範囲に収まります
- 長押しの前に指を動かすとパン（表示の移動）になります
- 画面の端に寄せても自動ではスクロールしません。一度離してパンしてから、つかみ直してください

### 凡例の注記

縦軸の目盛りは数字だけで、単位（円 / 千円）は凡例の行の ⓘ の前に「縦軸 千円」の形で常に出ます（表示範囲が 10 万円以上なら千円）。

凡例の行末の ⓘ を押すと、線の前提（指定日の線のシナリオ値・β・IV の動き方）と、縦線上の「満 / 指 / 今」の金額の単位（指標の単位）・長押しの操作の説明が出ます。

次の注意は吹き出しに入れず、凡例の下に常に出ます。

- 「プレミアム 0 のため自動」: ±N 倍を選んだが基準が 0
- 「指定日 d を最遠の足の SQ（N 日）に収めて描いた」: d が足の満期を越えている

## 7. 読み取りの帯

損益グラフのすぐ下の帯に、**シナリオ点の値** をまとめて出します。

| 行 | 内容 |
|---|---|
| 1 行目 | シナリオ点の原資産 X（ΔX の円と %）・経過日数 d |
| 2 行目 | 損益: 指定日 + シナリオ / 満期 / 今日 |
| 3 行目 | 合計グリーク: Δ（ラージ換算の枚数、括弧にミニ換算）・Γ（100 円あたり）・Θ（1 日あたり）・V（IV 1pt あたり） |

帯は損益グラフの操作行・グラフとともに画面の上端に残ります（スライダーを動かしながら値を見られます。残る範囲は [6 章](#たたむ上端に残る)）。グラフを [たたむ] と、操作行と帯だけが残ります。

## 8. シナリオ

「もし原資産・IV・時間がこう動いたら」を設定します。値はすぐに損益グラフ・読み取りの帯・指標・テール表に反映されます。

### スライダー

各スライダーは、つまみ・数値欄のどちらでも入れられます。

| スライダー | 意味 | 範囲・刻み |
|---|---|---|
| **経過日数 d**（日） | 板の時刻から何日たったか（暦日。小数可） | 0〜最遠の足の SQ まで、1 日 |
| **原資産 ΔX**（% または円） | 基準原資産 X₀ からの変化 | −40%〜+20%。% は 0.5% 刻み、円は 100 円刻み |
| **IV 平行移動 Δσ**（pt） | すべての行使価格の IV に足す | −10〜+40pt、0.5pt |
| **スキュー Δs**（pt / 10%） | moneyness 10% あたりの IV の傾きの変化。正で put 側の IV が上がり、call 側が下がる | −5〜+5、0.5 |

スライダーにフォーカスがあるときのキー: ← → で 1 刻み、Shift + ← → で 10 刻み、R で既定値（0）、+ / − で損益グラフの拡大・縮小（画面では評価時刻の行末の ⓘ に出ます）。

### プリセットとリセット

| ボタン | 設定する値 |
|---|---|
| **−10% / +20pt / +3** | ΔX −10%、Δσ +20pt、Δs +3（急落） |
| **−5% / +8pt / +1** | ΔX −5%、Δσ +8pt、Δs +1 |
| **反発 +5% / −5pt / −1** | ΔX +5%、Δσ −5pt、Δs −1 |
| **シナリオをリセット** | すべて既定（0、β 1.0、sticky strike）に戻す |

プリセットは 3 つのスライダーを同時に動かすだけです。d・β・IV の動き方は変えません。設定後も自由に編集できます。

### 設定行

| 設定 | 意味 |
|---|---|
| **ΔX % / ΔX 円** | ΔX の入力の単位 |
| **β**（pt / 1%）既定 1.0 | **原資産と IV の連動**。原資産が 1% 下がるごとに IV を β pt 上げる（上がれば下げる）。0 で連動なし。グラフの横軸の各点・テール表の各行で、その点の下落率で効く |
| **sticky strike**（既定） | 原資産が動いても、行使価格ごとの IV は変えない |
| **sticky moneyness** | スマイルが原資産と一緒に動く。put スキューの上では、原資産が下がると **同じ行使価格の IV は下がる** 向きに動く（急落時の IV 上昇は β と Δσ で表す） |
| **basis 固定**（既定） / **basis 減衰** | 先物の足の評価で、先物と基準原資産の差（basis）を一定にするか、先物の SQ に向けて 0 へ線形に減らすか。先物の足が無い・オプションと同じ限月の先物だけなら差は出ない。説明は横の ⓘ にも出ます |

Δσ はプリセットでも β とは **別に足し算** されます。たとえば β = 1 で「−10% / +20pt / +3」を当てると、ATM の IV は +10pt（β）+20pt（Δσ）= +30pt 上がります。

### 評価時刻のボタン

| ボタン | d を設定する先 |
|---|---|
| **SQ 日 9:00** | 対象の限月の SQ 日 9:00 |
| **取引最終日 15:45** | 対象の限月の取引最終日の日中の引け |

「対象」は足の限月から選べます（既定は SQ が最も近い限月。限月が 1 つなら選択欄は出ません）。ボタンの下に、いまの評価時刻（板の時刻 + d）が常に出ます。

## 9. 指標とテール表

### 単位と手数料

| 設定 | 内容 |
|---|---|
| **自動 / 円 / 千円** | 金額の単位。自動は「受取 + 支払が 10 万円以上なら千円」（画面では「金額の単位: 千円（自動）」の行末の ⓘ に出ます） |
| **手数料（円 / 枚）** | 1 枚あたりの手数料（0〜100,000、既定 0）。損益グラフ・指標・テール表に効く |

単位は金額（損益・プレミアム・Θ・V など）にだけ効き、Δ・Γ には効きません。

### 指標

| 項目 | 意味 |
|---|---|
| **満期 最大利益** | 満期の損益の最大。片側で無限に増えるときは「call 側 ∞ / put 側 …」と両側を出す |
| **満期 最大損失** | 満期の損益の最小。call の売り越しで上に無限なら「call 側 −∞ / put 側 …（X = …）」。put 側は原資産 0（SQ = 下端）までで有限 |
| **満期 BEP** | 満期の損益分岐点（1 円単位）。無ければ「なし」 |
| **指定日 + シナリオ** | シナリオ点の理論損益と、その条件での BEP |
| **合計グリーク（シナリオ点）** | Δ（ラージ換算の枚数、括弧にミニ）・Γ / 100 円・Θ / 日・V / pt |
| **受取 / 支払** | 受け取るプレミアムと支払うプレミアム。差引と、手数料込みの差引・手数料の合計 |
| **掛け金**（支払超のときだけ） | 支払 − 受取 + 手数料。「利益が掛け金の 1 / 5 / 10 倍になる原資産（満期）」も出す |
| **スプレッドコスト** | 建値と mid の差の合計（気配の幅で負担しているコスト） |
| **建値ずれ** | 建値がモデルの理論価格と合わない分の影響（[11 章](#11-ポジション)） |

**足別（シナリオ点）** を開くと、足ごとの IV・Δ・Γ・Θ・V と状態の印（満期直前 / 満期 / 先物は SQ 済み / F なし）が見られます。

指定日 + シナリオの BEP は、全域を細かく区切って探しています。とても近い 2 つの BEP（細いバタフライの頂点付近など）は取りこぼすことがあるので、グラフでも確かめてください。

### テール表

原資産が **−5% / −10% / −20% / −30% / −40%** 動いたときの損益を、2 つの評価で並べます。

| 列 | 評価 |
|---|---|
| **SQ** | その原資産で満期決済したときの損益 |
| **指定日 + シナリオ** | d・Δσ・Δs・β・IV の動き方はシナリオのまま、原資産だけを各行の値にして評価した損益（β は各行の下落率で IV を上げる） |

「指定日 + シナリオ」の列の計算方法は、見出し「テール表」の横の ⓘ にも出ます。表の上の 1 行（損益の単位と倍率の基準額）は常に出ます。

各セルの下段の **×N** は、損益の大きさがプレミアムの何倍かです。基準は受取超なら「受取 − 支払」、支払超なら掛け金です。売りの戦略では、「最大損失 ∞」よりも、期中の評価損とこの倍率を見るのが実用的です。損失のセルは色が変わります。

## 10. スマイル

表示中の限月の IV のスマイル（縦軸 IV %）です。

### 横軸の切替

| 軸 | 内容 |
|---|---|
| **行使価格**（既定） | K |
| **moneyness** | K / 基準価格 − 1（ATM の基準の選択に従う） |
| **デルタ** | put 換算のデルタ（0〜1） |

### 点と線

| 表示 | 意味 |
|---|---|
| ● mid / ● bid / ● ask | 各行使価格の IV（OTM 側の気配から） |
| ─ 実線 | 節点（使える行）の間 |
| ┄ 点線 | 補間・外挿の区間 |
| × | IV 不安定の行（節点から外した行） |
| │ ATM | 市場の ATM（選択中の基準） |
| ┆ シナリオ ATM | ΔX だけ動いた後の ATM（ΔX ≠ 0 のとき） |

スマイルは OTM 側（基準価格より下は put、上は call）の行から作ります。端の外は、裁定が起きない傾きに抑えて外挿しています。

### スマイルから足を入れる

点（× を含む）を **タップ / クリック** すると、最寄りの行使価格が選ばれ、スマイルの下に操作行が出ます。

`K 64,000 put: [売り（bid 28）] [買い（ask 38）] [×]`

板の bid / ask を押したときと同じ規則で足が入ります（OTM 側の種別。建値は売り = bid、買い = ask）。選択中の点をもう一度タップする・点から離れた所をタップする・[×] を押すと、選択を消します。限月の切替・板の読み直しでも選択は消えます。

**長押しして左右にドラッグ** すると、選択を連続して切り替えられます。グラフを長押し（約 0.45 秒、ほぼ動かさずに）すると押した位置に最も近い点が選ばれ、離さずに左右へ動かすと、指の位置に最も近い点（表示範囲の中）へ選択と縦線が付いてきます。操作行もそのつど切り替わり、離した時点の選択が残ります（もう一度タップで解除）。キーでは `,` / `.` で 1 本、`<` / `>` で 5 本、選択を左右へ動かせます（選択が無い・表示範囲の外なら、最初のキーで ATM を選ぶ。ATM が見えていなければ中央の点）。

拡大・パン・リセットの操作は損益グラフと同じです（長押しは、損益グラフではシナリオ点、スマイルでは選択の切り替え）。点の選択の操作は、スマイルの凡例の行末の ⓘ にも出ます。

## 11. ポジション

入れた足の一覧です。追加した順に、**足 1 本を 1 行** で並べます。行を押すと、その足の詳細が開きます（もう一度押すと閉じます）。幅（スマホ・タブレット・PC）によらず同じ形です。

見出し「ポジション」の横の ⓘ に、グリークの前提（シナリオ 0 = 評価時刻は板の時刻、X は基準価格）と建値ずれの意味（シナリオ 0 の理論損益への影響、手数料は含めない）が出ます。

### 1 行の表示

例（値は架空）:

```
▸ 売 P 64,000 ×1 @810  2026-11  [手入力]        [−][＋][売⇄買][×]
▸ ミニ先物 2026-12 買 ×1 @67,880                [−][＋][売⇄買][×]
```

| 部分 | 内容 |
|---|---|
| 売 / 買 | 売買 |
| P / C と行使価格 | オプションの種別と行使価格（先物は商品と限月） |
| ×N | 枚数 |
| @建値 | 建値（小数は小数第 2 位まで出します） |
| 限月（OP のみ） | 小さく添えます（限月の違う足を見分けるため） |
| 小さい印 | 手入力・気配なし・IV 不安定・外挿・補間・F 代用・建値手入力・価格なし・IV 編集・休業日未確定・エラー（[15 章](#15-印タグの意味)。全文は詳細に出ます）。警告のある足は枠が警告色になります |

### ボタン

| ボタン | 動作 |
|---|---|
| **[−] / [＋]** | 枚数を 1 減らす / 増やす。枚数は 1〜100,000 で、1 枚のとき [−]、100,000 枚のとき [＋] は押せません |
| **[売⇄買]** | 売買だけを切り替えます。**建値・IV の編集は変わりません**（反対側の気配に建て直しません）。必要なら詳細で建値を直してください |
| **[×]** | その足を消す |

[全クリア]（見出しの横）で全部の足を消します。足は自動で保存しているので、全クリアした後に再読み込みしても足は戻りません（シナリオ・設定は残ります。[1 章](#作業の自動保存この端末)）。

### 詳細（行を押すと開く）

| 項目 | 内容 |
|---|---|
| 商品・限月 | ラージ OP / ラージ先物 / ミニ先物 / マイクロ先物、限月、種別と行使価格 |
| 売買 | 買い / 売り（切り替えは [売⇄買]） |
| **枚数** | 1〜100,000 の整数。大きい枚数はここに直接入れます |
| **建値** | 0 以上 1,000,000,000 以下。板から入れた足は押した bid / ask が初期値 |
| **IV %** | その足の IV（下の「アンカー IV」）。編集すると「編集」の印。板の足は空欄にすると編集を取り消す |
| Δ ラージ（ミニ）・Γ / 100 円・Θ 円 / 日・V 円 / pt | 足ごとのグリーク（シナリオ 0 = 板の時刻・基準価格での値） |
| **建値ずれ 円** | 建値がモデルで説明できない分の、損益への影響（下記） |
| **SQ 日** | その足の SQ 日。カレンダーの範囲外なら「休業日未確定」 |
| **印** | 気配なし・IV 不安定・補間 / 外挿などの全文。警告・エラーの文もここ（印が無ければ出ません） |

数値欄は、入力を確定（Enter・フォーカスを外す）したときに検証され、範囲外なら反映せずにエラーを出します。確定前に行を閉じると、入れかけの値とエラーは消えます（確定済みの値は残ります）。足を消したり追加したりしても、ほかの足の開閉は変わりません。開閉の状態は保存されません。

### 保存一覧（名前を付けて保存）

見出し「ポジション」の行か、画面上部の読み込みの行（[最新] の並び）の **[保存一覧（N）]**（N = 保存した件数）を押すと、「保存したポジション」の画面（ダイアログ）が開きます。作業中のポジションに名前を付けて **この端末（ブラウザ）** に残し、一覧から開き直せます。[閉じる] か Esc で閉じます（ⓘ の説明を開いているときの Esc は、説明だけを閉じます）。

板が 1 枚も無い（読み込みに失敗し、保存した板も無い）ときも、上部の [保存一覧（N）] から開けます。書き出し・読み込み・名前の変更・削除はできますが、[開く] は板を読んでからです（足の市場を板から作るため）。

```
保存したポジション ⓘ                                      [閉じる]
名前 [2026-11 売P64,000 売C70,500          ] [保存]
[書き出し] [読み込み…]  2 件・約 2.4 千字
評価損益・最大損失・Δ は今の板（2026-10-13 21:31）で計算。金額の単位: 千円
┌ 11月 ストラングル  [作業中]
│ 2026-11・足 2 本  受取 1,620  満期の最大損失 −∞  Δ −0.12  評価損益 −22.6
│ 保存 2026-10-16 12:00・保存時の板 2026-10-13 21:31
│ [開く] [新しいタブで開く] [重ねる] [上書き] [複製] [名前] [削除]
└
```

（値は架空）

- **[保存]**: **作業中のタブ**（名前の欄の横に「作業中のタブ B」）の足・シナリオ・設定を、入れた名前で一覧の先頭に足します。ほかのタブは保存しません。名前の欄には足から作った名前（限月と先頭 3 本。例 `2026-11 売P64,000 売C70,500`）が入っています。名前は 40 字まで（改行などの制御文字は除きます）。同じ名前も付けられます。足が 0 本のときは保存できません
- **一覧の 1 行**:

| 部分 | 内容 |
|---|---|
| 名前・タグ | 「作業中」= 今の作業と同じ内容（足・シナリオ・手数料・先物の basis）。「板に無い足 N」= 限月が今の板に無い板の足（開くとエラーの行になる） |
| 限月・足 N 本 | 足の限月（3 つ以上は「ほか N」） |
| 受取 / 掛け金 | 建値 × 枚数 × 乗数。受取超なら受取 − 支払、支払超なら掛け金 = 支払 − 受取 + 手数料（指標と同じ） |
| 満期の最大損失・Δ | **今の板** で計算した値（Δ は画面の「今日」の Δ と同じ、ラージ換算） |
| **評価損益** | 保存した建値のまま、**今の板の mid**（両側の気配が無ければスマイルの理論価格）で評価した損益から、その項目の手数料（1 枚あたり × 枚数）を引いたもの。建てた直後なら −スプレッドコスト − 手数料 になります。理論価格を使った足があれば「理論値を含む」。今の板で値の無い足（板に無い限月など）が 1 本でもあると「—」（一部の足だけの合計は出しません） |
| 保存・保存時の板 | 保存（上書き）した日時と、そのときの板の時刻 |

- **[開く]**: その項目の足で **作業中のタブ** を置き換え、シナリオ・**手数料・先物の basis** も項目の値にします（シナリオ・手数料・basis は全タブ共通なので、ほかのタブの評価も変わります。表示の設定 = 限月のタブ・ATM の基準・縦軸・単位・ヘッジは今のまま）。建値は保存したときのままで、評価は今の板で計算し直します（[1 章](#作業の自動保存この端末) と同じ）。作業中のタブの内容が保存一覧に無い（「作業中」の項目が無い）ときは、行の中に「作業中のタブ B の足 N 本は保存一覧に無い。「名前」を開くとこのタブが置き換わる（残すなら [新しいタブで開く]）」と確認が出ます
- **[新しいタブで開く]**: 作業中のタブを残したまま、右隣に新しいタブを作ってその項目を開きます（確認なし。シナリオ・手数料・basis は [開く] と同じく項目の値になります）。タブが 6 個のときは押せません（押した時点で 6 個なら、一覧は閉じずに「タブは 6 個まで」と出ます）
- **[重ねる]**: その項目の足を、損益グラフに **ピン**（今の板・今のシナリオ・今の設定で描く線）として重ねます（[6 章](#ピン留め線を重ねて比べる)）。一覧は閉じます。重ねた時点の足の写しなので、あとで項目を上書き・削除しても線は変わりません。板が無い・ピンが 3 本のときは押せません
- **[上書き]**: 作業中のタブの内容でその項目を置き換えます（確認あり。名前・並びは変わりません）
- **[複製]**: 「名前 (コピー)」をすぐ下に作ります
- **[名前]**: 名前の欄になります。Enter か [決定] で確定、Esc か [やめる] で戻します
- **[削除]**: 確認のあとで消します
- **[書き出し]**: 保存一覧の全部を JSON のファイル（`option-simulator-positions-日付-時刻.json`）に保存します。別の端末・ブラウザへ移すときや、控えに使います
- **[読み込み…]**: 書き出したファイル（または作業 1 つの JSON）を選ぶと、読める項目を一覧の先頭に **追加** します（今の項目は消しません）。同じ名前があれば「(2)」を付けます。壊れたファイル・新しい版の画面で書き出したファイルは「読めない」と出て、何も変わりません。2 MB まで
- 保存は **100 件・約 100 万字まで** です。超える保存・複製・読み込みは断ります（不要な項目を削除するか、書き出して整理してください）。8 割を超えると「残りが少ない」と出ます
- 別のタブで保存一覧を変えると、こちらの件数・一覧も読み直します

### アンカー IV（足の IV）の考え方

- 足を入れたときの **建値から逆算した IV** をその足の IV にします。そのため、シナリオ 0（d・ΔX・Δσ・Δs が 0、sticky strike）では、足の理論価格は **必ず建値に戻り**、損益は 0（手数料を除く）になります
- 原資産が動いたときは、足の IV を「スマイルの形に沿って」相対的に動かします
- 建値が本源的価値以下（ITM の bid など）で IV が逆算できないときは、スマイルの IV を使い、建値と理論価格の差を **建値ずれ** として別に出します
- 気配が片側だけ・無い行から入れた足は、建値の初期値が「ask − 呼値 1 つ」（ask も無ければスマイルの理論価格）になり、「気配なし」の印が付きます。建値を確かめて、必要なら直してください

## 12. デルタヘッジ

ポジションのデルタを先物で目標値に合わせるための枚数を出します。足が 0 本でも表示されます。

| 設定 | 内容 |
|---|---|
| **目標 Δ（ラージ換算）** | 合わせたいデルタ（既定 0。−1,000〜1,000） |
| **シナリオ適用前**（既定） / **シナリオ時点** | どの点のデルタを使うか。適用前 = ポジション一覧と同じ点、シナリオ時点 = シナリオ点（読み取りの帯と同じ点） |
| **限月** | ヘッジに使う先物の限月（板の先物と、板の OP の限月から選ぶ） |

表示:

- **現在 Δ**: ラージ換算の枚数 = ミニ換算の枚数
- **ミニ ±N 枚（残り ±r）[追加]**: ミニ先物で必要な枚数と、追加した後に残るデルタ（ラージ換算）
- **ラージ ±M 枚（残り ±r）[追加]**: ラージ先物の場合
- ミニで 0 枚に丸まるときは、マイクロ換算の枚数を注記で出します（マイクロは足の追加フォームから入れます）

[追加] を押すと、その先物の足（売買は符号、建値は板の先物の値）がポジションに入ります。足・シナリオ・目標が変わるたびに枚数は計算し直され、追加した直後は 0 枚になります（「再ヘッジ」は、評価点を「シナリオ時点」にして枚数を見直すことで行います）。

板の先物と違う限月を選ぶと、建値の初期値はその月の合成先物になり、「建値は手入力（板の先物と限月違い）」と注記が出ます。追加できないとき（先物価格が無い・評価日が先物の SQ 以降・枚数が上限を超えるなど）は理由が出てボタンが押せなくなります。

## 14. グラフの操作一覧

損益グラフとスマイルで共通です（長押しと , . < > の対象は、損益グラフがシナリオ点、スマイルが選択中の行使価格）。キー操作は、グラフをクリックしてフォーカスがあるときに効きます。

| 操作 | マウス | タッチ | キー |
|---|---|---|---|
| 拡大・縮小 | ホイール（カーソル位置が中心）、[＋][−] | 2 本指で広げる / 狭める | + / − |
| パン（左右の移動） | ドラッグ、横スクロール | 1 本指でドラッグ | ← / → |
| リセット | ダブルクリック、[⟲] | ダブルタップ | R |
| シナリオ点 ΔX（損益グラフ） | 長押ししてドラッグ / 縦線をつかむ | 長押ししてドラッグ | , / . で ∓100 円、< / > で ∓1,000 円 |
| 行使価格を選ぶ（スマイル） | クリック、長押ししてドラッグ | タップ、長押ししてドラッグ | , / . で 1 本、< / > で 5 本 |
| ピン（損益グラフ） | [ピン N/3] → [今の線を残す] / [B を重ねる] / [期中][満期]、一覧の [外す] | 同じ | ピンの行は Esc で閉じる |

グラフの中を触ってもページはスクロールしません。ページをスクロールするときは、グラフの外を触ってください。

## 15. 印・タグの意味

| 印 | 出る場所 | 意味 |
|---|---|---|
| 最新 / 板寄せ前 / 引け後 / 時間外 | ヘッダ | 板を選んだ理由（[3 章](#3-ヘッダ)） |
| 合成先物 / 先物で代用 / 先物で代用（限月違い）/ F なし | ヘッダ | 限月の F の求め方 |
| A で代用 | ヘッダ | B（合成先物）が決まらず A（先物）を使った |
| 古い | ヘッダ | 基準価格の時刻が板の時刻より 30 分以上古い |
| 古い板 | ヘッダ | 読み込みに失敗し、このブラウザに残っていた最後の板を表示している |
| IV 不安定 | 板・スマイル（×）・ポジション | 価格の分解能のわりに IV がぶれる行 |
| 補間 / 外挿 | 板・ポジション | スマイルの IV が節点の補間 / 端からの外挿 |
| 気配なし | 板・ポジション | bid・ask が無い |
| JPX の IV 欠損 | 板 | JPX が IV を出していない |
| 編集（行では「IV 編集」） | ポジション | IV を手で変えた |
| 休業日未確定 | ポジション | SQ 日がカレンダーの確定範囲より先 |
| 満期直前 / 満期 / 先物は SQ 済み / F なし | 指標の足別 | 評価点での足の状態 |

ポジションの行では印を短く出します（例: 「板なし（手入力）」→「手入力」、「F は先物で代用」→「F 代用」）。全文は行を開いた詳細に出ます。

## 16. 計算の前提と単位

### 価格モデル

- オプションの価格は **Black-76**（限月ごとの合成先物 F を原資産とする）
- 金利は既定 0.5%（割引と合成先物の計算に使う。1 か月で価格への影響は 0.05% 程度）
- 時間は **暦日 / 365**。満期は **SQ 日の 9:00**。評価時刻の既定は板の時刻
- 満期の直前（残り 1 分以下）は本源的価値で評価します
- IV の下限は 1%

### 横軸（基準原資産 X）と複数限月

- 横軸 X の基準 X₀ は **1 限月の基準価格**（既定は 1 限月の合成先物）
- 他の限月・先物の足の原資産は、X との差（basis）を一定に保って動かします（円モード）。たとえば 2 限月の F が X₀ より 75 円高ければ、X が動いても 2 限月の F は常に X + 75
- そのため、満期の線の折れ点は「行使価格 − その限月の basis」の位置に出ます

### 単位

| 値 | 単位 |
|---|---|
| 金額 | 円（自動で千円）。乗数はラージ OP / ラージ先物 1,000、ミニ先物 100、マイクロ先物 10 |
| Δ | ラージ先物換算の枚数（括弧にミニ先物換算 = × 10）。先物は 1 枚で ラージ 1 / ミニ 0.1 / マイクロ 0.01 |
| Γ | 原資産が 100 円動いたときの Δ（ラージ換算）の変化 |
| Θ | 円 / 暦日（乗数込み）。買いが負 |
| V | 円 / IV 1pt（乗数込み） |
| IV | %。Δσ・β・スキューは pt（IV の % ポイント） |

損益 = Σ 枚数 × 乗数 ×（評価価格 − 建値）× 売買の符号 − 手数料 です。

## 17. 使い方の例

数値はすべて架空の例です。

### 例 1: 翌日のイベント前に、1 限月のプット・デビットスプレッド

1. 1 限月のタブを選ぶ。[ATM へ戻る] で ATM の行へ
2. ATM の put の **ask** を押す（買い）。500 円下の put の **bid** を押す（売り）
3. 損益グラフで満期の形（折れ点 2 つ・BEP）を確かめる。指標の「掛け金」と「利益が掛け金の N 倍になる原資産」を見る
4. シナリオの経過日数を 1、原資産 ΔX を −3% にして、翌日の理論損益を見る
5. ΔX を 0 に戻し、Δσ を −3pt にして、イベント後の IV 低下（IV クラッシュ）の影響を見る

### 例 2: ファー OTM の put 売り（小資金）

1. 1 限月で種別を **put**、[OTM 30%] へジャンプ。または [ask ≤ 50 円] で絞り込む
2. **IV 不安定** の印が無い行の bid を押す（売り）
3. 損益グラフの縦軸を **±N 倍**（N = 5）にして、折れ点と BEP を見る。[−] で横軸を広げて −40% まで見る
4. テール表で、−10% / −20% / −30% の SQ と指定日の損失が、受取の何倍になるかを見る
5. プリセット「−10% / +20pt / +3」で、期中の評価損を見る。β を 0 にして、IV 連動が無い場合と比べる
6. 下落のヘッジに、足の追加フォームからミニ先物の売りを足して、Δ と −20% 時の損失の変化を見る

### 例 3: ストラングル売りとデルタヘッジ

1. 2 限月で、ATM から離れた put と call の bid を 1 枚ずつ押す（売り）
2. 指標の受取・BEP・スプレッドコスト、テール表を見る
3. デルタヘッジで目標 Δ 0 → 「ミニ ±N 枚」の [追加] を押す。現在 Δ が 0 近くになり、枚数は 0 に戻る
4. 原資産を −5% にし、評価点を **シナリオ時点** にする → 下落後に必要な追加枚数が出る
5. 損益グラフを長押しして左右に動かし、原資産ごとの損益とデルタを帯で読む

### 例 4: カレンダー・スプレッド（1 限月売り / 2 限月買い）

1. 1 限月のタブで ATM の put の bid を押す（売り）。2 限月のタブで同じ行使価格の put の ask を押す（買い）
2. シナリオの [SQ 日 9:00]（対象 = 1 限月）を押し、評価時刻を 1 限月の SQ に置く → 1 限月は満期、2 限月は残りの期間で理論値になる
3. Δσ を動かして、2 限月のベガの効き方を見る

## 18. 制限・まだ無い機能

- 自動保存は **このブラウザの作業中のタブ（最大 6 個）** です（[1 章](#作業の自動保存この端末)・[6 章](#作業中のタブbox)）。ほかのタブ・保存したポジションの線は **ピン** で重ねて比べられます（最大 3 本・保存しない。[6 章](#ピン留め線を重ねて比べる)）。指標を横に並べる本格的な比較は今後の予定です。名前を付けて複数のポジションを残す・一覧から開く・JSON で書き出す / 読み込むのは **保存一覧**（[11 章](#保存一覧名前を付けて保存)）。別の端末と自動で同期する機能は今後の予定です（端末間はポジション 1 つなら URL で渡す（[6 章](#url-で渡す別の端末で開く)）、まとめてなら保存一覧の書き出し / 読み込みで移します）
- 保存一覧の評価損益は今の板の mid（またはスマイルの理論価格）での評価で、返済側の気配（買いは bid・売りは ask）で決済したときの損益ではありません
- テンプレート（ストラングル・カレンダーなどを一度に組む）、証拠金の手入力、ピンの保存（再読み込みで消えます）、限月間の % モード（他の限月の原資産を差ではなく比率で動かす）は今後の予定です
- 板があるのは **ラージ OP の直近 2 限月** と **ラージ先物の直近四半期限月** だけです。それ以外の限月は手入力です（[13 章](#13-足の追加フォーム)）
- ミニ OP は扱いません
- 過去の時点の板を選ぶ機能はありません（[ファイルを開く…] で手元の JSON を読むことはできます）
- 板は約 15 分遅れで、自動更新しません
- 「清算値」での評価はありません

## 19. 困ったとき

| 症状 | 確かめること |
|---|---|
| 開くと「板を読めない」 | [最新] を押し直す。続くときは、データの取り込み（optionchan）が止まっていないか、休業日でないかを確かめる |
| 板の時刻が古い | ヘッダのタグを見る。「時間外」なら休業日・夜間の終了後など。立会中なのに古いときは取り込みの停止を疑う |
| 損益グラフが出ない | 足が 0 本か、F が決まらない限月の足だけ（「評価できる足が無い」と出る） |
| シナリオ 0 なのに損益が 0 にならない | 手数料が入っている、または建値ずれ（IV が逆算できない建値）がある。ポジションの建値ずれ・印を見る |
| 指定日の線が出ない | d = 0 かつ Δσ = Δs = 0 のときは、今日の線と同じなので描かない |
| スマイルが「スマイルなし」 | F が決まらないか、使える気配が無い（寄り前・夜間序盤など） |
| 数値欄が赤くなる | 範囲外の値。エラーの文に範囲が出る。反映はされていない |
| 長押ししても動かない | 長押しの前に指が動くとパンになる。0.45 秒ほど止めてから動かす |
| 前提の行に警告が出る | 取引カレンダーの期限切れ。SQ 日の計算が不確かになるので、管理者に知らせる |
| 再読み込みすると足・設定が消える | 「この端末に作業を保存できない」が出ていないか見る。プライベートモード・Cookie / サイトデータのブロック・容量不足では保存できない。別のブラウザ・端末で開いたときは、その端末の保存が使われる |
| 「保存した作業を読めなかった」「新しい版で保存された作業は読めない」と出る | 保存の形式が壊れているか、新しい版の画面で保存したもの。既定の状態で開く。新しい版の保存は消さない（この画面では保存しない）ので、新しい版に戻れば読める |
| 「別のタブが新しい版で作業を保存した」と出る | 開いたままのこのタブより新しい版の画面が、別のタブで保存した。このタブでは以後保存しない（新しい版の保存を上書きしない）。ページを再読み込みすると新しい版で開く |
| 保存を全部消したい | 足だけなら [全クリア]。シナリオ・設定・最後の板も消すには、ブラウザの設定でこのサイトのデータ（Cookie とサイトデータ）を削除して再読み込みする |
| 保存一覧に「保存一覧を読めない」と出る | 保存の形式が壊れている。保存されている内容はそのまま残し、変更しない。[空にする…]（確認あり）で作り直せる（壊れた内容は消える） |
| 保存一覧に「新しい版の画面で保存した一覧は…読めない」と出る | 新しい版の画面で保存したもの。この画面では読まず変更もしない。ページを再読み込みして新しい版で開く |
| 保存一覧で「保存できない」と出る | 容量の不足（最後に取れた板を消しても足りない）か、ブラウザの設定で保存が無効。項目を削除するか、書き出して整理する |
| 保存一覧の評価損益が「—」 | 今の板に無い限月の足（手入力の足・SQ を過ぎた足）がある。板が無いときは「板を読むと出る」 |
| ヘッダに「古い板」と出る | 開いたときに読み込みに失敗し、最後に取れた板を表示している。取得時刻の日付を確かめ、[最新] を押し直す |
| URL を開いてもポジションが開かない（何も出ない） | ログイン（IAP の Google アカウントの画面）を挟むと、ログイン後に URL の `#` から後ろが落ちることがある。ログインしたあとで、**もう一度同じ URL を開く** |
| 「URL のポジションを読めなかった（壊れているか途中で切れている）」と出る | URL が途中で切れたか、どこかの字が変わった（メールの折り返し・貼り付けの欠け）。渡した側でもう一度 [URL をコピー] して、切れない方法（メッセンジャー・メモ）で渡す。長い URL は保存一覧の書き出しで渡す。作業は変わっていない |
| 「新しい版で作った URL は読めない」と出る | 新しい版の画面で作った URL。ページを再読み込みして新しい版の画面で、もう一度 URL を開く |
| 「このブラウザでは URL のポジションを開けない」「URL を作れない」と出る | ブラウザが古い（iOS 16.4 より前の Safari など）。ブラウザ・OS を更新するか、別のブラウザで開く |
| [URL をコピー] で「コピーできない」と出る | ブラウザがクリップボードへの書き込みを許可していない。下に出た欄（選択された状態）からコピーする |
| 「別のタブで作業が保存された」と出る | 同じブラウザの別のタブで操作した。このタブで操作すると、このタブの内容で上書きする。別のタブの内容を使うなら再読み込み |
