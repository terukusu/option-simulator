# option-simulator 利用者マニュアル

日経225オプション（ラージ）のポジションを **建てる前に** 検討するための損益シミュレーターです。最新の板（気配・IV）を読み込み、板から足を選んでポジションを組み、満期・指定日・今日の損益と、原資産・IV・時間を動かしたときの損益（シナリオ）を見ます。

- 計算はすべてブラウザの中で行います。シナリオを動かしても通信しません（通信するのは板・IV 推移・先物推移を読むときだけ）
- 発注・約定の機能はありません。値はモデルによる **理論値** で、実際の約定・清算価格とは一致しません
- この文書の数値の例はすべて **架空の値** です

設計の詳細（式・判定の規則・決定の経緯）は [`design.md`](design.md)、画面の設計は [`ui-redesign.md`](ui-redesign.md) にあります。この文書では画面の使い方と、表示の読み方を説明します。

## 1. はじめに

### 開き方

デプロイ先の URL をブラウザで開きます（画面とタブのタイトルは「OP Simulator」）。IAP（Google アカウントのログイン）で守られているので、閲覧を許可された Google アカウントでログインします。開くと自動で 1 回だけ **最新の板** を読み込みます。

- パソコン・タブレット・スマートフォンのどちらでも使えます。幅 360px（小さめのスマホ）でも横スクロールしない作りです
- 自動更新はしません。新しい板が欲しいときはトップバーの [最新] を押します（[2 章](#2-板の読み込み)）
- 前の版の画面を開くときに URL に付けていたクエリ（`ui` の値）が残っていても、同じ画面で開きます

### 画面の構成

画面は **ページ全体がスクロールしない** 作りです。上にトップバー、真ん中に **舞台**（損益グラフ）があり、舞台は常に見えています。ほかの領域（パネル）は、画面の幅で次のように並びます。スクロールするのはパネルの中だけです。

| 画面の幅 | 並び |
|---|---|
| スマホ（720px 未満） | 上 = 舞台、下 = **シート**（引き出し）に 1 枚のパネル。下端の **ドック**（ポジ / 板 / シナリオ / 指標 / IV / AI）でパネルを選ぶ（[12 章](#12-ドックとシートスマホタブレット)） |
| タブレット（720〜1,199px） | 2 列: 左 = 舞台 + シナリオ（常設）、右 = ドック（ポジ / 板 / 指標 / IV / AI）で選んだパネル 1 枚 |
| PC（1,200px 以上） | 3 列: 左 = **市場**（板 / スマイルを切替）、中 = 舞台 + シナリオ、右 = **作業台**（ポジション → 指標 · テール） |

| 領域 | 内容 |
|---|---|
| トップバー | ブランド・BOX タブ（作業中のポジションのタブ）・**市場ピル**（板の時刻・鮮度・F・ATM）・警告のタグ・[最新]・テーマ・⋯（[3 章](#3-トップバーと市場ピル)） |
| 舞台 | 凡例行（線・ピン・ツール）→ 損益グラフの描画域 + 右の **IV レール** → 下の **時間レール** → **読み取り**（大きな数字）（[4 章](#4-舞台損益グラフ)・[5 章](#5-読み取り)） |
| シナリオ | ステッパー 4 つ（d・ΔX・Δσ・Δs）・プリセット・評価時刻・モデルの前提（[6 章](#6-シナリオ)） |
| ポジション | 足 1 本 1 行・詳細・デルタヘッジ（[7 章](#7-作業台-ポジション)） |
| 指標 · テール | タイル 6 枚・内訳・テール表（[8 章](#8-作業台-指標--テール)） |
| 板 | 限月・put / call・ジャンプのチップ・表・脚注（[9 章](#9-市場-板)） |
| スマイル | 横軸の切替・描画域・選んだ点の操作行・凡例（[10 章](#10-市場-スマイルiv-推移先物推移)）。スマホ・タブレットでは IV 推移と同じパネル（ドックの [IV]。開いたときは IV 推移） |

前の版の画面にあった、損益グラフを隠す [たたむ] は廃止しました（[`ui-redesign.md`](ui-redesign.md) §11 決定 7）。スマホでシートを全開にすると、舞台は線と読み取りだけの小さな形（ミニ）になります。

### ⓘ（説明の吹き出し）

計算の前提・操作の説明・印の意味などの説明文は、ふだんは隠してあり、パネルの見出しなどの **ⓘ** を押すと吹き出し（ポップオーバー）で出ます。

- もう一度 ⓘ を押す・吹き出しの外を押す（タップする）・Esc で閉じます。外を押したときは、そこにあるボタンやグラフの操作もそのまま効きます
- 同時に開くのは 1 つだけです。別の ⓘ を押すと前の吹き出しは閉じます
- キーボードでは Tab で ⓘ に移り Enter / Space で開きます。Esc で閉じるとフォーカスは ⓘ に戻ります
- **値・警告・状態は吹き出しに入れず常に出します**（市場ピルの警告のタグ・評価時刻・金額の単位・損益グラフの縦軸の単位・「プレミアム 0 のため自動」など）
- シナリオ・ポジション・指標 · テール・舞台の凡例行（損益グラフの前提）・IV 推移の吹き出しの末尾には **「用語:」と用語のボタン**（`Δs`・`β`・`NOV` など）があります。押すとその用語の説明カードが出ます（[14 章](#用語集説明カード)）

ⓘ の場所: 舞台の凡例行の右端（損益グラフの前提）、シナリオ・ポジション・指標 · テール・板・スマイルの見出しの右。市場ピルを押して出る詳細には、計算の前提の説明も入っています。

### 最短の使い方

1. 開く（最新の板が入る）
2. 板（スマホ・タブレットはドックの [板]、PC は左の列）で限月を選び、売りたい行の **bid**（売り）/ 買いたい行の **ask**（買い）を押す
3. 舞台の損益グラフと読み取りの数字、指標 · テールを見る
4. 舞台のハンドル（シナリオ点）を左右に、IV レールを上下に、時間レールを左右に動かして、期中の損益を見る（シナリオのステッパーでも同じ値を変えられます）

### 作業の自動保存（この端末）

足・シナリオ・表示の設定は、**BOX タブ（[11 章](#作業中のタブbox)）全部** を含めて、操作が止まってから約 0.5 秒で **このブラウザ（この端末）に自動で保存** され、再読み込み・タブを閉じた後に開き直すと元に戻ります。保存ボタンはありません。

| 保存されるもの | 保存されないもの |
|---|---|
| タブ（名前・並び・作業中のタブ）と各タブの足（建値・枚数・売買・IV の編集・印・手入力の足の F）、シナリオ（d・ΔX・Δσ・Δs・β・IV の動き方）、ATM の基準・表示中の限月・板の種別と絞り込み・スマイルの軸・縦軸・金額の単位・手数料・先物の basis・デルタヘッジの設定 | 板（ただし最後に取れた板は別に残します。[2 章](#2-板の読み込み)）、ΔX の単位、グラフの拡大・スマイルの選択、ピン、足の詳細の開閉、開いているパネル・シートの高さ・市場の板 / スマイル・[線 \| 面]、入れかけの値 |

テーマ（ダーク / ライト / 端末に合わせる）は作業とは別に、この端末の設定として残ります（[13 章](#テーマ)）。

- 開き直すと「前回の作業を復元した（足 N 本。保存 日時、そのときの板 日時）。建値は保存時のまま」の **トースト**（画面の下の知らせ）が出ます（約 6 秒で消えます。[閉じる] でも消せます）。タブが 2 個以上なら「（タブ N 個・作業中のタブの足 n 本。…）」です。保存が一部壊れていたときは、壊れたタブだけを捨てて「保存したタブ N 個を読めなかった。残りのタブ M 個を復元した」と警告のトーストが出ます（[閉じる] まで残ります）
- 前の版の画面で保存した作業（タブの無いころの保存・前の版の画面の保存）も、そのまま開けます。タブの無いころの保存はタブ「A」1 個として開きます
- **建値・枚数・売買・IV の編集は保存したときのまま** です。板の値で建て直しません。足の評価（IV・グリーク・損益）は、開いたときに読んだ新しい板で計算し直します。手入力の足の F（先物で代用したもの）や、板の先物と限月違いの先物の足の評価価格も、新しい板から求め直します
- 保存した足の限月が新しい板に無い（SQ を過ぎて限月が進んだなど）ときは、板の足は「板に無い限月」のエラーになり、グラフ・指標から外れます（[7 章](#7-作業台-ポジション)）。消すか、手入力の足として入れ直してください。手入力の足（板に無い限月で入れた足）は、その限月が板に入ったあとで限月の無い板（古いファイルなど）を読んでも、入れた F・暦の SQ で評価を続けます
- 保存はブラウザ・端末ごとです。別の PC・スマホとは共有しません。プライベートモード・Cookie のブロック・容量不足で保存できないときは、トップバーに警告のタグ「保存できない」が出ます（画面はそのまま使えます。あとで保存できたら消えます。[3 章](#警告のタグ)）
- 同じブラウザでタブを 2 つ開いて両方で操作すると、**最後に操作したタブの内容が残ります**。別のタブが保存すると警告のタグ「別のタブ」が出ます。そのタブの内容を取り込むには再読み込みしてください。別のタブが新しい版の画面で保存したときは警告のタグ「新しい版」が出て、このタブは以後保存しません（新しい版の保存を上書きしないため）
- 保存した足を消すには ⋯ > [全クリア]（[7 章](#全クリア)）。全部の保存を消すには、ブラウザのサイトデータの削除（[19 章](#19-困ったとき)）
- 自動保存は **BOX タブ（最大 6 個）** だけです。それより多くのポジションを名前を付けて残す・別の端末へ移すには **保存一覧**（[11 章](#保存一覧名前を付けて保存)）を使います。ポジション 1 つをすぐ別の端末（PC → スマホなど）で開くには **URL で渡す**（[11 章](#url-で渡す別の端末で開く)）

### ホーム画面に追加

スマホでは、ブラウザの「ホーム画面に追加」で、アイコン（名前は「OP Sim」）から開けます（iPhone は Safari の共有ボタン → [ホーム画面に追加]、Android の Chrome はメニュー → [ホーム画面に追加]）。

- アプリの設定は全画面にしていないので、ふつうはブラウザの画面で開きます（ログインもいつもの IAP）。iOS の版によってはホーム画面から全画面で開くことがあります
- オフライン（通信なし）では板を読めません。板を読むには通信が要ります

## 2. 板の読み込み

トップバーと ⋯ メニューで板を読み込みます。

| 操作 | 内容 |
|---|---|
| **[最新]**（トップバー） | サーバー（API）から、いま使える最新の板を読み直す。読み込み中は押せず、市場ピルに「読み込み中…」が出る |
| **⋯ > ファイルを開く…** | 手元にある板の JSON ファイル（形は `design.md` 7.1 の版 1）を開く |
| 「表示中」 | いま表示している板のデータ元（API・ファイル名）。市場ピルを押して出る詳細の末尾にある |

### 「使える最新の板」とは

板のデータは optionchan（JPX のページから毎分取り込むツール）が蓄積したもので、**約 15 分遅れ** です。サーバーは新しい順に板を調べ、気配が十分にそろった板だけを返します。そのため、時間帯によっては「いまの時刻の板」ではなく、少し前の板が表示されます。市場ピルのタグで理由がわかります（[3 章](#3-トップバーと市場ピル)）。

### 読み込みに失敗したとき

- 失敗した瞬間に **警告のトースト** でエラーの文言が出ます（次に読み込みが成功すると消えます）。市場ピルには「読めない」のタグが付き、ピルを押すとエラーの詳細が見られます
- すでに板を表示していた場合は **前の板のまま** 表示を続けます（ピルの詳細に「前の板のまま（取得 HH:MM）」）。ポジションも消えません
- 板が 1 枚も無いときは、市場ピルが「板を読めない」になり、「板を読めない。[最新] で読み直すか、板の JSON を選んでください。」と出ます
- **開いたときに読み込みに失敗して板が 1 枚も無いとき**（サーバーが止まっている・通信エラー・ログイン切れ）は、このブラウザに残っている **最後に取れた板** を表示します。市場ピルの ● が警告色になり **「古い板」** のタグが付きます。ピルの詳細には日付つきの取得時刻（`取得 2026-11-02 21:47（保存した板（API））`）が出ます。数日前の板のこともあるので、日付を確かめてください。[最新] で読み込めれば印は消えます
- 最後に取れた板は、[最新]（と本番で開いたとき）に読み込みに成功するたびに 1 枚だけ上書きで残します。⋯ > ファイルを開く… で読んだ板は残しません
- 板を読み直しても、ポジションの足・シナリオは残り、新しい板で評価し直されます（建値は変わりません。手入力の足の F の代用・限月違いの先物の評価価格は新しい板から求め直します）。グラフの拡大・スマイルの選択は元に戻ります

### 市場ピル

例（PC）: `● 板 11/02 21:31  最新  F 67,810 · ATM 67,750 · 先物 67,880`

| 表示 | 意味 |
|---|---|
| ● | 板の状態。警告（読めない・古い板・カレンダー期限切れ・F なし・ATM なし・古い）があると警告色 |
| 板 MM/DD HH:mm | 板（スナップショット）の時刻。JPX のページの時刻 |
| タグ | 板を選んだ理由・警告（下の表）。PC は 3 つ、タブレットは 1 つまで出し、残りは `+N`（全部は詳細に） |
| F · ATM | **表示中の限月**（板 / スマイルで選んでいる限月）の F と、選択中の基準での ATM の行使価格 |
| 先物 | 直近四半期限月のラージ先物の値 |

スマホでは幅に合わせて `● 21:31` の短い形にし、最も重い警告のタグを 1 つだけ短い形（例: 「カレンダー期限切れ」→「期限切れ」）で添えます。トップバーに警告のタグがあるときは、ピルのタグを出さず `● HH:mm` だけにします（全部は詳細で見られます）。

板の鮮度のタグ:

| タグ | 意味 |
|---|---|
| **最新** | 直近の板（45 分以内・立会中）をそのまま表示 |
| **板寄せ前** | 寄り前のため、直前の立会の「板寄せ前の最後のスナップショット」を表示 |
| **引け後** | 引け後のため、その立会の「板寄せ前の最後のスナップショット」を表示 |
| **時間外** | 時間外・休業日、または取り込みの停止のため、最後に使えた板寄せ前のスナップショットを表示 |

ほかのタグ（重い順に並びます: 読めない > 古い板 > カレンダー期限切れ > F なし / ATM なし > 古い > A で代用 > 先物で代用 > 鮮度）は [15 章](#15-印タグの意味) を見てください。「最新」以外のときは、詳細に理由の 1 文と表示している板の時刻が出ます。

### ポップオーバー（板の詳細）

市場ピルを押すと、板の詳細が吹き出しで出ます（もう一度押す・外を押す・Esc で閉じます）。

| 項目 | 内容 |
|---|---|
| 板 | 板の時刻と遅れ（約 N 分遅れ）・鮮度のタグと理由の 1 文 |
| 取得・データ元 | ブラウザで読み込んだ時刻とデータ元（`bigquery` など）。古い板なら日付つき |
| 日経平均 | 現物の値と時刻（夜間は止まっています） |
| 先物 | 直近四半期限月のラージ先物の値・約定時刻・SQ 日 |
| ATM の基準 | 今の基準（**B 合成先物（限月ごと）** / **A ラージ先物（直近四半期）**）。切り替えは ⋯ > 設定…（[13 章](#設定)） |
| 限月ごとの欄 | 限月（`2026-11 限` など）ごとに、最終・SQ、**F**（`67,810 ±15` のように不確かさ付き。タグで求め方: 合成先物 / 先物で代用 / 先物で代用（限月違い）/ F なし）、基準価格の候補 **A 先物 / B 合成先物** と時刻（選択中の方を強調。「A で代用」「古い」のタグ）、ATM の行使価格（決まらなければ「ATM なし」） |
| 前提 | 計算の前提（金利・評価時刻・取引カレンダー）の値と、それぞれが何に使われるか（金利は割引とプット・コール・パリティ、評価時刻は残存期間の起点、取引カレンダーは SQ 日・取引最終日の休業日）。取引カレンダーの期限を過ぎていると警告の文が強調されます（SQ 日の計算が不確かになるため） |
| 表示中・エラー | 表示中のデータ元。読み込みに失敗していればエラーの詳細 |

ATM の基準の違い:

| 選択 | 基準価格 | 特徴 |
|---|---|---|
| **B 合成先物（限月ごと）**（既定） | 限月ごとに、プットとコールの気配から求めた合成先物 F | 限月ごとに別の値。価格モデルの F と同じ。先物の限月交代で飛ばない |
| **A ラージ先物（直近四半期）** | 板のラージ先物の値 | 両限月で共通。SQ で先物の限月が変わると ATM が飛ぶ |

ATM の基準は、板の ATM 行の強調・スマイルの ATM の縦線・moneyness の基準・ジャンプの基準・市場ピルの ATM に効きます。

### 警告のタグ

この端末の作業の保存について、次のタグがトップバー（市場ピルの右）に出ます。押すと全文と [閉じる] が出ます。スマホでは先頭の 1 つと `+N` だけ出します。

| タグ | 意味 |
|---|---|
| **保存できない** | この端末に作業を保存できない（プライベートモード・Cookie のブロック・容量不足）。画面はそのまま使える |
| **別のタブ** | 同じブラウザの別のタブで作業が保存された。このタブで操作すると、このタブの内容で上書きする |
| **新しい版** | 別のタブが新しい版の画面で作業を保存した。このタブでは以後保存しない |

## 4. 舞台（損益グラフ）

横軸が **基準原資産 X**（円）、縦軸が **損益**（円。大きいときは千円）のグラフです。舞台は凡例行・描画域・IV レール（右）・時間レール（下）・読み取り（[5 章](#5-読み取り)）でできています。

### 凡例行とツール

左に線の凡例（─ 満期・─ 指定日（d N 日後）・┄ 今日）とピンの印、右にツールが並びます。

| ツール | 動き |
|---|---|
| **[線 \| 面]** | グラフの表示の切替（[面モード](#面モード)）。舞台の幅が狭いときは ⋯ の中 |
| **[ピン N/3]** | ピンのメニュー（[ピン](#ピン線を重ねて比べる)） |
| **[−] [＋] [⟲]** | 縮小・拡大・表示をリセット。舞台の幅が狭いときは ⋯ の中 |
| **⋯**（グラフの設定） | [線 \| 面]・**縦軸**（[下](#縦軸)）・[−][＋][⟲] |
| **ⓘ** | 損益グラフの前提（指定日の線のシナリオ値・β・IV の動き方、縦線上の金額の意味、印の意味） |

### 線と印

| 線・印 | 意味 |
|---|---|
| **─ 満期（SQ）** | 全部の足を SQ で決済したときの損益（手数料込み） |
| **─ 指定日** | シナリオ（経過日数 d・IV の変化）を当てたときの理論損益。d > 0 か Δσ・Δs ≠ 0 のときだけ描く（d = 0 のときの凡例は「シナリオ（d = 0）」） |
| **┄ 今日** | 板の時刻のまま、シナリオの IV（Δσ・Δs）を入れずに原資産だけ動かしたときの理論損益。原資産を動かしたときの IV の動き方（β・IV の動き方の設定）は、指定日の線と同じく効く |
| 塗り | 指定日の線（無ければ今日の線）と 0 の間。利益は緑、損失は赤 |
| ◇ | 満期の損益分岐点（BEP） |
| X₀ の縦線 | いまの基準原資産 |
| **ハンドル**（● と縦線） | シナリオ点 X₀ + ΔX。ΔX = 0 でも X₀ の上に出る |
| シナリオ ATM（点線） | ΔX だけ動いた後の ATM の行使価格（表示中の限月）。ΔX ≠ 0 で、板の行使価格の範囲内のとき |
| **足マーカー**（横軸の ▲ / ▼） | 足の行使価格（▲ call / ▼ put。塗り = 買い、白抜き = 売り）（[下](#足マーカー)） |
| **追証の線**（赤の破線と札「追証」） | 指定日 + シナリオの曲線（ΔX 以外はシナリオのまま、原資産だけを横軸の各点に置いた状態）で **余力（概算）が 0 になる原資産**。資金を設定したとき（⋯ > 設定…）だけで、余力がどこでも正なら出ません。ΔX・パン・拡大では動きません。d・Δσ・Δs・β などを動かしている間は消え、止まって約 0.1 秒で出ます（[8 章](#証拠金概算)） |

**ハンドルの縦線と各線の交点** に点と金額のラベル（`満 +120,000` / `指 −45,000` / `今 −10,000` のように）が出ます。金額の単位は指標と同じです（グラフの縦軸の単位とは別）。ラベルは線やほかのラベルに重ならない位置へ上下にずらします。交点が縦軸の範囲外なら、ラベルを端に寄せて ▲ / ▼ を付けます。

離散の変更（プリセット・枚数 ±・⇄・タブの切替・ピンの追加・足の追加 / 削除）では、線が約 0.2 秒で新しい形へ動きます（Chromium・Firefox。Safari などは即時）。ドラッグ・連打の間は即時です。端末の「視差効果を減らす」（動きを減らす）の設定ではすべて即時になります。

### シナリオ点を動かす（ハンドル）

- **ハンドル**（● とその縦線の左右 14px）を押して左右にドラッグすると、シナリオ点の ΔX が付いてきます。交点の金額・読み取り・シナリオの ΔX が同時に変わります（離しても ΔX はそのまま）
- ハンドルから離れた所は **長押し**（約 0.45 秒、ほぼ動かさずに）でつかめます。押した位置がシナリオ点になり、そのまま左右に動かせます（スマホでは軽く振動します）
- 長押しの前に指を 6px 以上動かすとパン（表示の移動）になります
- ΔX は 10 円単位で、−90%〜+100% の範囲に収まります（数値入力で入れたこの範囲の外の値（−95% など）からつかんで動かすと、この範囲に収まります）
- 線モードのハンドルは横だけです（縦に動かしても d は変わりません。ΔX と d を同時に動かすのは [面モード](#面モード)）
- 画面の端に寄せても自動ではスクロールしません。一度離してパンしてから、つかみ直してください

### 十字線で読む

任意の原資産の値での損益と、ある損益の水準を読むための線です（シナリオは変わりません）。線モードの損益グラフだけで、面モードとシートを全開にした小さな舞台には出ません。

- **PC**: 描画域にマウスを載せると出ます（外すと消えます）。ドラッグのパン・ハンドル・長押しは今までどおりです
- **スマホ・タブレット**: 描画域を **タップ** すると、その位置に置きます。別の所をタップすると移ります。置いた十字線の交点（縦線と横線の交わる所）を押してドラッグすると、十字線が指に付いて動きます。読み取りの右上の **×** をタップするか、描画域の外（軸の数字の所）をタップすると消えます（読み取りのほかの所のタップは十字線をそこへ移します）。ダブルタップ（表示のリセット）でも消えます。長押しはこれまでどおりシナリオ点をつかむ操作です
- **縦線** はカーソルの原資産（10 円単位）で、横軸の札にその値（例 `63,250`）が出ます
- **横線** は線には吸い付かず、マウス / 指の高さに付いて動きます。縦軸の札がその高さの損益です（グラフの縦軸と同じ単位 = 千円か円）。「損失が −1,000 千円になる原資産はどこか」は、横線を −1,000 に合わせて、満期の線と交わる所の横軸の札を読みます
- **読み取り**（描画域の角の 2〜3 行）に、縦線の位置での満期・指定日・今日の損益（`満 −1,000千円` のように。グラフの縦軸の単位）が出ます。線の上の小さな丸がその点です。読み取りは縦線と反対の側の角に出て、交点のラベル・IV レールの吹き出しを避けます。線が縦軸の範囲の外なら丸は出ず、金額に ▲ / ▼ が付きます
- パン・拡大をしても、十字線は同じ原資産・同じ損益の所に残ります（表示範囲の外へ出たら消えます）

### IV レールと時間レール

| レール | 動き |
|---|---|
| **IV レール**（描画域の右、縦） | つまみを上下にドラッグして **Δσ**（IV の平行移動）を変える。上端 +40pt・下端 −10pt、0.5pt 刻み。ダブルクリックで 0。レールが短いときは押した位置へ飛ばず、縦の移動量で動く |
| **時間レール**（描画域の下、横） | つまみを左右にドラッグして **経過日数 d** を変える（1 日刻み、0〜最遠の足の SQ）。目盛り（最終日 ┃・SQ ┃。例 `11月 SQ 11/13`）を押すと、**その時刻ぴったり**（最終日 15:45・SQ 9:00）に合わせる。つまみの下に `d 1.5 日 · 11/04 09:31（水）` の形で評価時刻が出る |

### 足マーカー

横軸の上の ▲ / ▼ が足の位置です。

- **タップ / クリック**: その足を選び、ポジションの行を開いて強調します（スマホ・タブレットではポジションのパネルが開きます）
- **長押し（約 0.45 秒）して左右に動かす**: その足の行使価格を変えます（板の OP の足だけ）。建値は新しい行使価格の bid（売り）/ ask（買い）、IV も新しい建値から求め直します。離すとトースト `K 64,000 → 63,500 · 建値 740 → 610` と [元に戻す] が出ます
- 長押しの前に 6px 以上動かすとパンになります。マーカーの上のダブルクリック / ダブルタップはリセットしません

### 拡大・移動

- ホイール（カーソル位置が中心）・ピンチ（2 本指の下の値を保つ）・[−][＋] で拡大・縮小
- ドラッグ（長押しの前に 6px 以上動かす）・横スクロールでパン
- ダブルクリック / ダブルタップ・[⟲]・キー R で表示をリセット
- 舞台の中を触ってもページはスクロールしません。詳しくは [14 章](#グラフの操作一覧)

### 縦軸

舞台の ⋯（グラフの設定）か ⋯ > 設定… の「損益グラフの縦軸」で選びます。

| 選択 | 範囲 |
|---|---|
| **自動**（既定） | 表示中の線が収まる範囲 |
| **±N 倍** | プレミアムの差引（受取 − 支払）の ±N 倍（N の既定 5）。小さいプレミアムの売りで、折れ点と BEP を見るとき。差引が 0 のときは自動になり、凡例行に「プレミアム 0 のため自動」と出る |
| **手動** | 下端・上端（円）を入れる。切り替えた時点の範囲から始まる |

縦軸の目盛りは数字だけで、単位（円 / 千円）は描画域の左上に出ます（表示範囲が 10 万円以上なら千円）。

### 面モード

凡例行の [線 \| 面] で **面** にすると、描画域が「横 = 原資産、縦 = 経過日数（下 = 今日・上 = 最遠の SQ）、色 = 指定日の損益」の面になります（緑 = 利益・赤 = 損失、濃さは損益の大きさ、0 付近は透明）。凡例行には色の見本と最大の金額が出ます。

- 描画域を押してドラッグすると、シナリオ点の **ΔX（横）と d（縦）を同時に** 動かせます（長押しを待たず、すぐつかみます）。点の近く（14px 以内）を押したときは点は飛ばず、そこからの移動量で動きます。離れた所を押すと点がその位置へ動きます
- 面モードの 1 本のドラッグはパンしません。パンは 2 本指・横スクロール・[−][＋][⟲] で行います。ドラッグの途中で 2 本目の指が来たら、押す前の ΔX・d に戻してピンチになります
- キー・IV レール・時間レール・足マーカーは線モードと同じに効きます
- 縦軸の設定は線モードで使います（面モードの縦軸は経過日数）
- [線 \| 面] は保存しません（再読み込みで線に戻ります）

### ピン（線を重ねて比べる）

損益グラフに、ほかの線を **最大 3 本** 重ねて比べられます（**ピン**）。ピンは 2 種類です。

| 種類 | 何を比べるか | 線の値 |
|---|---|---|
| **固定**（ゴースト）| 今の線を残して、足やシナリオを **変える前** と比べる（「足を 1 本足したら」「IV が +5pt なら」） | 残したときの値のまま。あとで足・シナリオ・手数料を変えても、板を読み直しても、タブを切り替えても **動きません** |
| **タブ** / **保存**（重ね）| 別のタブ・保存一覧の項目を、**今の板・今のシナリオ・今の設定** で同じ条件で比べる（案を並べる） | シナリオを動かすと **一緒に動きます**（シナリオは全タブ共通） |

凡例行の **[ピン N/3]**（N = 今のピンの本数）を押すとメニューが出ます。

| 項目 | 動き |
|---|---|
| **今の線を残す** | 今の期中の線（指定日の線。シナリオが 0 なら今日の線）を **固定** のピンで残す |
| **B を重ねる** | 作業中以外のタブごとに出る。そのタブの足を今の条件で重ねる（足 0 本のタブ・重ね済みのタブは押せない） |
| **ピンの線: 期中 / 満期** | ピンの線を期中の線か満期の線に切り替える（全部のピンで共通。既定は期中）。最大損失を比べるときは満期 |
| **① 名前 を外す** | そのピンを外す |
| **全部外す** | まとめて外す |

保存一覧の行の **[重ねる]**（[11 章](#保存一覧名前を付けて保存)）でも、その項目の足（重ねた時点の写し）を今の条件で重ねられます。

- 線は今の線の **下** に、色・**線種**（① 破線・② 点線・③ 一点鎖線）と、線の右端の **番号 ①②③** で区別します（色が見分けにくくても線種と番号で分かります）。線の値が縦軸の外なら番号に ↑ / ↓ が付きます
- 凡例行に ①②③ と名前、[×] が出ます（[×] で外す。スマホ・狭い舞台では名前を省きます）。名前の全文はマウスを載せると出ます
- 重ねたタブに切り替えると、そのピンは今の線と同じなので線を描きません（同じ線を二重に描かない）。戻すとまた描きます。そのタブを閉じるとピンも外れます
- 今の板で評価できない足（限月が板に無い足など）は除いて描きます
- 縦軸が **自動** のときはピンの線も範囲に入ります（手動・±N 倍は変わりません）。パン・ズームしても表示範囲の全体に描きます（ズームしている間は少し粗く描き、止まるとすぐ細かく描き直します）
- 3 本あるときは追加の項目が押せません。外すと、空いた番号を次のピンが使います（ほかのピンの番号は変わりません）
- **ピンは保存しません**。再読み込み・別の端末では消えます（作業の自動保存・保存一覧・URL には入りません）。残したい案は保存一覧に保存して、あとで [重ねる] で重ね直してください
- 作業中のタブの足が 0 本のときはグラフが空なので、ピンの線も描きません

### 凡例の注記

次の注意は吹き出しに入れず、凡例行に常に出ます。

- 「プレミアム 0 のため自動」: ±N 倍を選んだが基準が 0
- 「指定日 d を最遠の SQ に収めた」: d が足の満期を越えている（d の短いタブに切り替えたときなど）

### 空の舞台

足が 0 本のときは、目盛りだけの格子と「足を追加すると損益が出ます」が出ます。F が決まらない限月の足だけのときは「評価できる足が無い（F が決まらない限月の足だけ）」です。

## 5. 読み取り

舞台の下に、**シナリオ点の値** を大きな数字で出します。舞台の幅で個数が変わります（狭い = 3 つ、中 = 5 つ、広い = 6 つ）。

| 項目 | 内容 |
|---|---|
| **損益 · d N（日付）**（主役） | 指定日（シナリオ）の理論損益。下にシナリオ点の X（ΔX の円と %） |
| **満期（SQ）** | 満期の損益。下に今日の損益 |
| **Δ ラージ（ミニ）** | 合計デルタ（ラージ換算の枚数、括弧にミニ換算）。下に Γ（100 円あたり） |
| **Θ / 日** | 1 日あたりの時間価値の変化（5 つ以上のとき） |
| **V / pt** | IV 1pt あたりの変化（5 つ以上のとき） |
| **受取 − 支払** / **掛け金** | プレミアムの差引（支払超なら掛け金）（6 つのとき） |

- 損益は符号（+ / −）と色で出します。金額の単位は指標と同じ（`千円` など値の横に小さく）
- 損益・満期・Δ・受取 − 支払 / 掛け金は、押す（Enter / Space）と全文（副題で省いた項目を含む）が吹き出しで出ます
- 舞台を操作している間も値は付いてきます。Θ・V・受取はスマホでは指標 · テール（[8 章](#8-作業台-指標--テール)）で見ます

## 6. シナリオ

「もし原資産・IV・時間がこう動いたら」を設定します。値はすぐに損益グラフ・読み取り・指標・テール表に反映されます。PC・タブレットでは舞台の下に常にあり、スマホではドックの [シナリオ] で開きます。

### ステッパー

4 つのステッパーで値を変えます。値の下に小さく副題（評価日時・円と X の値など）が出ます。既定値（0）でない値は強調色になります。

| ステッパー | 意味 | 範囲・刻み |
|---|---|---|
| **経過日数 d**（日） | 板の時刻から何日たったか（暦日。小数可）。副題に評価日時 | 0〜最遠の足の SQ まで、1 日（足が 0 本のときは動かない） |
| **原資産 ΔX**（% または円） | 基準原資産 X₀ からの変化。副題に円（または %）と X | [−] / [＋]・キーなどの操作は −90%〜+100%、数値入力は −99%〜+900%（円は X₀ × −0.99〜X₀ × 9 の内側の整数）。% は 0.5% 刻み、円は 100 円刻み |
| **IV 平行移動 Δσ**（pt） | すべての行使価格の IV に足す | −10〜+40pt、0.5pt |
| **スキュー Δs**（pt / 10%） | moneyness 10% あたりの IV の傾きの変化。正で put 側の IV が上がり、call 側が下がる | −5〜+5、0.5 |

操作:

| 操作 | 動き |
|---|---|
| **[−] / [＋]** | 1 刻み（**Shift + クリックで 10 刻み**）。押し続けると 0.4 秒後から 0.08 秒ごとに 1 刻み。範囲の端で止まる |
| **値の上を左右にドラッグ（スクラブ）** | 8px で 1 刻み |
| **値の上でホイール** | 1 回で 1 刻み（上 = +、下 = −） |
| **キー**（値にフォーカス） | ↑ / → で +1、↓ / ← で −1、Shift + 矢印・PageUp / PageDown で ±10、Home / End で端、R で既定値（0） |
| **数値入力** | 値をダブルクリック（タッチは約 0.45 秒の長押し）で入力欄になる。Enter で確定、Esc で戻す。範囲外・数でない値は赤くなり、範囲の文が出て反映しない。入れた値は刻みに寄せない |

- d は端数を保ちます（4.27 日で [＋] → 5.27 日）。ΔX・Δσ・Δs は刻みの格子に寄せてから動きます
- ΔX を数値入力で操作の範囲の外（−95%・+300% など）にしたとき、[−] / [＋]・キーは押した向きにだけ動きます（−95% から [＋] で −90%、[−] は動かない）
- ΔX を数値入力で確定した点が損益グラフの表示範囲の外なら、その点が見えるように横軸を広げます（反対側の端はそのまま）。グラフの全域もその点まで広がるので、縮小・パンでも行けます
- 幅が広いときは 1 行 4 列、狭いときは 2 行 2 列に並びます
- 舞台のハンドル・IV レール・時間レール（[4 章](#4-舞台損益グラフ)）でも同じ値（ΔX・Δσ・d）を変えられます

### プリセット

| チップ | 設定する値 |
|---|---|
| **リセット** | d・ΔX・Δσ・Δs を 0 に戻す（β・IV の動き方・basis は変えない）。行の先頭にあるので、スマホでも横にスクロールせずに押せます |
| **急落 −10% / +20pt / +3** | ΔX −10%、Δσ +20pt、Δs +3 |
| **下落 −5% / +8pt / +1** | ΔX −5%、Δσ +8pt、Δs +1 |
| **反発 +5% / −5pt / −1** | ΔX +5%、Δσ −5pt、Δs −1 |

プリセットは ΔX・Δσ・Δs を同時に動かすだけです。d・β・IV の動き方は変えません。設定後も自由に編集できます。今のシナリオと同じ値のチップは押された状態で出ます。チップの行が入らない幅では、行を横にスクロールします。

Δσ はプリセットでも β とは **別に足し算** されます。たとえば β = 1 で「急落 −10% / +20pt / +3」を当てると、ATM の IV は +10pt（β）+20pt（Δσ）= +30pt 上がります。

### 評価時刻

足の全限月について、SQ の近い順に `11月 最終日 15:45` `11月 SQ 9:00` のチップが出ます（同じ月番号が 2 つあれば年を付けます）。押すと d をその時刻ぴったりに合わせます。今の d と同じチップは押された状態です。足が 0 本のときは「足を入れると評価時刻のチップが出る」と出ます。

時間レールの目盛り（最終日 / SQ）を押しても同じです。いまの評価時刻（板の時刻 + d）は、d のステッパーの副題と時間レールに常に出ます。

### モデルの前提

シナリオの下の「モデルの前提」の行に、要約 `β 1.0 · sticky strike · basis 固定 · ΔX %` が常に出ます。行を押すと開きます。

| 設定 | 意味 |
|---|---|
| **IV–原資産連動 β**（pt / 1%）既定 1.0 | **原資産と IV の連動**。原資産が 1% 下がるごとに IV を β pt 上げる（上がれば下げる）。0 で連動なし（0〜10、0.1 刻みのステッパー）。グラフの横軸の各点・テール表の各行で、その点の下落率で効く |
| **IV の動き方: sticky strike**（既定） | 原資産が動いても、行使価格ごとの IV は変えない |
| **IV の動き方: sticky moneyness** | スマイルが原資産と一緒に動く。put スキューの上では、原資産が下がると **同じ行使価格の IV は下がる** 向きに動く（急落時の IV 上昇は β と Δσ で表す） |
| **先物の basis: 固定**（既定） / **減衰** | 先物の足の評価で、先物と基準原資産の差（basis）を一定にするか、先物の SQ に向けて 0 へ線形に減らすか。先物の足が無い・オプションと同じ限月の先物だけなら差は出ない |
| **ΔX の単位: % / 円** | ΔX のステッパーの単位（保存しない） |

先物の basis と ΔX の単位は、⋯ > 設定… にもあります（同じ値です）。

## 7. 作業台: ポジション

入れた足の一覧です。追加した順に、**足 1 本を 1 行** で並べます。PC では右の列の上、スマホ・タブレットではドックの [ポジ] で開きます（ドックのボタンに足の本数のバッジが付きます）。

見出しの副題に足の本数と受取（または掛け金）が出ます（`2 本 · 受取 1,580`。0 本は「足なし」）。見出しの ⓘ に、グリークの前提（シナリオ 0 = 評価時刻は板の時刻、X は基準価格）と建値ずれの意味（シナリオ 0 の理論損益への影響、手数料は含めない）が出ます。見出しの ⋯ は 全クリア / 足を追加… / ヘッジの設定… です。

### 1 行の表示

例（値は架空）:

```
[売] P 64,000 @740                    [− 1 +]  ⇄  ×
     2026-11  IV 24.5  Δ +0.20
[買] ミニ先物 @67,880                  [− 1 +]  ⇄  ×
     2026-12  Δ +0.10
```

| 部分 | 内容 |
|---|---|
| [売] / [買] | 売買（売りは赤、買いは緑の面） |
| P / C と行使価格・@建値 | オプションの種別と行使価格（先物は商品）と建値（小数は小数第 2 位まで） |
| 2 段目 | 限月・IV（OP。%）・Δ（ラージ換算）・短い印（手入力・気配なし・IV 不安定・外挿・補間・F 代用・建値手入力・価格なし・IV 編集・休業日未確定・エラー。[15 章](#15-印タグの意味)）。入らなければ 2 段目の末尾を省略記号にします（全文は詳細） |
| [− 枚数 +] | 枚数（[下](#枚数)） |
| ⇄ / × | 売買の切替 / 削除 |

舞台の足マーカーで選んだ足・板から入れた直後の足は、行が強調され、見える位置までスクロールします。

### 枚数・⇄・×

| 操作 | 動作 |
|---|---|
| **[−] / [＋]** | 枚数を 1 減らす / 増やす（1〜100,000。端では押せない）。大きい枚数は詳細の欄に直接入れる |
| **⇄** | 売買だけを切り替える。トースト `買 P 64,000 に切替（建値は保持）`。**建値・IV の編集は変わりません**（反対側の気配に建て直しません）。戻すにはもう一度 ⇄ |
| **×** | その足を **すぐ消し**、トースト `売 P 64,000 ×1 @740 を消した` と [元に戻す]（約 5 秒）を出す。[元に戻す] で同じ位置に戻る |

前の版の画面の、消す前の確認ダイアログは廃止しました（[`ui-redesign.md`](ui-redesign.md) §11 決定 8）。消した直後の [元に戻す] で取り消します。

BOX タブを切り替えると、[元に戻す] 付きのトーストは閉じます（戻せるのはそのタブにいる間だけ）。

### 詳細（行を押すと開く）

行の左側（本文）を押すと、その足の詳細が開きます（もう一度押すと閉じます）。開くとその足を舞台でも選びます。

| 項目 | 内容 |
|---|---|
| 商品・限月 | ラージ OP / ラージ先物 / ミニ先物 / マイクロ先物、限月、種別と行使価格 |
| 売買 | 買い / 売り（切り替えは ⇄） |
| **枚数** | 1〜100,000 の整数 |
| **建値** | 0 以上 1,000,000,000 以下。板から入れた足は押した bid / ask が初期値 |
| **IV %** | その足の IV（下の「アンカー IV」）。編集すると「IV 編集」の印。板の足は空欄にすると編集を取り消す |
| Δ ラージ（ミニ）・Γ / 100 円・Θ 円 / 日・V 円 / pt | 足ごとのグリーク（シナリオ 0 = 板の時刻・基準価格での値） |
| **建値ずれ 円** | 建値がモデルで説明できない分の、損益への影響（下記） |
| スプレッドコスト | 建値と mid の差（mid の無い足・先物は —） |
| **SQ 日** | その足の SQ 日。カレンダーの範囲外なら「休業日未確定」 |
| **シナリオ点（足別）** | シナリオ点での足の IV・Δ・Γ・Θ・V と状態（満期直前 / 満期 / 先物は SQ 済み / F なし） |
| **印** | 気配なし・IV 不安定・補間 / 外挿などの全文。警告・エラーの文もここ（印が無ければ出ません） |

数値欄は、入力を確定（Enter・フォーカスを外す）したときに検証され、範囲外なら反映せずにエラーを出します。確定前に行を閉じると、入れかけの値とエラーは消えます（確定済みの値は残ります）。足を消したり追加したりしても、ほかの足の開閉は変わりません。開閉の状態は保存されません。

### アンカー IV（足の IV）の考え方

- 足を入れたときの **建値から逆算した IV** をその足の IV にします。そのため、シナリオ 0（d・ΔX・Δσ・Δs が 0、sticky strike）では、足の理論価格は **必ず建値に戻り**、損益は 0（手数料を除く）になります
- 原資産が動いたときは、足の IV を「スマイルの形に沿って」相対的に動かします
- 建値が本源的価値以下（ITM の bid など）で IV が逆算できないときは、スマイルの IV を使い、建値と理論価格の差を **建値ずれ** として別に出します
- 気配が片側だけ・無い行から入れた足は、建値の初期値が「ask − 呼値 1 つ」（ask も無ければスマイルの理論価格）になり、「気配なし」の印が付きます。建値を確かめて、必要なら直してください
- 足マーカーで行使価格を変えたとき（[4 章](#足マーカー)）は、新しい建値から IV を求め直します

### 全クリア

ポジションの見出しの ⋯ か、トップバーの ⋯ の **[全クリア]** で、作業中のタブの足を全部消します。確認は出さず、トースト `足 N 本を消した` と [元に戻す] が出ます（[元に戻す] で全部の足が元の順に戻ります。損益グラフの表示範囲は初期に戻ったままです）。足は自動で保存しているので、全クリアのあとトーストが消えてから再読み込みしても足は戻りません（シナリオ・設定は残ります。[1 章](#作業の自動保存この端末)）。

### デルタヘッジ

ポジションの行の下の「デルタヘッジ」の節で、ポジションのデルタを先物で目標値に合わせるための枚数を出します。足が 0 本でも表示されます。

| 表示・設定 | 内容 |
|---|---|
| **[適用前 \| シナリオ時点]** | どの点のデルタを使うか。適用前（既定）= ポジションの行と同じ点、シナリオ時点 = シナリオ点（読み取りと同じ点） |
| 現在 Δ → 目標 | `現在 Δ +0.32（ミニ +3.2）→ 目標 0` の形。ラージ換算とミニ換算 |
| **ミニ ±N 枚（残り ±r）[追加]** | ミニ先物で必要な枚数と、追加した後に残るデルタ（ラージ換算） |
| **ラージ ±M 枚（残り ±r）[追加]** | ラージ先物の場合 |

- 目標 Δ（ラージ換算。既定 0、−1,000〜1,000）と **限月**（板の先物と、板の OP の限月から選ぶ）は、見出しの ⋯ > **ヘッジの設定…** のダイアログで変えます
- [追加] を押すと、その先物の足（売買は符号、建値は板の先物の値）がポジションに入り、トースト `ミニ先物 2026-12 売 ×3 を追加` が出ます。足・シナリオ・目標が変わるたびに枚数は計算し直され、追加した直後は 0 枚になります（「再ヘッジ」は、評価点を「シナリオ時点」にして枚数を見直すことで行います）
- ミニで 0 枚に丸まるときは、マイクロ換算の枚数を注記で出します（マイクロは [足を追加…](#足を追加先物手入力の-op) から入れます）
- 板の先物と違う限月を選ぶと、建値の初期値はその月の合成先物になり、「建値は手入力（板の先物と限月違い）」と注記が出ます。追加できないとき（先物価格が無い・評価日が先物の SQ 以降・枚数が上限を超えるなど）は理由が出てボタンが押せなくなります
- 段の文が入らない幅では省略記号にします

### 足を追加…（先物・手入力の OP）

ポジションの見出しの ⋯ > **足を追加…**（または空の状態の [足を追加…]）でダイアログが開きます。上の **[先物 \| OP（手入力）]** で種類を選びます。[追加]（Enter でも）で、入れた値を検証してから足を入れ、ダイアログを閉じてトースト `ミニ先物 2026-12 買 ×1 を追加` を出します。値が正しくないときはダイアログは開いたままで、中にエラーが出ます。

**先物**:

| 欄 | 内容 |
|---|---|
| 商品 | **ミニ先物**（既定）/ ラージ先物 / マイクロ先物 |
| 限月 | `YYYY-MM`。既定は板の先物の限月 |
| 売買・枚数 | 既定は買い 1 枚 |
| 建値 | 空欄なら板の先物の値。板と違う限月は入れておく |

乗数はラージ 1,000・ミニ 100・マイクロ 10 です。先物の足は、オプションの SQ より後の限月なら「SQ + basis」で評価します（basis 固定 / 減衰は [6 章](#モデルの前提)）。

**OP（手入力）**: 板に無い限月（3 限月以降など）のラージ OP を入れます。

| 欄 | 内容 |
|---|---|
| 限月 | `YYYY-MM` |
| 種別・K・売買・枚数 | 既定は put・売り・1 枚 |
| 建値・IV % | どちらも必須 |

板の無い限月の SQ 日は、取引カレンダー（休業日 = 土日・取引所の休業日・国民の祝日）から求めます。カレンダーの確定の範囲より先の限月は「休業日未確定」の印が付きます。F は板の先物価格で代用します。板が無いときは [足を追加…] は押せません。

### 空の状態

足が 0 本のときは、「板の bid（売り）/ ask（買い）を押すか、⋯ の「足を追加…」で足を入れる」と、**[板を開く]**（スマホ・タブレットは板のパネル、PC は市場の列を板に）・**[足を追加…]** が出ます。

## 8. 作業台: 指標 · テール

PC では右の列の下、スマホ・タブレットではドックの [指標] で開きます。見出しの副題に金額の単位と手数料（`千円（自動）· 手数料 100 円 / 枚` など）が出ます。単位と手数料は ⋯ > 設定… で変えます（[13 章](#設定)）。足が 0 本のときは「足を追加すると指標が出ます」と出ます。

### タイル

8 枚のタイルで主な指標を出します。タイルを押す（Enter / Space）と、全文（見出し・値と単位・副題で省いた項目）が吹き出しで出ます。必要証拠金・余力の 2 枚の全文は、その値に関わる行だけです（シナリオ点・NOV・証拠金所要額・今の額・最悪の点など。前提を含む全部の行は「内訳」で見ます）。

| タイル | 意味 |
|---|---|
| **満期 最大利益** | 満期の損益の最大と、その原資産 X。片側で無限に増えるときは「call 側 ∞ / put 側 …」 |
| **満期 最大損失** | 満期の損益の最小。call の売り越しで上に無限なら「−∞」と put 側の値（X = …）。put 側は原資産 0（SQ = 下端）までで有限 |
| **満期 BEP** | 満期の損益分岐点（1 円単位。無ければ「なし」）。副題に指定日の BEP |
| **受取 − 支払** / **掛け金** | 受取超なら受取 − 支払（副題に受取・支払）、支払超なら掛け金 = 支払 − 受取 + 手数料 |
| **指定日 + シナリオ** | シナリオ点の理論損益（副題に d・X） |
| **合計グリーク** | Δ（ラージ換算の枚数、括弧にミニ）。副題に Θ / 日・V / pt。全文に Γ / 100 円 |
| **必要証拠金（概算）** | シナリオ点で建てているときの必要証拠金の **概算**（格子の最悪の損失 × 掛け目。受け取るプレミアムを含まない、証券会社の建てる前の必要委託証拠金と同じ物差し。下の「証拠金（概算）」）。副題に今（シナリオ 0）の額。見出しの横に、値がどの点のものかを小さく出します（`· d 7 日 · ΔX −4.4%` のように 0 でない d・ΔX・Δσ・Δs、シナリオが全部 0 なら `· 今`。入らなければ「…」で、全文の「シナリオ点」の行で読めます） |
| **余力（概算）** | 資金 − 支払 + 受取 − 手数料 + 先物の評価損益 − 証拠金所要額（= 必要証拠金 − NOV。シナリオ点）。副題に今の余力と **建てられる倍数**（今のポジションの何倍まで余力が 0 以上か。増やしても余力が減らない形は「上限なし」）。余力が負なら警告の色（追証の目安）。資金を設定していなければ「—」と「資金は ⋯ > 設定…」。見出しの横の点の印は必要証拠金と同じ |

### 内訳

タイルの下の「内訳」を押すと、全部の指標を一覧で出します（既定は閉。開閉は保存しません）。

| 項目 | 意味 |
|---|---|
| **満期 最大利益 / 最大損失 / BEP** | タイルと同じ（両側の値） |
| **指定日 + シナリオ** | シナリオ点の理論損益と、その条件での BEP |
| **合計グリーク（シナリオ点）** | Δ（ラージ換算の枚数、括弧にミニ）・Γ / 100 円・Θ / 日・V / pt |
| **受取 / 支払** | 受け取るプレミアムと支払うプレミアム。差引と、手数料込みの差引・手数料の合計 |
| **掛け金**（支払超のときだけ） | 支払 − 受取 + 手数料。「利益が掛け金の 1 / 5 / 10 倍になる原資産（満期）」も出す |
| **スプレッドコスト** | 建値と mid の差の合計（気配の幅で負担しているコスト） |
| **建値ずれ** | 建値がモデルの理論価格と合わない分の影響（[7 章](#アンカー-iv足の-ivの考え方)） |
| **証拠金（概算・保守寄り）** | 先頭に「シナリオ点」（d・ΔX・Δσ・Δs のうち 0 でないものを 1 行ずつ。全部 0 なら「今と同じ」）、シナリオ点と今の必要証拠金（格子の最悪の損失 × 掛け目）・NOV（OP の評価額。買い +、売り −）・証拠金所要額（必要証拠金 − NOV。0 未満にしない）・余力、倍数（今。建てられる倍数）、最悪の点（必要証拠金があるとき。X の %・IV の倍率（`×1.5` など）・経過の日）、前提（値動き幅 R・IV の幅（`×1.5 / ×0.75`）・保有期間・掛け目・買いの OP） |

足ごとの IV・グリークと状態の印は、ポジションの行の詳細（[7 章](#詳細行を押すと開く)）の「シナリオ点（足別）」で見ます。

指定日 + シナリオの BEP は、全域を細かく区切って探しています。とても近い 2 つの BEP（細いバタフライの頂点付近など）は取りこぼすことがあるので、グラフでも確かめてください。

### テール表

原資産が **−5% / −10% / −20% / −30% / −40%** 動いたときの損益を、2 つの評価で並べます。セルには損益の大きさのバーが付きます。

| 列 | 評価 |
|---|---|
| **SQ** | その原資産で満期決済したときの損益 |
| **指定日 + シナリオ** | d・Δσ・Δs・β・IV の動き方はシナリオのまま、原資産だけを各行の値にして評価した損益（β は各行の下落率で IV を上げる） |

表の上の 2 行（損益の単位と倍率の基準額、「指定日 + シナリオ」の列の計算方法）は常に出ます。

各セルの下段の **×N** は、損益の大きさがプレミアムの何倍かです。基準は受取超なら「受取 − 支払」、支払超なら掛け金です。売りの戦略では、「最大損失 ∞」よりも、期中の評価損とこの倍率を見るのが実用的です。損失のセルは色が変わります。

### 証拠金（概算）

テール表の下に **証拠金（概算。指定日 + シナリオ）** の表が出ます。行はテール表と同じ（原資産 −5%〜−40%、d・Δσ・Δs・β・IV の動き方はシナリオのまま）で、列は **必要証拠金** と **余力** です。余力が負の行は警告の色と「追証」の印が付きます（資金を設定していなければ余力の列は「—」）。表の上の 1 行に単位と前提が出ます。

必要証拠金は **概算** です。JSCC の証拠金（VaR 方式）を再現したものではありません。

JSCC は 2023-11-06 に証拠金の計算方式を **SPAN**（米国の CME が作った方式。決めた幅で原資産と IV を動かした十数通りの場面の最大の損失をもとにし、深い OTM の売りには売りオプションの最低証拠金（下限。リスク量と比べて大きい方を取る）を設ける）から **VaR 方式**（指数先物・OP は HS-VaR。過去 1,250 日の値動きとストレスシナリオでポートフォリオの損益を計算し、大きな損失をカバーする額）へ変えました。simulator の概算は、決めた幅の格子の最悪の損失を取る SPAN に近い作りです。

- 計算: 原資産を ±R・±R/2・0、IV を足ごとの今の IV（シナリオの β・Δσ などを入れた値）の ×(1 + 上げ) / ×1 / ×(1 − 下げ)、経過を 0 / 2 営業日にした格子（30 点）で評価額の最悪の損失（PFE）を求め、掛け目を掛けます（**必要証拠金 = 掛け目 × PFE**）。受け取るプレミアム（NOV。売りは負）は含みません（証券会社の建てる前の画面の必要委託証拠金と同じ物差し）。格子の中の原資産の点ごとに β で IV を足すことはしません
- 余力に使うのは **証拠金所要額 = max(0, 必要証拠金 − NOV)** です（売りでは受け取ったプレミアムの分だけ大きい。掛け目は NOV には掛けません）
- 既定は **買いの OP で減らさない**: 必要証拠金は **売りの OP と先物だけ** で計算します（証券会社の必要委託証拠金の扱いに合わせたもの）。たとえば put 売り 2 枚 + 1 本上の put 買い 1 枚のレシオの必要証拠金は、put 売り 2 枚だけのときと同じです。買いの OP の支払は余力から引かれます。設定で「相殺する」にすると、買いの OP も含めた全部の足で相殺して計算します（JSCC の所要額の形。バーティカルなどは小さく出ます）。売りどうし（ストラングルの売りなど）は、どちらでもまとめて評価します
- 既定は R 5%・IV +50% / −25%（×1.5 / ×0.75）・掛け目 100% です。1 枚ずつの売りの 6 形（深い OTM・約 9% OTM・ATM 付近の put、約 10% OTM の call、ストラングル、期先の put）を証券会社の額と比べた答え合わせで、0.98〜1.07 倍に収まる値に決めました。⋯ > 設定… で変えられます（[13 章](#設定)）
- 急落の日（ストレスシナリオ）・先物との組み合わせ・レシオなど **答え合わせをしていない形では、実際の額と違うことがあります**。建てる前に JSCC の Web 試算か証券会社の画面の額で確かめ、幅・掛け目で寄せてください
- 証券会社の額は **前営業日の清算値で 1 日固定** です（場中に計算し直しても同じ額）。simulator は今の板で計算するので、シナリオが「今」でも場中の値動きの分だけ違います。比べるときは値動きの小さい時間か、前営業日の清算値に近い板で比べてください
- 買いだけのポジションは、既定（減らさない）では必要証拠金・所要額とも 0、「相殺する」でも掛け目 100% 以下なら所要額 0 です（どちらも余力 = 資金 − 支払 − 手数料）。指定日を SQ の先にした限月の足は、清算の額だけが余力に入ります
- 損益グラフの **追証の線**（[4 章](#線と印)）は、この余力が 0 になる原資産の水準です（シナリオの点の余力がこの線を越えると負になります）。原資産を板の行使価格の外（ΔX の数値欄で入れられる範囲まで）も探します
- 資金はこの端末にだけ保存します（作業の保存・保存一覧・書き出し・URL には入りません）

### 追証マップ

パネルの末尾の **▸ 追証マップ** を押すと開きます（既定は閉。開閉はアプリを開いている間だけ覚えます）。「原資産がどれだけ動き、**IV がどれだけ上がったら** 追証になるか」を 1 枚で見ます。追証の線（原資産だけを動かす）では見えない、急落と IV の急騰が同時に来る場面の余力が分かります。

- **軸**: 横 = 原資産の変化（今の X₀ に対する %。−30%〜+20%、2% 刻み）、縦 = IV の倍率（×0.5〜×2.5、0.1 刻み。足ごとの今の IV に掛けます）
- **色**: 各マス = そのときの余力（上の証拠金の余力と同じ式）。余力あり / 追証（余力 < 0）の 2 色で、境目に線が出ます。十字 = 今（0%, ×1）、縦の破線 = シナリオの ΔX
- **追証の側（赤）は概算です**: 証拠金の概算で余力が負になるところで、実際の追証の判定は引けの清算値で行われます。日中に追証の側へ入っても、引けで戻れば追証にはなりません
- **日数・スキュー・IV の動き方はシナリオのまま** です（d・Δs・sticky を変えると、止まってから作り直します）。シナリオの ΔX・Δσ・β はマップに効きません（縦軸が IV の変化そのものなので）。ΔX・Δσ・β を動かしてもマップは作り直しません
- **開いたとき**: パネルの下の端で開いても、マップが見えるところまでパネルが自動でスクロールします（動きを減らす設定の端末では一度に動きます）。過去の値の読み込み中・マスの計算中は、マップの枠の中にくるくる回る印（動きを減らす設定では止まった輪）と「過去の値動きを読み込み中…」「計算中…」が出ます。初めて開いたときは過去の値を読むので数秒かかることがあります
- **過去の点**: 取り込まれている全期間の、日中の終値どうしの **2 営業日の動き**（原資産の変化と ATM IV（30 日）の倍率）を点で重ねます。余力ありの側は丸、追証の側は × です。上に `過去 N 回の 2 営業日の動きのうち M 回が追証の側` が出ます。過去の値は開いたときに 1 回だけ読みます（読めなければ [再試行]。[最新] では読み直しません）
- **触る**: 点（またはマス）をタップ / クリックすると、下の 1 行に日付と値（点: `d₀ → d₁ · 原資産 ±% · IV a → b%（×r · ±pt）· 余力`、マス: `原資産 % · IV × · 余力`）が出ます。描画域にフォーカスして矢印キーでマスを 1 つずつ動かせます（Esc で外す）
- 資金を設定していないと「設定で資金を入れてください（⋯ > 設定…）」と出て、マップは作りません
- **過去の点の近似**: 過去の点は ATM の IV の倍率を **すべての足の IV に同じ倍率で** 掛けたものです。深い OTM・期先の売りでは、実際の IV の動きと違うことがあります。点は日をずらして重なった 2 日の組なので、N は独立な回数ではありません。点は 2 営業日の動きで、マップの日数はシナリオの d です（d を大きくすると「2 日分の動きが d 日後に来たら」の読みになります）

## 9. 市場: 板

PC では左の列（見出しの [板 \| スマイル \| IV 推移] で板）、スマホ・タブレットではドックの [板] で開きます。

### 限月と種別

- **限月のセグメント**（`11月限` `12月限`）で、**板とスマイルに出す限月** を選びます。ポジションには複数の限月の足を混ぜられます（限月を切り替えても足は消えません）
- **[put \| call]** は対象の種別です。ジャンプ（OTM・|Δ|）・絞り込みと、狭い枠の 5 列の表の種別に効きます。種別を切り替えても、枠の中央にあった行使価格の付近を保ちます
- 板のスクロール位置は限月ごとに保たれます。シナリオ ATM の線（[4 章](#線と印)）は表示中の限月について出ます

### 列

板の枠の幅で列の数が決まります（PC では画面の幅 1,800px 前後で 9 列、1,440px 前後で 7 列、1,280px 前後で 5 列。スマホ・タブレットも枠の幅しだい）。

| 列の数 | 並び |
|---|---|
| 9 列 | Δ · IV · C bid · C ask · **K** · P bid · P ask · IV · Δ |
| 7 列 | 9 列から両側の Δ を除いたもの |
| 5 列 | 選んだ種別（put / call）だけ: **K** · bid · ask · IV · Δ |

- **K**（行使価格）は **降順**（上が高い行使価格）に並びます
- **IV** は `bid の IV / ask の IV`（%）。気配から逆算した値です
- **Δ** はスマイル（[10 章](#10-市場-スマイルiv-推移先物推移)）の IV で計算したデルタです
- ATM の行は塗りで強調されます
- 作業中のタブに同じ限月・同じ K・同じ種別の OP の足があると、K の数字の下に枚数のバッジ（`売3` `買1`）が出ます（9 / 7 列は call の足を左・put の足を右）

### 足を入れる

- **bid を押す = 売り**、**ask を押す = 買い** の足（1 枚）がポジションに入ります。建値はその bid / ask です
- 入れた直後にトースト `売 P 64,000 @740 を追加` と [元に戻す]（約 5 秒）が出て、舞台の横軸に足マーカーが現れ、ポジションの行が選ばれます（市場のパネルは開いたまま）
- 気配が片側だけ・無い行（`—`）も押せます。その場合の建値の初期値は [7 章](#アンカー-iv足の-ivの考え方) を見てください
- 同じ足を何度押しても、別の足として追加されます（枚数はポジションで変えられます）
- 追加できないときは「足を追加できない: …」の警告のトーストが出ます
- この使い方と「Δ はスマイルの IV での値」は、見出しの ⓘ（板の使い方）でも確かめられます

### ジャンプと絞り込み

表の上のチップの行（入らない幅では横にスクロール）で、行へ移動・絞り込みをします。

| チップ | 動き |
|---|---|
| **ATM** | ATM の行を枠の中央に（ページ・シートはスクロールしない） |
| **OTM 10% / 20% / 30% / 40%** | 基準価格から、その割合だけ OTM の行使価格へ移動（put なら下、call なら上） |
| **\|Δ\| .05 / .10 / .20 / .30** | 対象の種別で、デルタの絶対値がその値に最も近い行へ移動 |
| **ask ≤ 50 円** | 対象の種別の ask が 50 円以下の行だけに絞る（ファー OTM を探すとき）。もう一度押すと解除。該当が無ければ「該当する行が無い」 |

ジャンプ先の行は 0.9 秒強調されます。絞り込みで隠れている行へジャンプすると、絞り込みを外してから移動します。

### 行の印と脚注

| 印 | 意味 |
|---|---|
| IV のセルの **×** | **IV 不安定**: 価格が呼値 1 つ分動くだけで IV が大きく変わる行（価格の分解能から見て IV が 5pt 超ぶれる、または ask ≤ 5 円）。スマイルの節点から外している |
| K の数字の **点線の下線** | **補間 / 外挿**: その行のスマイルの IV が、周りの節点からの補間 / 端からの外挿 |
| ボタンの **—**（薄い文字） | **気配なし**: その種別に bid・ask が無い |
| **—/—** | **JPX の IV 欠損**: JPX が IV を出していない（IV を出さないデータ元の板では、IV は気配の価格から計算して出し、この印は付かない） |

印の全文は、マウスを載せる（読み上げではボタンの名前）と出ます。意味の一覧は見出しの ⓘ にあります。表の下の脚注に、表示中の限月の F・ATM（基準 A / B）・SQ 日が出ます。

## 10. 市場: スマイル・IV 推移・先物推移

表示中の限月の IV のスマイル（縦軸 IV %）です。PC では左の列（見出しの [板 \| スマイル \| IV 推移] でスマイル）、スマホ・タブレットではドックの [IV] のパネルの見出しの **[IV 推移 \| スマイル]** で [スマイル] を選びます（パネルを開いたときは IV 推移。一度スマイルを選ぶと、閉じて開き直してもスマイルのままです。再読み込みで IV 推移に戻ります）。限月は板と同じセグメントで選びます。同じ場所で **IV 推移**（ATM IV の過去の推移。[下](#iv-推移atm-iv-の-30-日固定)）に切り替えられます。

### 横軸の切替

| 軸 | 内容 |
|---|---|
| **行使価格**（既定） | K |
| **moneyness** | K / 基準価格 − 1（ATM の基準の選択に従う） |
| **Δ** | put 換算のデルタ（0〜1） |

### 点と線

| 表示 | 意味 |
|---|---|
| ● mid / ● bid / ● ask | 各行使価格の IV（OTM 側の気配から） |
| ─ 実線 | 節点（使える行）の間 |
| ┄ 点線 | 補間・外挿の区間 |
| × | IV 不安定の行（節点から外した行） |
| ┆ ATM（破線） | 市場の ATM（選択中の基準） |
| ┆ シナリオ ATM（点線） | ΔX だけ動いた後の ATM（ΔX ≠ 0 のとき） |

スマイルは OTM 側（基準価格より下は put、上は call）の行から作ります。端の外は、裁定が起きない傾きに抑えて外挿しています。凡例は狭い幅では短い形（`●mid` `×不安定` `┄補間` など）になります（全文は見出しの ⓘ）。F が決まらないか、使える気配が無いときは「スマイルなし（F が決まらないか、使える気配が無い）」と出ます。

### スマイルから足を入れる

点（× を含む）を **タップ / クリック** すると、最寄りの行使価格が選ばれ、グラフの下の操作行が切り替わります。

`64,000 put · IV 28.0 · [売り 28] [買い 38] [×]`

板の bid / ask を押したときと同じ規則で足が入ります（OTM 側の種別。建値は売り = bid、買い = ask。トーストと [元に戻す] も同じ）。選択中の点をもう一度タップする・点から離れた所をタップする・[×] を押すと、選択を消します。限月の切替・板の読み直しでも選択は消えます。

**長押しして左右にドラッグ** すると、選択を連続して切り替えられます。グラフを長押し（約 0.45 秒、ほぼ動かさずに）すると押した位置に最も近い点が選ばれ、離さずに左右へ動かすと、指の位置に最も近い点（表示範囲の中）へ選択と縦線が付いてきます。操作行もそのつど切り替わり、離した時点の選択が残ります（もう一度タップで解除）。キーでは `,` / `.` で 1 本、`<` / `>` で 5 本、選択を左右へ動かせます（選択が無い・表示範囲の外なら、最初のキーで ATM を選ぶ。ATM が見えていなければ中央の点）。

拡大 [−][＋][⟲] は見出しの行にあります。ホイール・ピンチ・ドラッグ（パン）・ダブルクリック（リセット）の操作は損益グラフと同じです（キーの ← / → はスマイルではパン）。

### IV 推移（ATM IV の 30 日固定）

今の IV が過去に比べて高いか低いかを見るための、**ATM IV（30 日固定）** の推移のチャートです。IV が急に上がった所を売るポジションを組むタイミングを見るのに使います。

- 開き方: PC は左の列の見出しの **[板 \| スマイル \| IV 推移 \| 先物]** で [IV 推移]、スマホ・タブレットはドックの **[IV]**（折れ線のアイコン）。パネルを開くと IV 推移が出ます（見出しの **[IV 推移 \| スマイル \| 先物]** でスマイル・先物推移に切り替えられます）
- 値は optionchan が板から 1 回ごとに計算して保存している **残存 30 日に揃えた ATM の IV**（%。期近・次限月の ATM の IV を総分散で 30 日に補間したもの。SQ の前 3 日は次限月、SQ の直後で期近の残りが 30 日以上なら期近だけ）。限月の乗り換え・ATM の移動の段差がありません
- スマイルの ATM IV・足のアンカー IV（このシミュレーターのモデルの IV）とは **計算の仕方が別** です。値は近いことが多いですが、一致はしません
- 値の名前は **iv30** です（optionchan の表の列の名前）。IV はオプションの価格から逆算した、市場が織り込む変動率です。実際の値動き（日々の騰落率の標準偏差の年率）から計算する **HV**（ヒストリカルボラティリティ）とは別の値で、simulator は HV を出しません。IV − HV はボラティリティ・プレミアムと呼ばれます

### IV 推移の読み込み

- アプリを開いただけでは読みません。**初めて IV 推移を見たとき** に、今の足の最新の 1 回分（1 分足 3 日・1 時間足 60 日・日足 365 日）を読みます。パネルを閉じて開き直しても読み直しません。アプリを開き直す（再読み込み）と、また最新を読みます
- **⟳**（最新化）で最新の 1 回分を読み直します。トップバーの [最新] では IV 推移は読み直しません（板が新しくなると下の「今」の点が動きます）
- **左（過去）へパンすると続きを読みます**。左端が最初の足から 10 本以内になると、左の 1 回分を読みます（描画域の左上に「過去を読み込み中…」）。読み足しても見ている位置は動きません。それより前のデータが無くなると止まります（左の余白も消えます）
- 覚えておく長さには上限があります（1 分足 9 日・1 時間足 400 日。日足は無し）。超えると反対側（遠い側）を捨て、捨てた側へ戻ると読み直します
- 読み込みに失敗すると「読み込めませんでした」（足があるときは右上か左上に「更新できません」「過去を読めません」）と **[再試行]** が出ます

### 足・表示の形・読み取り

- 足: **[1分 5分 15分 1時間 4時間 日足]**（既定は 1 時間）。5 分・15 分は 1 分足から、4 時間は 1 時間足から作るので、元の足を読んであれば切り替えても通信しません。4 時間足は立会に合わせて区切ります: 日中は 8:45〜12:00・12:00〜15:45 の 2 本、夜間は 17:00〜21:00・21:00〜翌 1:00・1:00〜6:00 の 3 本（最後だけ 5 時間）で、1 日 5 本です（日中の引けと夜間の寄りを同じ足に混ぜません）。足を替えても見ていた時間の範囲を保ちます（読んでいない時間なら、その時間の 1 回分を読みます）
- 表示の形: **[ローソク \| 線]**（既定はローソク。陽線 = 緑、陰線 = 赤）
- 描画域の上の 1 行に、カーソルの足の時刻と **始 / 高 / 安 / 終** を出します（カーソルが無いときは最新の足）。PC はマウスを載せる、タッチは長押し（そのままドラッグで動く）、キーは `,` / `.` で 1 本ずつ。タップでカーソルを外します
- カーソルがあるときは **十字線** と **軸の札** が出ます。縦線はカーソルの足の位置で、横軸の札はその足の時刻（上の 1 行と同じ）です。横線は足の値ではなく **マウス / 指の高さ** に付いて動き、縦軸の札はその高さの IV（上の 1 行と同じ小数 2 桁）です。「この水準は過去のどこにあったか」を調べるのに使います（足の値は上の 1 行で読みます）。描画域の上下の端より外では端で止まります。キーだけで動かしたときは、最初の足の終値の高さに横線を置き、そのまま保ちます
- 横軸は足の並びです（取引の無い時間・休日は詰めて描きます）。時刻は日本時間です
- 拡大・パン・リセットは損益グラフ・スマイルと同じです（[14 章](#グラフの操作一覧)）

### 「今」の点とシナリオの水準

| 表示 | 意味 |
|---|---|
| ● 今（点） | 今の板から同じ定義で計算した ATM IV（30 日固定）。保存された推移は約 1 時間遅れるので、それより新しい板のときだけ右端に足します。凡例に値（例 `● 今 21.34`） |
| ┄ シナリオ（オレンジの破線） | 「今」の値（無ければ最新の足の終値）に、シナリオの **Δσ** と **β × ΔX%** を当てた水準（ATM なので Δs は効きません）。凡例に値（例 `┄ シナリオ 26.34`）。ΔX と Δσ が 0 なら出ません |

例（架空の値）: 今 20.00、ΔX = 0・Δσ = +5 なら水準は 25.00。ΔX = −10%・Δσ = +5・β = 1.0 なら 20.00 + 5 + 10 = 35.00。シナリオを動かすと水準もすぐ動きます（通信しません）。「シナリオで置いた IV が、過去の推移で見てどのくらいの高さか」を比べられます。

### 線の切れ目と確定前の足

- 立会の時間の中で 30 分以上（足の長さがそれより長ければ足 1 本分以上）データが空いた所は線をつなぎません（データの欠け）。立会の切れ目・土日・休業日をまたぐ所はつなぎます
- 右端の足は、保存された推移が毎時作り直されるので **確定前** です。薄く描き、読み取りの行に「確定前」と出ます。週末・夜明けなど更新が止まっていれば確定として描きます。⟳ で伸びます（右端が見えていれば表示も右端に付いていきます）

### 先物推移（日経225 先物）

原資産の **日経225 先物（ラージ・期近）** がどう動いてきたかを見るチャートです。IV 推移と並べて「IV が跳ねたとき原資産はどう動いたか」を読むのに使います。

- 開き方: PC は左の列の見出しの **[板 \| スマイル \| IV 推移 \| 先物]** で [先物]、スマホ・タブレットはドックの **[IV]** のパネルの見出しの **[IV 推移 \| スマイル \| 先物]** で [先物]
- 値は毎分取り込んだ先物の現在値（15 分遅れ）から作った足で、単位は円です。**1 分ごとのスナップショットから作るので、高値・安値は実際の約定の高値・安値より狭いことがあります**。ミニ・マイクロ先物の推移はありません（ラージとほぼ同じ値です）
- 足・表示の形・読み取り・十字線・拡大・パン・左へのパンでの読み足し・⟳ は IV 推移と同じです。読み取りの 1 行には、その足の **限月**（例 `12月限`）も出ます
- **限月交代**: 先物は取引最終日（SQ の前日）の夜間から次の限月に替わります。チャートは **期近のつなぎ足（調整なし）** で、替わった所も線はつながっています。替わった所には薄い **縦の点線** と新しい限月の札（例 `12月限`）を描きます（日足など札が混むときは線だけ）。点線の所の値の差（例: 0.3% 前後）は値動きではなく限月の違いです。過去の値を調整しないので、過去の値はそのまま当時の先物の値です
- ● 今（点）: 今の板の先物の値。保存された推移より新しい板で、限月が最後の足と同じときだけ右端に足します。シナリオの水準は出ません
- IV 推移と先物を切り替えると、**足と見ていた時間の範囲をそのまま保ちます**（並べて読めるように）。読んでいない時間なら、その時間の 1 回分を読みます
- 読み込みは IV 推移と同じく、初めて先物推移を見たとき・⟳・左右の端へのパンのときだけです（IV 推移を開いても先物は読みません。逆も同じ）。トップバーの [最新] では読み直しません
- **EMA の 3 本**: 価格の上に **EMA（指数平滑移動平均）の短期・中期・長期**（既定 5・25・75。どの足でも同じ期間）の線を重ねます。最初から出ていて、凡例の行の右の **[EMA]** で消す / 出すを切り替えます（アプリを開き直すと出ている状態に戻ります）。線は色と太さで見分けます（短期は細く、長期は太く）
  - 読み取りの 1 行の下に、EMA の値の行（例 `EMA5 38,512　EMA25 38,300　EMA75 37,900`。架空の値）が出ます。名前の左の短い線がグラフの線の色です（凡例の代わり）。値はカーソルの足、カーソルが無ければ最新の足です
  - 先物の足は期近のつなぎ足（調整なし）なので、限月が替わる日の値段の段差は EMA にもそのまま入ります
  - 読み込みの左端から 4 本・24 本・74 本（既定の期間）は計算に足りないので、その線は描かず値は `—` です。どの値もその足までのデータだけで計算します
  - 3 本が上から短期・中期・長期の順に並んでいれば上向きの並び（パーフェクトオーダー）、下から並んでいれば下向きです。並びは売買の合図ではありません
  - 期間は ⋯ > 設定… の「テクニカル指標」で変えられます。AI のツール（[20 章](#20-ai-に相談)）も同じ期間・同じ計算です
- **テクニカル指標の段**: 凡例の行の右の **[RSI] [MACD] [SO]** を押すと、価格の下にその指標の段が出ます（もう一度押すと消えます。最初はすべて隠れています。アプリを開き直すと隠れた状態に戻ります）。段は価格と一緒にパン・拡大し、カーソルの足の値を段の左上に出します（カーソルが無ければ最新の足）
  - **RSI**（既定 14。Wilder の平滑）: 0〜100。補助線は 30 と 70
  - **MACD**（既定 12・26・9）: 線は MACD（短期と長期の指数平均の差。円）とシグナル（MACD の指数平均）、棒はその差（ヒストグラム）。見出しの S = シグナル、H = ヒストグラム
  - **SO**（スロー・ストキャスティクス。既定 14・3・3）: 0〜100。線は %K と %D、補助線は 20 と 80
  - 期間は ⋯ > 設定… の「テクニカル指標」で変えられます（[13 章](#テクニカル指標の設定)）。段の見出しに使っている期間が出ます（例: `RSI（14）`）
  - 指標は読み込んである足から計算します。読み込みの左端から数本〜数十本（既定の期間で RSI 14 本・MACD 33 本・SO 17 本）は計算に足りないので線がありません。どの値もその足までのデータだけで計算します。AI のツール（[20 章](#20-ai-に相談)）も同じ期間・同じ計算です
  - 先物推移は期近をつないだ足（調整なし）なので、限月が替わった所の値の差（0.3% 前後）も指標に入ります
  - 指標は売買の合図ではありません（例: RSI が 70 を超えても上げ続けることはよくあります）
  - **段の高さを変える**: 価格と段の境目、段と段の境目をドラッグ（スマホは指で）すると高さが変わります。境目の近くではマウスのカーソルが上下の矢印になり、線が出ます。価格は 80px、段は 28px より小さくなりません。境目をダブルクリック / ダブルタップすると既定の高さ（1 段 56px）に戻ります。高さはこの端末に覚え、開き直しても同じです（境目にフォーカスして ↑ ↓ でも変えられます。Enter で既定）
  - **段を大きく見る**: 段の中をダブルクリック / ダブルタップすると、その段だけがグラフの領域いっぱいに広がります（価格とほかの段は隠れます）。もう一度ダブルクリック / ダブルタップすると元の配置に戻ります（開き直すと元の配置です）。段の上のダブルタップは最大化に使うので、表示範囲を初期表示に戻すのは価格のグラフのダブルタップか R キーです
  - **段の十字線**: 段の上でも、PC はマウスを乗せる、スマホは長押しで十字線が出ます。縦線は価格と全部の段で同じ足にそろい、価格の読み取りの 1 行・EMA の行・各段の見出しがその足の値になります。横線は指 / マウスの高さで、左の縦軸の札にその高さの値（例 `72.3`）が出ます（足の値には寄せません。水準を測る物差しです）。スマホは指で隠れないよう、触っている段の名前・横線の値・その足の値をグラフの上側にも出します。長押しの前に指が 6px 以上動くと、十字線ではなくパンになります（価格のグラフと同じ）。タップで消えます

## 11. BOX タブ・URL で渡す・保存一覧

### 作業中のタブ（BOX）

トップバーのタブで、**作業中のポジションを最大 6 個** 持って切り替えられます。「ストラングル」と「アイアンコンドル」を同じシナリオで見比べる、元の案を残したまま足を変えてみる、といった使い方をします。

```
[A 2][B 1][C] [＋]
```

（A・B・C = タブの名前、数字 = 足の本数。作業中のタブは強調）

- **タブを押す** と、そのタブの足に切り替わります。足・建値・枚数・IV の編集は **タブごと** で、混ざりません
- **全タブで共通** のもの: 板・表示中の限月・ATM の基準・**シナリオ（d・ΔX・Δσ・Δs・β・IV の動き方）**・手数料・先物の basis・縦軸・金額の単位・デルタヘッジの設定・**グラフの横の表示範囲**。シナリオを動かしたまま A / B を往復すると、同じ条件で比べられます。指定日 d が足の短いタブの最遠の SQ を超えるときは、そのタブでは SQ に収めて描きます（凡例行に注記）
- **[＋]**: [空のタブ] / [このタブを複製] のメニューが出ます。新しいタブは作業中のタブの右隣にでき、名前は A〜Z の空いている文字です。6 個のときは押せません（「タブは 6 個まで」）
- **作業中のタブをもう一度押す** と、そのタブのメニューが出ます:
  - **名前を変える…**: 小さなダイアログで名前を入れて [変える]（12 字まで。ほかのタブと同じ名前にはできません =「同じ名前のタブがある」）
  - **複製**: 右隣に同じ足のタブを作る
  - **保存一覧に保存…**: 保存一覧を、名前の欄にフォーカスして開く（保存するのは作業中のタブ）
  - **URL をコピー**: 作業中のタブを URL にしてコピーする（[次の節](#url-で渡す別の端末で開く)）
  - **閉じる**（タブが 1 個のときは出ません）: 確認なしで閉じ、トースト `タブ B（足 3 本）を閉じた` と [元に戻す] が出ます。[元に戻す] で同じ位置・名前・足・表示範囲に戻ります（ピンは戻りません）。戻せないときは「戻せなかった（タブが上限）」「戻せなかった（同じ名前のタブがある）」。閉じると右隣（無ければ左隣）のタブに移ります
- キーボード: タブにフォーカスがあるとき **← / →** で隣のタブ（端では反対の端へ）、**Home / End** で先頭 / 最後のタブに切り替わります
- 板を読み直すと、作業中のタブの足の評価は新しい板で計算し直します。ほかのタブは、切り替えたときに今の板で計算し直します（建値はそのまま）
- 長い名前は「…」で省略します（全文はマウスを重ねると出ます）。タブが多いときはタブの帯の中を横にスクロールします

### URL で渡す（別の端末で開く）

作業中のタブ 1 つ（足・建値・枚数・売買・IV の編集・タブの名前）を **URL** にして、別の端末（PC → スマホなど）やメモに渡せます。サーバーには何も保存しません（ポジションは URL の `#` より後ろに入り、サーバーには送られません）。

1. 渡したいタブを作業中にして、タブのメニュー（作業中のタブをもう一度押す）か ⋯ の **[URL をコピー]** を押します（足が 0 本のときは押せません）。トースト「コピーした（N 字）」が出たら、メッセンジャー・メールなどに貼り付けます
2. 受け取った側でその URL を開くと、作業中のタブが **空ならそのタブに**、**足があれば新しいタブに** 開きます（作業中の内容は置き換えません）。「URL のポジションを新しいタブで開いた（足 N 本。共有 日時、そのときの板 日時）。建値は共有時のまま。…」のトーストが出ます。タブの名前は渡した側の名前です（同じ名前のタブがあれば A〜Z の空いている文字）
3. タブが 6 個あるときは、ダイアログ「URL のポジションを開く」で「タブは 6 個まで。URL のポジション（足 N 本）を開くと作業中のタブ X（足 n 本）が置き換わる（保存一覧に無い内容は消える）」と聞かれます。[置き換える] か [やめる] を選びます（置き換えたくなければ、先にタブを閉じてから URL をもう一度開きます）

- 開いたあとはアドレス欄の `#` から後ろが消えます（再読み込みしても二重に開きません。開いたタブは自動保存されます）
- **建値は共有したときのまま** です。評価は開いた端末で読んだ今の板で計算し直します（保存一覧の [開く] と同じ。限月が今の板に無い板の足はエラーの行になります）
- URL から開くのは **足と名前だけ** です。**シナリオ・手数料・先物の basis・表示の設定**（限月・ATM の基準・縦軸など）は **開いた端末のまま** で、ほかのタブの評価も変わりません（渡した側のシナリオで見たいときは、受け取った側で同じ値に合わせます）。保存一覧の [開く] / [新しいタブで開く] は、シナリオ・手数料・basis も保存した値になります
- URL の長さの目安: 足 3 本で約 800 字、10 本で約 1,000 字、50 本で約 1,600 字。**2,000 字を超える** と「長い URL… アプリによっては途中で切れる」と注意が出ます（メールの折り返しなどで切れることがあります）。**8,000 字を超える**（足がとても多い）ときは URL にできません。保存一覧の書き出しでファイルにして渡してください
- コピーできない（ブラウザがクリップボードを許可しない）ときは、ダイアログ「共有の URL」に URL の入った欄が選択された状態で出ます。そこからコピーしてください
- URL の中身は **暗号化していません**。URL を渡した相手（と、そのメッセンジャーの履歴・ブラウザの履歴）からポジションが読めます。見せたくない相手には渡さないでください
- 古いブラウザ（iOS 16.4 より前の Safari など）では URL を作れず、開けません（「このブラウザでは…」と出ます）
- 前の版の画面で作った URL（クエリ `ui` の付いた形）も、そのまま開けます。いまコピーする URL にはクエリ `ui` を付けません

### 保存一覧（名前を付けて保存）

⋯ > **保存一覧（N）…**（N = 保存した件数）を押すと、「保存したポジション」のダイアログが開きます。作業中のポジションに名前を付けて **この端末（ブラウザ）** に残し、一覧から開き直せます。× か Esc で閉じます（ⓘ の説明を開いているときの Esc は、説明だけを閉じます）。

板が 1 枚も無い（読み込みに失敗し、保存した板も無い）ときも開けます。書き出し・読み込み・名前の変更・削除はできますが、[開く] は板を読んでからです（足の市場を板から作るため）。

```
保存したポジション ⓘ                                          ×
名前 [2026-11 売P64,000 売C70,500          ] [保存]  作業中のタブ B
[書き出し] [読み込み…]  2 件・約 2.4 千字
評価損益・最大損失・Δ は今の板（11/02 21:31）で計算。金額の単位: 千円
┌ 11月 ストラングル  [作業中]
│ 2026-11・足 2 本  受取 1,620  満期の最大損失 −∞  Δ −0.12  評価損益 −22.6
│ 保存 11/03 12:00・保存時の板 11/02 21:31
│ [開く] [新しいタブで開く] [重ねる] [上書き] [複製] [名前] [削除]
└
```

（値は架空）

- **[保存]**: **作業中のタブ** の足・シナリオ・設定を、入れた名前で一覧の先頭に足します。ほかのタブは保存しません。名前の欄には足から作った名前（限月と先頭 3 本。例 `2026-11 売P64,000 売C70,500`）が入っています。名前は 40 字まで（改行などの制御文字は除きます）。同じ名前も付けられます。足が 0 本のときは保存できません
- **一覧の 1 行**:

| 部分 | 内容 |
|---|---|
| 名前・タグ | 「作業中」= 今の作業と同じ内容（足・シナリオ・手数料・先物の basis）。「板に無い足 N」= 限月が今の板に無い板の足（開くとエラーの行になる） |
| 限月・足 N 本 | 足の限月（3 つ以上は「ほか N」） |
| 受取 / 掛け金 | 建値 × 枚数 × 乗数。受取超なら受取 − 支払、支払超なら掛け金 = 支払 − 受取 + 手数料（指標と同じ） |
| 満期の最大損失・Δ | **今の板** で計算した値（Δ は画面の「今日」の Δ と同じ、ラージ換算） |
| **評価損益** | 保存した建値のまま、**今の板の mid**（両側の気配が無ければスマイルの理論価格）で評価した損益から、その項目の手数料（1 枚あたり × 枚数）を引いたもの。建てた直後なら −スプレッドコスト − 手数料 になります。理論価格を使った足があれば「理論値を含む」。今の板で値の無い足（板に無い限月など）が 1 本でもあると「—」（一部の足だけの合計は出しません） |
| 保存・保存時の板 | 保存（上書き）した日時と、そのときの板の時刻 |

- **[開く]**: その項目の足で **作業中のタブ** を置き換え、シナリオ・**手数料・先物の basis** も項目の値にします（シナリオ・手数料・basis は全タブ共通なので、ほかのタブの評価も変わります。表示の設定 = 限月・ATM の基準・縦軸・単位・ヘッジは今のまま）。建値は保存したときのままで、評価は今の板で計算し直します（[1 章](#作業の自動保存この端末) と同じ）。作業中のタブの内容が保存一覧に無い（「作業中」の項目が無い）ときは、行の中に「作業中のタブ B の足 N 本は保存一覧に無い。「名前」を開くとこのタブが置き換わる（残すなら [新しいタブで開く]）」と行の中で確認が出ます（開くか、やめるかを選びます）
- **[新しいタブで開く]**: 作業中のタブを残したまま、右隣に新しいタブを作ってその項目を開きます（シナリオ・手数料・basis は [開く] と同じく項目の値になります）。タブが 6 個のときは押せません（押した時点で 6 個なら、一覧は閉じずに「タブは 6 個まで」と出ます）
- **[重ねる]**: その項目の足を、損益グラフに **ピン**（今の板・今のシナリオ・今の設定で描く線）として重ねます（[4 章](#ピン線を重ねて比べる)）。一覧は閉じます。重ねた時点の足の写しなので、あとで項目を上書き・削除しても線は変わりません。板が無い・ピンが 3 本のときは押せません
- **[上書き]**: 作業中のタブの内容でその項目を **すぐ** 置き換え（名前・並びは変わりません）、トースト `「名前」を上書きした` と [元に戻す] が出ます。[元に戻す] で上書きの前の内容に戻ります（タブを切り替えても戻せます）。上書きの後に保存一覧が変わった（名前の変更・削除・別のブラウザのタブでの上書き）ときは「戻せなかった（保存一覧が変わった）」
- **[複製]**: 「名前 (コピー)」をすぐ下に作ります
- **[名前]**: 名前の欄になります。Enter か [決定] で確定、Esc か [やめる] で戻します
- **[削除]**: 行の中で確認のあとで消します
- **[書き出し]**: 保存一覧の全部を JSON のファイル（`option-simulator-positions-日付-時刻.json`）に保存します。別の端末・ブラウザへ移すときや、控えに使います。⋯ > 書き出し でも同じです（結果はトースト）
- **[読み込み…]**: 書き出したファイル（または作業 1 つの JSON）を選ぶと、読める項目を一覧の先頭に **追加** します（今の項目は消しません）。同じ名前があれば「(2)」を付けます。壊れたファイル・新しい版の画面で書き出したファイルは「読めない」と出て、何も変わりません。2 MB まで。⋯ > 読み込み… でも同じです
- 保存は **100 件・約 100 万字まで** です。超える保存・複製・読み込みは断ります（不要な項目を削除するか、書き出して整理してください）。8 割を超えると「残りが少ない」と出ます
- 別のタブで保存一覧を変えると、こちらの件数・一覧も読み直します

## 12. ドックとシート（スマホ・タブレット）

スマホ（720px 未満）では、舞台の下に **シート**（引き出し）があり、下端の **ドック** の 6 つのボタン（**ポジ** / **板** / **シナリオ** / **指標** / **IV** / **AI**）でシートに出すパネルを選びます。[AI] は AI に相談するパネルです（[20 章](#20-ai-に相談)）。[ポジ] には足の本数のバッジが付きます。[IV] は IV 推移とスマイルのパネルで、開いたときは IV 推移です（[10 章](#iv-推移atm-iv-の-30-日固定)）。

| シートの高さ | 舞台 |
|---|---|
| **隠す** | 舞台が最大 |
| **覗く**（既定。画面の高さの約 42%） | 舞台は縮んだ形で全部見える |
| **全開** | 舞台はミニ（線と読み取りだけ・高さ 92px）。ミニの舞台は操作を受けない |

- シートの上端の **つまみ** を上下にドラッグする（40px 以上）と 1 段ずつ動き、タップすると 覗く ⇄ 全開 を切り替えます。下へドラッグすると 全開 → 覗く → 隠す
- ドックで **今のパネルのボタンをもう一度押す** とシートを隠します。隠しているときにボタンを押すと、覗くで開きます
- スクロールするのはシートの中だけです。舞台の上を触ってもページはスクロールしません
- 覗く ⇄ 全開 の高さは約 0.18 秒で動きます（動きを減らす設定では即時）
- 舞台の足マーカーをタップすると、ポジションのパネルが開きます

タブレット（720〜1,199px）では、右の列の上にドック（**ポジ** / **板** / **指標** / **IV** / **AI** の 5 つ）があり、選んだパネル 1 枚を右の列に出します。シナリオは左の列（舞台の下）に常にあるので、ドックにはありません。PC にはドックはありません（市場は左の列の [板 \| スマイル \| IV 推移] で切り替えます）。スマホ・タブレットの [IV] のパネルは開いたときに IV 推移を出し、見出しの [IV 推移 \| スマイル] でスマイルに切り替えます（選んだものはパネルを閉じて開き直しても保ち、再読み込みで IV 推移に戻ります。[10 章](#iv-推移atm-iv-の-30-日固定)）。

## 13. ⋯ メニューと設定

### ⋯ メニュー

トップバーの右端の ⋯ を押すと、次の項目が出ます（押せない項目はマウスを載せると理由が出ます）。

| 項目 | 動き |
|---|---|
| **保存一覧（N）…** | 保存一覧のダイアログを開く（[11 章](#保存一覧名前を付けて保存)） |
| **URL をコピー** | 作業中のタブを URL にしてコピー（[11 章](#url-で渡す別の端末で開く)）。足 0 本では押せない |
| **書き出し** | 保存一覧を JSON のファイルに書き出す。保存一覧が空・読めないときは押せない |
| **読み込み…** | 書き出した JSON を読み込んで保存一覧に追加する |
| **ファイルを開く…** | 手元の板の JSON を開く（[2 章](#2-板の読み込み)） |
| **全クリア** | 作業中のタブの足を全部消す（[元に戻す] 付き。[7 章](#全クリア)） |
| **用語集…** | 用語だけのコマンドパレット（問い合わせ `?` を入れた状態）を開く。スマホ・タブレットからも用語を引ける（[14 章](#用語集説明カード)） |
| **設定…** | 設定のダイアログ（下） |
| **端末に合わせる / ダーク / ライト** | テーマ（下） |

### 設定

⋯ > **設定…** でダイアログが開きます（× か Esc で閉じます）。変えるとすぐ効きます。

| 設定 | 選択 | 内容 |
|---|---|---|
| **ATM の基準** | 合成先物（B）/ ラージ先物（A） | 板の ATM 行・スマイルの ATM・市場ピルの ATM の基準（[3 章](#ポップオーバー板の詳細) の表） |
| **金額の単位** | 自動 / 円 / 千円 | 自動 = 受取 + 支払が 10 万円以上なら千円、未満なら円。金額（損益・プレミアム・Θ・V など）にだけ効き、Δ・Γ には効かない |
| **手数料（円 / 枚）** | 数値（0〜100,000、既定 0） | 1 枚あたりの手数料。損益グラフ・指標・テール表に効く（1 枚あたり × 枚数） |
| **損益グラフの縦軸** | 自動 / ±N 倍 / 手動 | [4 章](#縦軸)。舞台の ⋯ と同じ |
| **先物の basis** | 固定 / 減衰 | [6 章](#モデルの前提) と同じ |
| **ΔX の単位** | % / 円 | シナリオの ΔX の表示（保存しない） |
| **テーマ** | 端末に合わせる / ダーク / ライト | 下 |
| **証拠金（概算）** | 資金（円）・掛け目（%）・値動き幅 R（%）・IV の上げ（%）/ IV の下げ（%）・買いの OP（減らさない / 相殺する） | 下の「証拠金（概算）の設定」 |
| **テクニカル指標** | RSI・MACD・ストキャスティクス・EMA の期間 | 下の「テクニカル指標の設定」 |
| **前提** | （変更不可） | 金利・評価時刻・取引カレンダーの値。板が無いときは「板が無い（前提は板を読むと出る）」 |

β と IV の動き方は、シナリオの「モデルの前提」（[6 章](#モデルの前提)）で変えます。

#### 証拠金（概算）の設定

指標の必要証拠金・余力（[8 章](#証拠金概算)）に使います。欄は入力するたびに確かめ、範囲の内ならすぐ効きます（外なら欄の下にエラー文が出て、値は変わりません）。

| 欄 | 範囲 | 既定 |
|---|---|---|
| **資金（円）** | 0〜1,000,000,000,000 の整数。空欄（と 0）は未設定 | 未設定 |
| **掛け目（%）** | 50〜300 | 100 |
| **値動き幅 R（%）** | 1〜30（小数可） | 5 |
| **IV の上げ（%）** | 0〜200（小数可。50 = 今の IV の ×1.5） | 50 |
| **IV の下げ（%）** | 0〜90（小数可。25 = 今の IV の ×0.75） | 25 |
| **買いの OP**（買いの OP で減らさない） | 減らさない / 相殺する | 減らさない |

- **買いの OP**: 「減らさない」（既定）は売りの OP と先物だけで必要証拠金を計算します（証券会社の扱い）。「相殺する」は買いの OP も含めて相殺します（JSCC の所要額の形）。切り替えると指標・内訳・証拠金の表・追証の線がすぐ変わります。内訳の前提の「買いの OP」の行と、証拠金の表の上の 1 行の末尾（「· 買い OP 除く」= 減らさない）で今の設定が分かります
- **[既定に戻す]** は掛け目・値動き幅・IV の幅と買いの OP（減らさない）を既定に戻します（資金はそのまま）
- 既定の幅・掛け目は 6 形の答え合わせで決めた値です（[8 章](#証拠金概算)）。答え合わせをしていない形では実際の額と違うことがあるので、JSCC の Web 試算か証券会社の額で確かめて、幅・掛け目で寄せてください
- 2026-10-19（#150）に既定が変わりました（R 8% → 5%、IV の幅 +8 / −4pt → +50% / −25%、掛け目 120% → 100%）。掛け目・値動き幅を変えていた端末も、証拠金の設定は新しい既定に戻ります（資金と買いの OP の設定は残ります）
- 設定はテーマと同じくこの端末に残ります（作業の保存・保存一覧・URL には入りません）

#### テクニカル指標の設定

先物推移の指標の段と EMA の線（[10 章](#先物推移日経225-先物)）と、AI のツールのテクニカル（[20 章](#20-ai-に相談)）の両方に同じ期間を使います。過去に同じ状態だった後の値動きの分布も、この期間の指標で数えます。欄は入力するたびに確かめ、範囲の内ならすぐ効きます（外なら欄の下にエラー文が出て、値は変わりません）。

| 欄 | 範囲 | 既定 |
|---|---|---|
| **RSI の期間** | 2〜100 の整数 | 14 |
| **MACD の短期 / 長期** | 2〜100 の整数。短期 < 長期 | 12 / 26 |
| **MACD のシグナル** | 2〜100 の整数 | 9 |
| **SO の %K の期間** | 2〜100 の整数 | 14 |
| **SO のスロー**（%K の平滑） | 1〜20 の整数 | 3 |
| **SO の %D** | 1〜20 の整数 | 3 |
| **EMA の短期 / 中期 / 長期** | 2〜100 の整数。短期 < 中期 < 長期 | 5 / 25 / 75 |

- MACD の短期を長期以上にすると欄の下に「MACD は短期 < 長期にする」と出て、値は変わりません。短期と長期を両方大きくするときは、長期から変えてください
- EMA も同じで、短期 < 中期 < 長期にならない値を入れると欄の下に「EMA は短期 < 中期 < 長期にする」と出て、値は変わりません（大きくするときは長期から、小さくするときは短期から変えてください）
- **[既定に戻す]** はすべての期間を既定に戻します
- 期間を長くすると、計算に足りない左端が長くなります（週足は約 100 本しかないので、長い期間では AI のツールの値が空になることがあります）
- ゾーンの線（RSI 30 / 70、SO 20 / 80）は変わりません
- 設定はこの端末に残ります（作業の保存・保存一覧・URL には入りません）

### テーマ

画面の色は **ダーク** と **ライト** の 2 つです。

- **端末に合わせる**（既定）: 端末の設定（ダークモード）に従います。端末の設定を変えるとすぐ切り替わります
- 切り替えは、トップバーの ☾ / ☀（PC・タブレット）、⋯ のテーマの 3 項目、設定のテーマ、キー **T**（[14 章](#全体のキー)）、コマンドパレットのどれでもできます。☾ / ☀ と T は、今の色の反対を選びます（「端末に合わせる」から抜けます）
- テーマはこの端末の設定として残ります（作業の保存・保存一覧・URL には入りません。証拠金の設定も同じ）

## 14. キー・コマンドパレット・グラフの操作一覧

### 全体のキー

入力欄・ダイアログの上では効きません。日本語入力の変換中・Ctrl / ⌘ / Alt 付きでも効きません（ブラウザのキーを奪いません）。

| キー | 動き |
|---|---|
| **Ctrl / ⌘ + K** | コマンドパレットを開く（下） |
| **1〜6** | パネルへ移る（1 ポジション・2 板・3 シナリオ・4 指標・5 スマイル・6 AI）。PC の 6 は右の列を AI のチャットと入れ替え、もう一度 6（または 1・4）で戻す。スマホ・タブレットではシートや右の列にそのパネルを開き（5 は [IV] のパネル。中の IV 推移 / スマイルの選択はそのまま）、PC では市場の列を板 / スマイルに切り替える。パネルのスクロールする枠にフォーカスが移るので、そのまま ↓・PageDown でスクロールでき、次の Tab でパネルの中の操作に入る |
| **G** | 舞台の描画域にフォーカス（以後、描画域のキーが効く。足 0 本・ミニの舞台では移らない） |
| **T** | テーマを切り替える（今の色の反対） |
| **Esc** | メニュー・吹き出し・パレット・ダイアログを閉じる |

### コマンドパレット

**Ctrl / ⌘ + K** で、画面の上にコマンドの一覧と入力欄が出ます（PC のキーボード操作用。スマホ・タブレットのコマンドの入口はありません。用語だけは ⋯ > 用語集… から開けます）。文字を打つと絞り込み（空白で区切った語が全部含まれる行）、↑ / ↓ で選び、Enter で実行します。Esc・Ctrl / ⌘ + K・背景のクリックで閉じます。

絞り込みでは、全角 / 半角・大文字 / 小文字・カタカナ / ひらがな（半角カナも）を同じ文字として扱います。問い合わせの先頭を **`?`**（全角の `？` も）にすると、用語の行だけを出します（`?` だけなら用語の全部）。

| グループ | 行 |
|---|---|
| パネル | ポジション `1`・板 `2`・シナリオ `3`・指標 `4`・IV 推移 · スマイル `5`（「IV」でも「スマイル」でも出ます）・グラフにフォーカス `G` |
| シナリオ | リセット / 急落 / 下落 / 反発 |
| 評価時刻 | `11月 最終日 15:45` / `11月 SQ 9:00` など |
| ピン | 今の線を残す / B を重ねる / ピンの線: 期中・満期 / ① 名前 を外す / 全部外す |
| グラフ | 線 / 面 / 表示をリセット |
| 板 | ATM へ |
| 足 | `売 P 64,000 @740（11月限）` の形で、表示中の限月の足を入れる（ATM に近い順） |
| タブ | 空のタブを追加 / このタブを複製 / B に切り替え |
| 作業 | 保存一覧（N）… / 保存一覧に保存… / 全クリア / 設定… |
| テーマ | 切り替え `T` / 端末に合わせる / ダーク / ライト |
| 用語 | `IV 平行移動 Δσ`・`スキュー Δs` など 24 語（下の「用語集」）。選ぶと説明カードが出る |

押せない行は薄く出て、マウスを載せると理由が出ます。URL をコピー・書き出し・読み込み…・ファイルを開く…・名前を変える…・タブを閉じる・足を追加… はパレットにありません（メニューから使います）。

### 用語集（説明カード）

画面に出る記号・略語（Δσ・Δs・β・NOV・追証の線・iv30 など）の意味を、画面を離れずに引けます。用語を選ぶと、その場に **説明カード** が出ます。

開き方:

| 入口 | 動き |
|---|---|
| コマンドパレット（Ctrl / ⌘ + K） | 用語の見出し・読み・別名で当たります。`シグマ`・`しぐま`・`σ`・`sigma` で IV、`デルタs`・`Δs`・`スキュー` で Δs、`デルタσ` で Δσ が出ます（ギリシャ文字は読みでも当たります）。先頭に `?` を付けると用語だけ（例 `?シグマ`） |
| ⋯ > 用語集… | 用語だけのパレットを開きます（スマホ・タブレットの入口） |
| ⓘ の「用語:」 | シナリオ・ポジション・指標 · テール・損益グラフの前提・IV 推移の ⓘ の吹き出しの末尾のボタン |
| 内訳の見出し | 指標 · テールの「内訳」の Δ・Γ・Θ・V・必要証拠金・NOV・証拠金所要額・余力の行の見出し（点線の下線）を押す |

カードの中身: 見出し・読み・別名・一言・説明・式・例（**架空の値**）・simulator のどこに出るか・このマニュアルの節の名前・関連する用語。関連する用語のボタンを押すと、カードの中身がその用語に替わります。Esc・×・カードの外のクリックで閉じ、フォーカスは開く前の場所（吹き出しから開いたときはその ⓘ）に戻ります。

用語（24 語）: IV 平行移動 Δσ・スキュー Δs・原資産の変化 ΔX・IV（σ）・HV（ヒストリカルボラティリティ）・iv30・IV–原資産連動 β・グリーク・デルタ Δ・ガンマ Γ・ベガ V・シータ Θ・F（合成先物）・basis・sticky strike / sticky moneyness・NOV・PFE・必要証拠金（概算）・証拠金所要額・余力（概算）・追証の線・追証マップ・VaR / SPAN・JSCC。

σ（IV）はグリークではありません。グリーク（Δ・Γ・Θ・ベガ）は価格の微分で、ベガが σ に対する感応度です。

## 16. 計算の前提と単位

### 価格モデル

- オプションの価格は **Black-76**（限月ごとの合成先物 F を原資産とする）
- 金利は既定 0.5%（割引と合成先物の計算に使う。1 か月で価格への影響は 0.05% 程度）
- 時間は **暦日 / 365**。満期は **SQ 日の 9:00**。評価時刻の既定は板の時刻
- 満期の直前（残り 1 分以下）は本源的価値で評価します
- IV の下限は 1%
- IV（σ）は、オプションの価格から Black-76 を逆に解いて逆算した変動率です（市場が織り込む値動きの大きさ。実際の値動きから計算する HV とは別）

### 横軸（基準原資産 X）と複数限月

- 横軸 X の基準 X₀ は **1 限月の基準価格**（既定は 1 限月の合成先物）
- 他の限月・先物の足の原資産は、X との差（basis）を一定に保って動かします（円モード）。たとえば 2 限月の F が X₀ より 75 円高ければ、X が動いても 2 限月の F は常に X + 75
- そのため、満期の線の折れ点は「行使価格 − その限月の basis」の位置に出ます

### 単位

| 値 | 単位 |
|---|---|
| 金額 | 円（自動で千円）。乗数はラージ OP / ラージ先物 1,000、ミニ先物 100、マイクロ先物 10 |
| Δ | ラージ先物換算の枚数（括弧にミニ先物換算 = × 10）。先物は 1 枚で ラージ 1 / ミニ 0.1 / マイクロ 0.01 |
| Γ | 原資産が 100 円動いたときの Δ（ラージ換算）の変化 |
| Θ | 円 / 暦日（乗数込み）。買いが負 |
| V | 円 / IV 1pt（乗数込み） |
| IV | %。Δσ・β・スキューは pt（IV の % ポイント） |

損益 = Σ 枚数 × 乗数 ×（評価価格 − 建値）× 売買の符号 − 手数料 です。

## 17. 使い方の例

数値はすべて架空の例です。

### 例 1: 翌日のイベント前に、1 限月のプット・デビットスプレッド

1. 板で 1 限月（`11月限` など）を選ぶ。チップの [ATM] で ATM の行へ
2. ATM の put の **ask** を押す（買い）。500 円下の put の **bid** を押す（売り）
3. 舞台で満期の形（折れ点 2 つ・BEP ◇）を確かめる。指標の「掛け金」のタイルと、内訳の「利益が掛け金の N 倍になる原資産」を見る
4. シナリオの経過日数 d を 1、原資産 ΔX を −3% にして（ステッパー、または時間レール・ハンドル）、翌日の理論損益を読み取りで見る
5. ΔX を 0 に戻し、Δσ を −3pt にして（IV レールを下へ）、イベント後の IV 低下（IV クラッシュ）の影響を見る

### 例 2: ファー OTM の put 売り（小資金）

1. 板で 1 限月・**put** を選び、チップの [OTM 30%] へジャンプ。または [ask ≤ 50 円] で絞り込む
2. **IV 不安定**（IV のセルの ×）が無い行の bid を押す（売り）
3. 舞台の ⋯ で縦軸を **±N 倍**（N = 5）にして、折れ点と BEP を見る。[−] で横軸を広げて −40% まで見る
4. テール表で、−10% / −20% / −30% の SQ と指定日の損失が、受取の何倍になるかを見る
5. プリセット「急落 −10% / +20pt / +3」で、期中の評価損を見る。モデルの前提で β を 0 にして、IV 連動が無い場合と比べる
6. 下落のヘッジに、ポジションの ⋯ > 足を追加… からミニ先物の売りを足して、Δ と −20% 時の損失の変化を見る

### 例 3: ストラングル売りとデルタヘッジ

1. 2 限月で、ATM から離れた put と call の bid を 1 枚ずつ押す（売り）
2. 指標の受取・BEP、内訳のスプレッドコスト、テール表を見る
3. デルタヘッジで目標 Δ 0 → 「ミニ ±N 枚」の [追加] を押す。現在 Δ が 0 近くになり、枚数は 0 に戻る
4. 原資産を −5% にし、デルタヘッジの評価点を **シナリオ時点** にする → 下落後に必要な追加枚数が出る
5. 舞台のハンドルを左右に動かし、原資産ごとの損益とデルタを読み取りで読む
6. ピンの [今の線を残す] で今の線を残してから、ヘッジの足を [×] で消して、ヘッジの有無を重ねて比べる（[元に戻す] で足は戻る）

### 例 4: カレンダー・スプレッド（1 限月売り / 2 限月買い）

1. 板の `11月限` で ATM の put の bid を押す（売り）。`12月限` に切り替えて同じ行使価格の put の ask を押す（買い）
2. シナリオの評価時刻のチップ [11月 SQ 9:00]（または時間レールの 11 月の SQ の目盛り）を押し、評価時刻を 1 限月の SQ に置く → 1 限月は満期、2 限月は残りの期間で理論値になる
3. IV レール（Δσ）を動かして、2 限月のベガの効き方を見る。面モードにすると、時間の経過と原資産の両方で損益がどう変わるかを 1 枚で見られる

## 18. 制限・まだ無い機能

- 自動保存は **このブラウザの BOX タブ（最大 6 個）** です（[1 章](#作業の自動保存この端末)・[11 章](#作業中のタブbox)）。ほかのタブ・保存したポジションの線は **ピン** で重ねて比べられます（最大 3 本・保存しない。[4 章](#ピン線を重ねて比べる)）。指標を横に並べる本格的な比較は今後の予定です。名前を付けて複数のポジションを残す・一覧から開く・JSON で書き出す / 読み込むのは **保存一覧**（[11 章](#保存一覧名前を付けて保存)）。別の端末と自動で同期する機能は今後の予定です（端末間はポジション 1 つなら URL で渡す（[11 章](#url-で渡す別の端末で開く)）、まとめてなら保存一覧の書き出し / 読み込みで移します）
- 保存一覧の評価損益は今の板の mid（またはスマイルの理論価格）での評価で、返済側の気配（買いは bid・売りは ask）で決済したときの損益ではありません
- テンプレート（ストラングル・カレンダーなどを一度に組む）、ピンの保存（再読み込みで消えます）、限月間の % モード（他の限月の原資産を差ではなく比率で動かす）は今後の予定です
- 板があるのは **ラージ OP の直近 2 限月** と **ラージ先物の直近四半期限月** だけです。それ以外の限月は手入力です（[7 章](#足を追加先物手入力の-op)）
- ミニ OP は扱いません
- 過去の時点の板を選ぶ機能はありません（⋯ > ファイルを開く… で手元の JSON を読むことはできます）
- 板は約 15 分遅れで、自動更新しません
- IV 推移は ATM IV（30 日固定）の 1 本だけです。限月ごとの IV・パーセンタイルなどの統計・日付へ移る欄・自動更新はありません（読むのは開いたとき・⟳・パンしたときだけ。[10 章](#iv-推移の読み込み)）
- 「清算値」での評価はありません
- ホーム画面に追加したアイコンは全画面のアプリにはしていません。オフラインで板を見る機能はありません（[1 章](#ホーム画面に追加)）
- コマンドパレットはキーボードの操作です（スマホ・タブレットには入口がありません）

## 19. 困ったとき

| 症状 | 確かめること |
|---|---|
| 開くと「板を読めない」 | [最新] を押し直す。続くときは、データの取り込み（optionchan）が止まっていないか、休業日でないかを確かめる |
| 板の時刻が古い | 市場ピルのタグを見る（ピルを押すと理由の 1 文）。「時間外」なら休業日・夜間の終了後など。立会中なのに古いときは取り込みの停止を疑う |
| 損益グラフが出ない | 足が 0 本か、F が決まらない限月の足だけ（「評価できる足が無い」と出る） |
| シナリオ 0 なのに損益が 0 にならない | 手数料が入っている、または建値ずれ（IV が逆算できない建値）がある。ポジションの詳細の建値ずれ・印を見る |
| 指定日の線が出ない | d = 0 かつ Δσ = Δs = 0 のときは、今日の線と同じなので描かない |
| スマイルが「スマイルなし」 | F が決まらないか、使える気配が無い（寄り前・夜間序盤など） |
| 数値欄が赤くなる | 範囲外の値。エラーの文に範囲が出る。反映はされていない |
| ハンドルから離れた所で長押ししても動かない | 長押しの前に指が動くとパンになる。0.45 秒ほど止めてから動かす。ハンドル（● と縦線）の近くはすぐつかめる |

| 「URL のポジションを読めなかった（壊れているか途中で切れている）」と出る | URL が途中で切れたか、どこかの字が変わった（メールの折り返し・貼り付けの欠け）。渡した側でもう一度 [URL をコピー] して、切れない方法（メッセンジャー・メモ）で渡す。長い URL は保存一覧の書き出しで渡す。作業は変わっていない |
| 「新しい版で作った URL は読めない」と出る | 新しい版の画面で作った URL。ページを再読み込みして新しい版の画面で、もう一度 URL を開く |
| 「このブラウザでは URL のポジションを開けない」「URL を作れない」と出る | ブラウザが古い（iOS 16.4 より前の Safari など）。ブラウザ・OS を更新するか、別のブラウザで開く |
| [URL をコピー] で「共有の URL」のダイアログが出る | ブラウザがクリップボードへの書き込みを許可していない。ダイアログの欄（選択された状態）からコピーする |
| トップバーに「別のタブ」のタグが出る | 同じブラウザの別のタブで操作した。このタブで操作すると、このタブの内容で上書きする。別のタブの内容を使うなら再読み込み |
| キー（1〜6・G・T）が効かない | 入力欄・ダイアログにフォーカスがある、または日本語入力の変換中。Esc や入力欄の外をクリックしてから押す |

## 20. AI に相談

AI（Anthropic の Claude）に、今のポジションの弱点の読み解きや、ややこしい数字の説明、組み方・ヘッジの提案を頼めます。数字はこのシミュレーターの計算（指標・テール表・証拠金・シナリオの評価と同じ計算）から取り、AI には計算させません。管理者が AI を有効にしているときだけ使えます。

- 開き方: スマホ・タブレットはドックの **[AI]**（吹き出しのアイコン）、PC はトップバーの **[AI]** かキー **6**（右の列のポジション・指標と入れ替わります。もう一度押すと戻ります）。コマンドパレット（Ctrl / ⌘ + K）の「AI に相談」「このポジションを診断」からも開けます。損益グラフは開いたまま見えます
- 見出しに **今日の残り**（例 `残り $2.40 / $3.00`）が出ます。1 日の上限を使い切ると翌日まで送れません
- 初めて開いたときだけ注意書き（投資の助言ではない・売買の判断はご自身で）が出ます。[閉じる] を押すと、この端末では次から出ません
- **[このポジションを診断]**: 今のポジション・シナリオ・資金（設定の証拠金の資金）を送り、弱点を 3〜5 個、どこで損が膨らむか・何に弱いかを数字つきで返します
- **質問**: 下の入力欄に書いて Enter（改行は Shift + Enter）。AI は必要なら決まったシナリオを計算させ、その結果をカード（例「シナリオの評価: ΔX −6.0% · 3 日 · IV +5pt → 損益 …」）で見せます。カードの **[シナリオに適用]** で、その日数・ΔX・IV・スキューをシナリオに入れられます（トーストの [元に戻す] で戻せます）
- **ポジションの提案**: 「今の IV と資金から見てボラ売りの候補を出して」「最大損失を −1,000 千円に抑えるヘッジの足を足して」「このポジションの調整案を出して」のように頼むと、AI は **提案のカード** を出します。行使価格は AI が勝手に決めず、シミュレーターが今の板（買いと売りの気配がそろった行）から作った候補・条件に合う行から選びます（例: 最大損失の下限を満たす中で一番安い行使価格）。カードには足の差分（＋ 追加・− 削除・± 枚数 / 行使価格の変更）と、入れた後の満期の最大損失・必要証拠金・Δ（ラージ / ミニ）・追証の水準（資金を設定しているとき）が、今 → 後で出ます
  - **[今のタブに適用]** で今のタブの足を入れ替え、**[新しいタブに入れる]** で組み合わせを丸ごと新しいタブに入れます（タブを並べて・ピンで比べられます）。トーストの **[元に戻す]** で戻せます（新しいタブは閉じて、押したときのタブに戻ります。新しいタブの足を変えた後は戻しません。タブの × で閉じてください）
  - 提案の後に足を変えた・板が読み直されて選ばれる行使価格が変わったときは、反映せずに知らせが出ます。もう一度 AI に頼んでください
  - 板に無い限月・行使価格の提案はカードになりません。提案は検討の材料で、建てるかどうかはご自身で決めてください。必要証拠金は概算です（設定の既定では買いの OP で減らしません）
- 進み具合: 押すとすぐに「計算中 → 送信しました → 考え中 → 書いています」と経過秒が出ます。**[中止]** で止められます（止めた分も費用は数えます）
- **テクニカル**: 「日足の RSI は？」「週足と 4 時間足の MACD は？」のように聞くと、AI は先物（ラージ・期近）の週足・日足・4 時間足の RSI・MACD・ストキャスティクスと EMA の 3 本（先物推移の段・線と同じ期間・同じ計算。期間は設定の「テクニカル指標」）を読みます。「日足のトレンドは？」と聞くと、EMA の並び（上向き / 下向きのパーフェクトオーダーか）・価格と各 EMA の距離（円・%）・直近の交差も使います。返すのは今の値・直近の推移・状態（例: RSI が 70 以上で何本目、MACD がシグナルと交差して何本目）と、**過去に同じ状態だった後の値動きの分布**（件数・中央値・下位 10%・上位 10%）です。分布は予想ではなく材料で、件数が 20 未満なら「サンプル不足」と書きます。分布は限月が替わる所をまたぐ期間を除いて数えます（替わった所の値の差を値動きと混ぜないため）。最新の足は取引中なら確定前で、AI もそう扱います。AI は上がる・下がるを断定しません。読むのは聞いたときだけです（先物推移と同じデータを読み、10 分間は読み直しません）
- 照合できない数字: 返答の中の数字が計算の値と照合できないときは、点線の下線が付きます（その数字は計算の値ではありません）
- 会話はこのタブの間だけ残ります（再読み込みでは残り、タブを閉じると消えます）。保存一覧・URL・書き出しには入りません。**[新しい会話]** で消します。長くなると新しい会話を勧めます
- 押せないとき: 足が無い・AI が無効・今日の上限・送信中のときは、ボタンの下に理由が出ます。「ログインの期限が切れた可能性があります」と出たら再読み込みしてください
