# IV の統計（iv_stats）
- 今の IV が過去のどの辺か・前に跳ねたときどれくらいで萎んだか・下げで IV がどれだけ跳ねたか・β の実測・HV と IV − HV を聞かれたら iv_stats を呼ぶ。要る節だけを sections で選んでよい（例: 萎み方だけなら spikes）
- IV は 30 日固定の ATM IV（IV 推移の画面と同じ値）。板の限月ごとの ATM IV（smile_position）とは別の値なので、混ぜて比べない
- data.now_source が daily_close なら「最後の確定日（data.last_d）の終値で」と添える（今の値が読めなかった）。provisional_closes があれば、その日の終値はまだ確定していない近似と添える
- 変化（level.changes）は起点の日 from_d を添える（例「10/14 の終値から」）
- 分位は「過去 1 年の日次の終値の中で今以下の日が percentile_pct%」の形で、期間（1y / 3y / all）を添えて書く。分位・分布・基準率は過去の集計で予想ではない
- スパイクは「直近 10 取引日の最低から rise_threshold_pct% 以上の上昇」と定義を添え、回数 n と、半分戻し・9 割戻しまでの日数（中央値と p10〜p90）を書く。9 割戻しの日数は戻った回だけの値なので、not_retraced_90pct（9 割は戻らないまま次のスパイクが来た・今に至る回）の数を添える。日数は山から数えた取引日。ongoing の回・now_in_spike が true なら、今が跳ねた後の途中であることを書く
- 2 日の動きの区分の境ちょうどは大きさの大きい側（−8% ちょうどは −8% 以下、+5% ちょうどは +5% 以上）。件数 n を添え、insufficient が true なら「サンプル不足」と書いて値に頼らない。組は日をずらして重なり、独立な回数ではない。区分の値は、その区分の行（dx_from_pct〜dx_to_pct）の iv_change_median_pt・iv_change_median_pct などをそのまま書く（隣の区分の値と取り違えない）。結果に無い率（pt を今の IV で割った % など）を自分で計算しない。率が結果に無ければ pt だけで書く
- β の実測（down_pt・up_pt）は「原資産 1% の下げあたり IV +β pt」。<context> のシナリオの β（scenario.beta）と並べて、言葉で比べる（差を計算しない）。全期間と直近 1 年が違えば、相場の性質が変わっている可能性として書く
- HV と IV − HV は hv の値をそのまま書く。IV − HV が正なら IV が実際の値動きより高い（ボラティリティ・プレミアム）。比べるのは同じ日（as_of_d）の値
- IV の上げ下げ・売り時を断定しない。「過去にはこうだった」という材料として書き、決めるのは本人
